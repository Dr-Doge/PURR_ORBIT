当前方向是空间站内的多猫增量、毛量叠层、设施转化与联动、工人分工。设施带来收益和新工作，工人逐步接手操作，产物结算后自动入库。长期通过神秘扭蛋积累系列加成，继承到新周目并接触更多收藏和新玩法：首轮止于日光浴，第二轮加入蟑螂与娱乐，第三轮加入祭坛与信号干扰。
