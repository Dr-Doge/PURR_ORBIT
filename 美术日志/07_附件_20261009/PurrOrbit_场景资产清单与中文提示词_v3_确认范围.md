# Purr Orbit 场景资产清单与中文提示词 v3｜确认范围

本版按用户最新选择，替代 v2 作为当前制作清单。仅制作 **01、02、03、04、06、10、11，共 7 个完整资产模块**，保留原编号以便对照。以“拖进引擎即可摆放”为目标，固定装饰和小零件直接画在所属模块里；只对独立运动、透明窗口和空间朝向有要求的部分保留必要分层。

视觉参考：[已确认的米灰暖褐概念图](PurrOrbit_视觉基准_v1.png)。所有制图任务都附上该图，仅参考画风、配色、细节密度。本文中的画布尺寸为建议，可按实际镜头调整；本文不改工程或玩法。

**7 个模块不等于严格 7 张 PNG。** 墙顶与墙面朝向不同，门叶需要运动，前景需要左右摆放，这几处仍有必要的小分层；灯、管夹、螺钉、窗台、食盆等不再单列制作任务。

### 本轮不制作的项目

- **05 密封回收舱：暂缓制作。** 04 保留接收接口和托座，但本轮不生成回收舱物件或开舱素材。
- **07 猫窝整组、08 喂食设备整机、09 梳毛设备整机：不制作。** 不把这些设备追加进其他模块的画面。
- 这里只调整本轮美术制作范围，不代表删除现有工程资产或取消玩法。

### 为什么地面可以合成一张

当前先服务于已经确定的固定房间：整张地面画成规则、同规格的板块，视觉仍然模块化，但不要求每块砖独立摆放。图内包含四周边框，减少接缝和素材管理工作。如果以后要改变房间大小，再从母图整理可平铺地板，不现在提前拆几十块。

### 为什么墙仍保留少量分面

标准墙段作为一个整体模块交付和摆放，但实际由“竖直内墙面＋水平墙顶面＋前端封面”组成。它们可以共用一个图集，不需要分别列入资产清单。后墙和侧墙可复用墙段，窗墙与回收接口替换对应墙段。**墙顶的厚度不能仅靠在内墙图片顶部画一条斜边代替。**

## 二、统一制图规则

- 每项下方的中文提示词可以单独复制使用，均已包含必要风格描述。
- 固定结构画正投影：地面严格俯视，墙段严格正面；不要提前画入房间透视。家具和前景匹配游戏的正面略俯视镜头。
- 配色以米灰、燕麦白、暖褐、低饱和深灰为主，琥珀灯色点缀；只有植物保留少量自然绿色。
- 保留清晰勾线、简洁色块和少量固有明暗，不要厚重纸纹、水彩笔触、密集划痕，也不要变成写实三维渲染。
- 壁灯和状态灯可以直接画进模块。若需要发光，后续从原图灯罩区域制作遮罩，并在引擎里添加灯光；不单独重新生成灯罩。
- 图片不烘焙房间中央光斑、地面投影和四周暗角，以免移动模块后光影冲突。
- 生成结果仍需检查透明边、尺寸和拼接。不要要求生成模型直接输出准确图集或真正的分层文件；先确认母图，再整理必要层。

## 三、中文制图提示词

### 01｜整体地面

```text
为《Purr Orbit》制作一张完整的太空站室内地面贴图。参考附图的米灰暖褐配色、清晰勾线和温馨科幻质感，只生成地面。

严格垂直俯视、正投影、无透视。整个房间的地面为一个完整矩形，内部由同规格的正方形金属板排列组成，建议6列×5行，四周包含连续的窄边框与完整转角。少量板块加入简洁的检修盖细节，尺寸与其他板完全一致。浅米灰地板，低对比细接缝，少量统一的小固定点；周边收口使用稍深的暖灰色。中央保持干净、舒展，地面细节不抢猫的注意力。

干净的二维游戏插画贴图，线条克制，色块平整，允许很轻的材质色差。不要厚板倒角、强高光、绿色棋盘格、随机大小的拼砖、密集螺钉和做旧纹理。不要墙、家具、猫、文字、地面投影、暖光光斑或暗角。不透明背景，地面完整填满画布，无额外留白。四周边框画在贴图内部，不要画出可见侧面厚度。
```

### 02｜标准墙段

```text
为《Purr Orbit》制作一个可重复拼接的完整太空站内墙模块。参考附图，只生成单个墙段的正面贴图，不画整间房。

严格正面正投影，无透视。一个接近正方形的墙段，上部米灰色舱壁，下部为低饱和暖深灰检修带，底部整合连续墙脚。将一处小通风口、少量固定管线及管夹、一盏琥珀色壁灯和简洁墙板分缝直接画入墙段，作为同一件资产。两侧边缘保持整洁，墙脚和下方检修带在相同高度结束，便于相邻墙段连续拼接。避免两侧各画半根粗柱造成重复拼接时柱子过厚。

干净勾线、平整色块、少量柔和固有明暗，米灰、暖褐、暖深灰为主。科幻结构明确但不繁琐，不使用蓝绿色大色块，不画写实金属反射、纸张纹理或密集划痕。灯罩有暖色但不向周围烘焙大片光晕。不要门、窗、家具、地面或文字。不透明贴图，不展示墙体的顶面、侧面和透视厚度。
```

墙段验收后，补充封边的中文提示词（仍归入同一模块，不增加资产条目）：

```text
为已确认的标准墙段补充一个窄封边表面，颜色和线条必须与附图墙段一致。本次只画【水平墙顶面／竖直前端面】中的一个，严格垂直于该表面观察，正投影，不带透视，不画相邻面。暖灰金属表面，简单细边线，少量或没有内部细节，沿长度保持可连续连接。宽度按墙体厚度设置，不画成粗厚梁。不要灯、管线、阴影和背景场景。两种封边分别生成或直接从母图整理，最终与内墙面排入同一套素材。
```

### 03｜带窗墙段

```text
为《Purr Orbit》制作一个完整的带舷窗太空站墙段。附上已确认的标准墙段和概念图，匹配它们的墙高、墙脚高度、配色和描边。

严格正面正投影，无透视。墙段中上方是一扇尺寸克制的圆角长方形舷窗；窗框、薄窗台、上方琥珀壁灯、周围墙板和下方检修带合并为一个完整模块。舷窗四周保留足够实体墙面，不做落地窗或全景玻璃幕墙。米灰外框配窄暖深灰密封圈，厚度只用简洁内外轮廓与少量固有明暗提示。

窗口内部必须是真正透明的空洞，不画星空、星球、黑底或反光玻璃。其余墙面不透明。窗洞位置之外不要出现额外透明缺口。清晰勾线、平整色块、低饱和暖中性色，二维贴片美术。不要绘画纸纹、写实三维渲染、文字或房间透视。上下和左右边缘需能与标准墙段衔接。
```

### 04｜轨道回收接口整组

```text
为《Purr Orbit》制作一组完整的轨道回收操作舱入口，匹配附图的温馨科幻空间站风格。门框、关闭的双开金属门、右侧小控制台、低矮门槛和接收托座整合为一个清楚的功能模块。

以正面视图为主，与后墙平行，只有门槛和托座可略见顶面。门框纤细克制，米灰舱门配暖深灰密封圈，门中央有小观察圆窗，左右门叶闭合缝清楚。右侧控制台显示简洁的接驳信号图形，配一枚小琥珀状态灯。不要显示文字、数字或价格。入口代表交付毛团能源、接收密封回收舱的操作区域，不是垃圾桶、洗衣机或售货机。

采用清晰勾线、整洁色块与少量浅层明暗，控制台和门框不要夸张突出。不要深隧道、巨大拱门、大面积警戒条纹、蓝绿色屏幕强光或写实金属材质。透明背景，外轮廓完整，不附带整面墙或房间地板。没有外部投影。先输出一张完整的闭门母图，后续只把活动的左右门叶拆出，其他固定部件保持合并。
```

必要的开门状态补图提示词：

```text
以已确认的回收接口母图为基准，只移开左右门叶，补全门后被遮挡的浅层操作舱衬景。门框、控制台、门槛、托座的位置、尺寸、画布和画风都保持一致。门后是安静的暖深灰舱壁和简单接收凹位，层次浅、对比低，不生成长隧道、另一套门框或额外设备。不要回收舱和文字。此图用于提取门后的背景层，精确对齐以原母图为准。
```

### 06｜宇宙背景

```text
为《Purr Orbit》制作一张供空间站小舷窗共用的宇宙背景。完整正方形画面，深色低饱和夜蓝接近黑色的太空，稀疏的星点，一颗偏离画面中心的远处星球和少量小行星。保留大面积安静区域，星球不占满画面。

平整、简洁、与二维勾线游戏协调的插画风，少量柔和星球明暗，不使用写实天文摄影和浓烈星云。星点亮度克制，不能抢过室内猫咪和暖灯。不画舷窗、窗框、墙壁、飞船、文字、光晕或镜头光斑。整张不透明背景。不同窗户后续显示这同一张图的不同部分，不为每个窗口单独画星空。
```

### 10｜壁挂装饰整组

```text
为《Purr Orbit》制作一组完整的壁挂装饰：一块短小搁板、下方简洁金属支架、一个小盆栽和一个米白猫形摆件。所有物件已经摆放在搁板上，作为同一个透明贴片交付，不拆开生成。

正面略俯视，搁板顶部少量可见。暖灰支架，低饱和暖褐搁板，小盆栽只有少量自然绿色圆叶，猫形摆件表情极简。造型温馨，体量小，不能成为场景主视觉。清晰勾线、平整色块，少量柔和固有明暗。

不要木纹、水彩纸纹、密集装饰、更多摆件、文字、墙面、地面或墙上投影。真实透明背景，全部物件完整，不裁切植物。
```

### 11｜前景机械边框组

```text
为《Purr Orbit》制作一条【左侧／右侧】前景机械边框贴片。参考附图中克制的边缘点缀，只包含纤细的竖向机械框架及依附其上的少量管线、短线缆、固定件，它们作为一个完整模块。

贴片主面正对镜头，造型高而窄，暖深灰与低饱和褐灰为主，少量暗铜固定件，线条清晰但内部细节稀疏，只有很轻的内侧受光提示。进入最终场景后，每侧只覆盖画面宽度约2%至3%，绝大部分位于边缘，不占用中央地面。左右框架结构同类，可有轻微细节差异。

不要巨大弯管、粗柱、斜撑、大块底座、整圈拱门或明亮灯带。保持二维插画贴片感，不做写实三维支架。透明背景，输出完整未裁切的源素材，实际出画裁切由镜头完成。不要地面、墙面、猫、文字和外部投影。左右分别生成，不把两边合在一张含空白房间的图里。
```

## 四、合并后的搭建与制作顺序

1. **先完成房间外壳**：01 地面、02 标准墙段、03 带窗墙段、06 宇宙背景。侧墙由标准墙段加封边组成；带窗墙段的透明窗洞后方不能再叠一块不透明墙挡住宇宙。
2. **补完整功能入口**：04 回收接口。固定入口整组摆放，仅活动门叶保留必要分层；保留空的接收托座，不制作 05 回收舱。
3. **加入壁挂装饰**：10 壁挂装饰整组，搁板、盆栽和猫形摆件作为一件摆放；不制作猫窝、喂食设备或梳毛设备。
4. **最后加前景**：11 机械边框组。只在边缘提供遮挡，不遮住可互动地面。

先做静态整件，只有实际需要运动的部位才拆层。灯光由工程添加，碰撞和交互位置跟随完整模块设置。猫的动画、界面和状态文字沿用单独制作流程，不在这份场景清单中扩项。
