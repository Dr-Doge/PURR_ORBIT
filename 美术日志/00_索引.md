## 记录口径

- 以 Git 作者 `jominccc <jominc@andrew.cmu.edu>` 的提交和仓库内报告为可核对范围；“提交／接入”不等同于对每张原图的原创署名。合并提交中的队友内容单独注明，不归为个人原创。
- 内容包括美术资源、动画配置、空间站场景、3D 展示、特效、视觉交互及相应测试／整合记录。纯玩法和数值设计以[策划索引](../摸猫增量策划案/00_索引.md)及[实装变更日志](../摸猫增量策划案/18_实装变更日志.md)为准。
- 旧版素材和被替换的方案仍记录在日志中，并标明当前使用状态；不把历史版本误写为正在运行的资源。
- 后续新增内容按日期追加至 01，并同步 02 的当前路径和状态。每项至少写明内容、路径、提交或其他证据。
- 01 每个时期的“操作与画面说明”解释素材如何进入场景、玩家会看到什么；查看或继续制作时先从 02 找到当前资源，再按 01 的提交和报告核对版本。
- 03—05 把**已接入游戏的资源**和**工作目录里的实验／导出**分开标记。画布工具源码和数据目前位于相邻的 `Gaming` 工作区，不在本 GitHub 仓库；本目录是其可随仓库阅读的交接记录，不代表工具或原始输出已随本仓库发布。
