# 15｜空间站外星猫：交互总表

v0.27｜2026-09-18。入口：[00_索引](00_索引.md)。Demo是一段约一小时的连续经营，分两批内容，不重开。以下仅讲玩法；数值与操作细节见各系统文档，未实装本次改动。

## 机制表

| 我会遇到什么 | 游戏怎样变化 | 我要做什么 |
| --- | --- | --- |
| 猫长出毛球 | 每过相同CD多一层，层数越高额外收益越多 | 开局先收一层赚启动钱，之后试着攒几层再收 |
| 猫和设施越来越多 | 赚得多，但收割、补粮、搬猫会忙不过来 | 招募工人，让他们接手重复操作；结算产物直接入库，不用捡 |
| 第一枚神秘代币 | 神秘猫形存在送来刻满图腾的扭蛋机 | 投币、转旋钮，看到收藏带来的加成 |
| 第一阶段 | 发展到喂食器和日光浴，还没有虫害；可抽2套、每套6件 | 提高产量、学习攒层和安排工人，收齐首批12件 |
| 仪器补货 | 原场地和全部经营进度保留，新增4套、每套6件 | 接着经营和抽取，不重新开局；旧收藏继续加成 |
| 第二阶段 | 旧喂食器可能生虫，新增分工与娱乐设施 | 亲手清虫，再安排工人；让部分猫去赢取换金道具 |
| Demo收藏完成 | 两批合计6套、36件都已拥有 | 查看成果并继续经营；后续内容留待扩展 |

体验顺序：工人 → 喂食器 → 猫粮与巨型转化 → 日光浴与静电转化 → 首批收齐、补货 → 蟑螂与分工 → 娱乐与招财转化。顺序用于安排引导，不要求转化成功或旁支满级才能继续。

## 猫咪表

| 猫咪 | 怎么得到 | 有什么用 |
| --- | --- | --- |
| 短毛猫 | 唯一可以直接买的基础猫 | 长毛、收割，使用设施时有机会转化 |
| 巨型猫 | 第一阶段起，喂食器转化 | 体型变大、依赖猫粮、产量更高；第二阶段进食能吃掉一部分蟑螂 |
| 静电猫 | 第一阶段起，日光浴转化 | 炸毛圆球形；自己产毛时让附近猫同时产出一次 |
| 招财猫 | 第二阶段起，娱乐设施转化 | 每次产物产出时抛币：正面多给一件换金道具，反面保留原奖励 |
| 外星猫【后续，Demo外】 | 密语祭坛转化 | 绿色、黑色大眼、球头触角，缩短附近猫的毛层CD |

特殊猫通过设施转化获得；升级转化几率不会直接送猫。招财猫不通过抛币给代币。

## 自动化与设施表

| 设施／配件 | 我怎样使用 | 与其他机制的联系 | 升级方向 |
| --- | --- | --- | --- |
| 高能喂食器 | 摆好并补粮，自动喂范围内的猫 | 提高产量、转化巨型猫；第二阶段配合日光浴出现虫害风险 | 更高级猫粮、巨型转化几率 |
| 太空舷窗日光浴 | 拖入CD中的猫，就绪后猫自行离开 | 帮助更快长毛、转化静电猫；第一阶段无虫害 | 单次时间、容纳量、静电转化几率 |
| 次世代猫用娱乐设施 | 第二阶段把猫拖进去，按轮次赢取道具 | 猫暂时不产毛；有机会变招财猫；道具入库后可出售 | 获胜率、轮次速度、奖品价值、招财转化几率 |
| 神秘扭蛋机 | 首枚代币后获得，投币并转动旋钮 | 先抽12件，再补24件；每件不重复，已有buff始终有效 | 通过收集度增强系列buff，不另设普通升级分支 |
| 毛球精灵小帮手 | 招募工人接手收割、补粮、搬猫和清虫 | 新设施增加工作量，需要更多人手与明确分工 | 职责分配；效率和目标毛层策略为提案 |
| 职责分配帽 | 给固定工人安排固定任务 | 避免收割、补粮、清虫抢同一批人手 | 解锁固定分工，具体分支待定 |
| 喵喵密语祭坛【后续】 | 指派猫驻留，提供全局生产加速 | 转化外星猫；同时干扰娱乐设施，造成黑屏停产 | 槽位、单猫加成、外星转化几率 |
| 工人维护节点【后续】 | 研究后让工人接手捶打维修 | 配合职责帽恢复故障设备，不免疫后续干扰 | 维护能力，后续分支待定 |

## 新需求表

| 新需求 | 怎么出现 | 我要做什么 | 怎样逐渐轻松下来 |
| --- | --- | --- | --- |
| 猫粮补给 | 喂食器增产需要持续用粮 | 树上解锁、商店买粮、补进喂食器 | 安排工人补粮；是否代购另定 |
| 设施用猫安排 | 日光浴和娱乐设施需要猫 | 拖猫进去，权衡继续长毛或赢取道具 | 工人负责搬猫，玩家决定分配策略 |
| 太空蟑螂 | 第二阶段已有日光浴，喂食器久未打理 | 打开内部窗口连续点击清虫；不清会失去增产并减产 | 巨型猫吃一部分，清虫工人负责处理 |
| 工作分配 | 新设施带来更多种工作 | 招工、戴职责帽，把任务分开 | 固定岗位减少顾此失彼，不新增拾取岗位 |
| 黑屏维修【后续】 | 安装祭坛干扰娱乐设施 | 黑屏停止换金产出，连点捶打恢复 | 研究工人维护后，安排专人维修 |
