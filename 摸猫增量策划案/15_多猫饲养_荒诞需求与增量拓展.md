## 机制表

| 我会遇到什么 | 游戏怎样变化 | 我要做什么 |
| --- | --- | --- |
| 猫长出毛球 | 始终有第一层可收；基础每10秒多长一层，收益更高；首层要摸此前1.5倍的距离，毛越多越难收，但后面每多一层只多花一点工夫，操作量逐渐接近首层3倍 | 开局连续收第一层赚启动钱，之后选择攒层 |
| 猫收完毛的反应 | 这只猫播放反应动画时暂时不能再收，结束后恢复 | 趁它反应时去摸其他猫，期间划动不预存进度 |
| 鼠标放到猫身上 | 猫会停下，乖乖播放待机动作；收完毛时仍先播完反应动画 | 来回摸它完成收割，移开鼠标后它继续活动；只悬停不会自动收毛 |
| 选择我的玩法路线【新方向，待实装】 | 升级资源有限，这一段玩下来不能什么都点满 | 选单层快速反复收割、攒层爆发收割或道具交换换金，再搭配少量其他路线；具体节点为方案建议 |
| 小帮手收割 | 初始门槛1层；每次产出后休息一个工作CD，再收下一轮 | 自选升级：提高目标层数换大额收益，或缩短CD加快回款 |
| 猫和设施越来越多 | 赚得多，但收割、补粮、搬猫会忙不过来 | 招募工人，让他们接手重复操作；结算产物直接入库，不用捡 |
| 第一枚神秘代币 | 神秘猫形存在送来刻满图腾的扭蛋机 | 投币、转旋钮，看到收藏带来的加成 |
| 第一阶段 | 发展到喂食器和日光浴，还没有虫害；可抽2套、每套6件 | 提高产量、学习攒层和安排工人，收齐首批12件 |
| 仪器补货 | 原场地和全部经营进度保留，新增4套、每套6件 | 接着经营和抽取，不重新开局；旧收藏继续加成 |
| 第二阶段 | 旧喂食器可能生虫，新增分工与娱乐设施 | 亲手清虫，再安排工人；让部分猫去赢取换金道具 |
| Demo收藏完成 | 两批合计6套、36件都已拥有 | 查看成果并继续经营；后续内容留待扩展 |

体验顺序：工人 → 喂食器 → 猫粮与巨型转化 → 日光浴与静电转化 → 首批收齐、补货 → 蟑螂与分工 → 娱乐与招财转化。顺序用于安排引导，不要求转化成功或旁支满级才能继续。

## 猫咪表

| 猫咪 | 怎么得到 | 有什么用 |
| --- | --- | --- |
| 短毛猫 | 唯一可以直接买的基础猫 | 长毛、收割，使用设施时有机会转化 |

| 静电猫 | 第一阶段起，日光浴转化 | 炸毛圆球形；自己产毛时让附近猫同时产出一次 |
| 招财猫 | 第二阶段起，娱乐设施转化 | 每次产物产出时抛币：正面多给一件换金道具，反面保留原奖励 |

特殊猫通过设施转化获得；升级转化几率不会直接送猫。招财猫不通过抛币给代币。
