# 14｜周目循环与继承

v0.26｜2026-09-18。入口：[00_索引](00_索引.md)。已确认原则与重启细节提案分开记录；Demo已有临时实现，正式未定项仍由12维护。

## 长期循环（已确认）

**经营猫群与设施 → 获得代币 → 抽取不重复的收藏 → 系列buff持续增强 → 收完本周目所有可获得收藏 → 进入新周目 → 继承收藏加成、更快重新发展 → 接触更多新系列，并开放新的设施与事件。**

扭蛋机是长期推进的中心，但游戏不明说“主线就是集齐全部扭蛋”。玩家在体验更高收益和发现未知系列的过程中，自然愿意再次开始增量循环。

## 每个周目增加什么

| 内容 | 已确认规则 | 说明 |
| --- | --- | --- |
| 当期系列 | 每一周目开放新的扭蛋系列 | 不重新抽已经集齐的旧系列 |
| 系列数量 | 越往后的周目，可获得的系列数量越多 | 具体增长规则尚未指定 |
| 设施与事件 | 按周目阶段逐步开放，而非首轮全部提供 | 新周目带来新的操作和联动问题，具体排期见下表 |
| 完成条件 | 收完本周目所有可获得扭蛋 | 不额外要求升级树满级或指定猫种齐全 |
| 再开始 | 完成后半强制引导进入下一周目 | 具体触发界面和保留自由游玩方式待设计 |
| 继承 | 已获得收藏与系列加成保留 | 加成用于下一周目开局的快速增长 |

按“每周目新增可抽系列”的口径整理用户举例：第一周目可抽2套，第二周目可以新开放3套；此前2套留在永久收藏中，第二周目完成后累计5套。**2、3是示例，不是已定数量表，也不据此锁定每周目固定加1套。**

更后面的系列总量、周目上限以及最终内容边界未指定；当前不能宣称已有无限系列内容。后续开放新系列时，不应让已完成旧系列重新缺件而削弱继承加成，此为内容扩展建议。

## 设施与事件的周目排期（当前采用）

周目同时控制“可抽哪些系列”和“能接触哪些玩法”。旧内容因永久加成而更快推进，新内容让每一轮都有新的目标与操作。以下按用户给出的前三轮安排展开。

| 周目 | 设施开放范围 | 新事件与交互 | 这一轮的体验重点 |
| --- | --- | --- | --- |
| 第一周目 | 基础猫群、工人、喂食器，生产设施推进到日光浴为止；神秘扭蛋机仍在早期出现 | 抚摸、攒毛、补粮、搬猫进入日光浴；不出现蟑螂和信号干扰 | 学会基本增量与劳动自动化，收集首批永久buff |
| 第二周目 | 先前内容继续可用，新增娱乐设施；密语祭坛尚未开放 | 引入喂食器蟑螂事件，增加清虫工作；安排猫进入娱乐设施 | 熟悉的喂食器出现新问题，同时获得新的换金玩法 |
| 第三周目 | 先前内容继续可用，新增密语祭坛 | 引入信号干扰，娱乐设施黑屏；手动捶打，再解锁工人维护接手 | 追求全局提速时需要维护旧设备，形成新一轮分工 |
| 第四周目及以后 | 继续以新设施、事件和系列扩展 | 具体内容未定 | 每轮新增有意义的玩法，避免只增加数值与抽取数量 |

这表示内容开放资格的范围，并不决定原有猫、设施实体和树等级是否随重开保留；重置清单仍待定。已开放的旧系统会进入后续周目的可用内容范围，是否需重新购买或研究另行确定。

## 事件必须同时满足周目与设施条件

- **蟑螂：第二周目及以后，且日光浴已在本轮满足安装条件，喂食器久未打理才可能生虫。**第一周目即使安装了日光浴也不触发，不能把“安装过日光浴”单独作为充分条件。
- **信号干扰：第三周目及以后，且密语祭坛满足安装条件后，部分娱乐设施才可能黑屏。**进入第三周目不等于所有设备立即故障。
- 若设施实体跨周目保留，进入新周目应重新判断其有效状态；若实体清零，则按本轮重新安装处理。事件计时如何初始化待定，不用旧周目的安装标记绕过当前状态。
- 两种事件都不要求先转化出特殊猫。巨型猫的吃虫能力在第一周目没有虫害目标，第二周目才展现其额外用途。

## 开放资格与实际解锁

先检查周目是否开放该系统，再检查树中前置与费用，最后购买、摆放或指派使用。进入第二周目不是自动送一台娱乐设施，进入第三周目也不是自动安装祭坛。永久buff带来的高收入不能提前买到后续周目内容。

设施相关转化不能早于设施开放：招财猫最早从第二周目的娱乐设施产生，外星猫最早从第三周目的祭坛产生。喂食器、日光浴的转化分支等级与其他旁支逐轮开放细节尚未定。职责帽建议随第二周目工作增多重点引导，具体解锁周目仍属于排期提案。

## “半强制”如何表现（设计提案）

1. 本周目奖池抽空后，仪器停止提供当期抽取，并显现新的图腾或信号。
2. 神秘存在再次接触，提示下一次旅程会回应这个信号；玩家能看到新系列的模糊轮廓和继承收益。
3. 提供“开启下一周目”与“暂时留下”。留下可继续经营，但下一批收藏以及后续周目的设施与事件都需要进入对应周目才开放。
4. 进入前明确展示保留与重置清单，玩家选择后再执行切换。

推进压力来自当期收藏空间已经完成、新内容在下一周目；不通过倒计时删除存档或突然清空猫群制造压力。是否采用上述暂留方式，仍是提案，不擅自把“半强制”写成自动重置。

## 继承与重置边界

| 内容 | 当前确定程度 | 处理方向 |
| --- | --- | --- |
| 已获得的扭蛋收藏 | 已确认继承 | 不丢失、不重复抽取 |
| 已获得系列buff | 已确认继承 | 下一周目从开局就提供快速增长能力，不等待再解锁扭蛋机才生效 |
| 下一周目的新系列 | 已确认开放更多 | 新增当期可抽内容，与旧收藏一起展示但不混入旧物品 |
| 猫、工人、设施与摆放 | 待定 | 为重新经营哪些重置、哪些保留需明确 |
| 升级树等级、购买资格 | 待定 | 是否重研、开放条件如何处理需明确 |
| 毛球、猫粮、普通换金道具 | 待定 | 结余保留、清零或换算均未指定 |
| 剩余代币 | 待定 | 不能默认全部保留或清零；需防止囤币使下一周目立即抽空 |
| 扭蛋机本体与使用资格 | 待定 | 用户描述下一周目再次解锁，具体是重新交付还是重新激活尚未定 |

设计提案：已经历的首遇教学缩短为一次新的信号回应；继承buff持续生效，仪器是否已可用是另一状态。切换应同时保存收藏、周目编号与重置结果，避免中断后丢失收藏或重复结算；不在本轮代替用户决定所有清零项。

## 周目节奏

首周目重点是收割、叠层、喂食与日光浴；第二周目加入蟑螂与娱乐，第三周目加入祭坛与信号干扰。原工人至祭坛的长顺序现在跨周目展开，不再要求首轮走完。永久加成缩短已熟悉的部分，教学重点留给这一轮新开放的操作。

更多系列会增加所需抽数，因此下一周目不应只增加收藏数量而不给玩家更快的代币获取或更有意义的新目标。另一方面，永久加成不能让所有经营过程都被瞬间跳过。代币产出与局内毛球增长是否挂钩，是下一轮节奏设计的重点。

需要测试：首枚代币和首抽是否足够早，第一套是否带来明确动力，本周目收完时是否仍有大量本轮已开放但未体验的设施，第二周目是否明显更快且仍有选择。具体时长、Demo包含几周目及最终结束方式见[12](12_待定决策与变更.md)。
