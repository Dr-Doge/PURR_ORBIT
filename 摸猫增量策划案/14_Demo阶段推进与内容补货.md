# 14｜Demo阶段推进与内容补货

v0.27｜2026-09-18。入口：[00_索引](00_索引.md)。本版取代Demo的两次重开与三轮排期；正式版保留周目制方向，具体重置与继承细节不在本Demo中验证。

## 连续体验的推进规则

**经营增产 → 获得代币 → 抽取首批12件并增强buff → 全部收齐后补货24件、开放第二阶段 → 在现有经营规模上继续扩张 → 收齐全部36件，完成Demo收藏体验。**

原“第一、第二周目”只作为内容批次的来源称呼，玩家不重开、不重新搭建第一阶段。补货条件按首批12件全部获得处理，不追加全树满级、指定猫种转化成功等条件。

## 两阶段内容安排

沿用原前两轮的设施分期；现在以连续阶段承接。第一阶段约25分钟、第二阶段约35分钟是调参提案，只有总目标约一小时已由用户指定。

| 阶段 | 进入条件 | 设施与新操作 | 收藏 |
| --- | --- | --- | --- |
| 第一阶段 | 开始游戏 | 收割与攒层、招工、喂食补粮、猫粮分支、巨型转化、日光浴搬运、静电转化；无蟑螂 | 新2套×6＝12件 |
| 第二阶段 | 第一批12件全获得，仪器补货 | 原场地继续生产；开启虫害资格、清虫与分工，研究和购买娱乐设施、分配猫、换金与招财转化 | 新4套×6＝24件 |
| 后续扩展，当前Demo外 | 另行设计 | 密语祭坛、外星猫、信号干扰、捶打与工人维护；保留既有联动设定 | 未定，不承诺第三批规模 |

进入阶段只开放资格。研究、购买实体、摆放、分配猫仍按各系统执行；不自动赠送娱乐设施。第二阶段不以拥有祭坛或维修收益为平衡前提。

## 切换时保留什么

| 状态 | 连续阶段的处理 |
| --- | --- |
| 猫、工人、设施 | 保持数量、猫种、位置、指派与岗位；不重建 |
| 树节点与等级 | 已购内容保持；新阶段提供新的可研发内容 |
| 毛球、猫粮、普通道具、代币 | 库存与已投进喂食器的粮食保持，不清零、不重复发开局物资 |
| 收藏与buff | 首批12件永久保有、持续生效；不重新抽取或重复叠算 |
| 生产状态 | 保持毛层、正在进行的CD、工人任务和已有运行状态 |
| 扭蛋机 | 使用原仪器补货，不重复首遇、交付或激活门槛 |

以上是“不引入重开”的连续经营处理，不制定正式版未来周目的继承清单。

## 虫害如何衔接旧设施（实现建议）

第二阶段仍检查“场上已有日光浴＋喂食器久未打理”。第一阶段留下的日光浴直接满足安装条件，不要求拆掉重放，也不能因没有“本轮安装事件”而永不生虫。

建议风险计时在第二阶段资格生效后才开始：忽略第一阶段累计的未清理时间，给一段完整的首次打理间隔，不在补货瞬间让全场喂食器同时生虫。若进入第二阶段时尚无日光浴，则等实际安装后开始计时。只初始化新解锁的虫害计时，不重置其他经营状态。具体间隔仍待D07／D22校准。

## 结束与内容预告（交互提案）

第36件获得后展示已完成本次信号中的收藏，允许继续经营。后续祭坛等可作轮廓预告，不提供本Demo内无法完成的付费升级，不展示“必须进入第三周目”按钮。

不通过固定25分钟倒计时锁住第二阶段：擅长经营的玩家可以更快完成；一小时由可选择的投资、劳动与抽取效率共同形成。完整节奏建议见[16](16_一小时Demo数值与阶段节奏分析.md)。
