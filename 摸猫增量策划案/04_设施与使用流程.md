# 04｜设施与使用流程

v0.27｜2026-09-21更新喂食交互。入口：[00_索引](00_索引.md)。

设施提供增量与新机制；补粮、搬猫、清虫、维修由玩家或工人承担。设施是场景中的实物，已确认的自动喂食与轮次运行保留。

**Demo阶段范围：**第一阶段到日光浴，第二阶段开放娱乐；密语祭坛保留为后续内容。补货不清空已有设施，开放资格不等于自动赠送新实体，仍需研究、购买与摆放。完整排期见[14](14_Demo阶段推进与内容补货.md)。

## 四类生产设施（设定保留，祭坛不在当前Demo内）

| 设施 | 使用流程 | 收益与转化 | 升级分支 |
| --- | --- | --- | --- |
| 高能喂食器 | 摆放并补粮 → 猫自动寻找有粮设备并前往 → 进食获得固定时长增产buff → 到期后再次觅食 | 提高产物数量；实际进食时可能转化巨型猫 | 更高级猫粮种类、巨型猫转化几率 |
| 太空舷窗日光浴 | 放置区域 → 把产毛CD中的猫拖入 → 停留至产物就绪 → 猫自行离开 | 帮助猫就绪；可能转化静电猫 | 缩短单次时间、区域容纳量、静电猫转化几率 |
| 次世代猫用娱乐设施 | 将猫拖入拉杆与显示屏设施 → 按轮次概率赢取道具 | 占用期间不产毛；可能转化招财猫 | 获胜率、轮次速度、奖品价值、招财猫转化几率 |
| 喵喵密语祭坛 | 安装 → 将猫指派进槽位 → 猫提供全局生产速度比例加成 | 帮助更快积累毛层；可能转化外星猫 | 猫咪槽位、单只猫全局加成、外星猫转化几率 |

## 高能喂食器：自动觅食循环（2026-09-21确认）

**没有喂食buff → 自动寻找有猫粮储备的喂食器 → 自行前往并吃下食物 → 获得固定时长的增产buff → 离开继续活动 → buff到期后再次觅食。**

| 环节 | 猫咪的行动 | 玩家需要做什么 |
| --- | --- | --- |
| 寻找食物 | 没有喂食buff时，自动寻找有猫粮储备的喂食器 | 摆放设备并保证粮食供应，不必逐只拖猫投喂 |
| 前往与进食 | 自行走到喂食器，实际吃下猫粮后才获得buff | 无需逐次点击确认；玩家或工人负责补粮 |
| 加成持续 | 在固定时长内获得产物数量加成，离开设备后仍有效 | 照常抚摸收割、安排猫与设施，不必让猫一直待在喂食器旁 |
| 再次觅食 | buff时间结束后，重新寻找有粮的喂食器，重复循环 | 随猫群扩大调整供粮和工人安排 |

这项规则替换原先“喂食器周期性直接给范围内猫投喂”的交互。加成由**实际进食**取得，不是只要进入设施范围就自动生效；手动拖入不再是投喂的必要步骤。玩家的重复劳动集中在补粮，工人接手补粮；猫咪自主觅食不需要新增搬猫投喂岗位。

喂食不等于收割，不自动清空毛层或结算毛球。巨型猫高产、依赖粮食、进食吃部分蟑螂的已有设定保留；转化和吃虫随实际进食衔接。

**仍待细化：**buff具体秒数与倍率、每次耗粮、进食耗时、搜索范围与多设备择优、拥挤与目标中途缺粮处理、设施中猫的觅食优先级。没有可用食物时不能凭空获得buff；继续正常活动并等待有粮目标为处理建议，不在本次规定饥饿停产。buff怎样作用于已有／新生毛层仍待D01明确；此前提出“只加成buff期间生长的毛量”是建议，不在本次自动定为结算规则。

本轮已实装自动觅食；试玩暂取进食1秒、buff11秒、每次1份、全场最近有粮目标，缺粮重选，无粮闲逛，不抢占设施。仍不将这些细节自动确认为正式参数。具体实现同步至[17_数值总表](17_Demo数值总表与调参清单.md)第12节。

## 每个设施带来的额外工作

| 设施 | 新增劳动与影响 |
| --- | --- |
| 喂食器 | 需要购买猫粮并补粮；巨型猫更依赖粮食供应 |
| 日光浴 | 需要把合适的猫送入；第一阶段无虫害，第二阶段场上已有日光浴时才开启喂食器虫害风险 |
| 娱乐设施 | 需要安排参与娱乐的猫，权衡毛球与换金道具收益 |
| 祭坛 | 后续扩展可指派猫；安装后开启信号干扰，部分娱乐设施黑屏，需要捶打维修 |

具体异常处理见[05](05_新需求与设施联动.md)，工人如何接手见[06](06_工人与职责分配.md)。

## 摆放与管理（设计提案）

购买后进入摆放预览，范围型设施显示覆盖区域；容量型设施显示已占槽位与可容纳数量。选择设施时再显示详细信息，避免全场永久浮着面板。

范围重叠、设施持有数量上限、搬迁费用、拆除是否返还以及异常是否随搬迁保留，均尚未定。不能通过默认“收起再放下即可修复”绕过补粮、清虫或维修。

## 神秘扭蛋机：连续收藏成长设施（已确认）

首次从猫咪获得神秘代币后，神秘猫形存在交付一台刻满猫图腾、正面有投币口和旋钮的外星仪器。玩家投币、转动旋钮，抽取不重复收藏，提升对应系列buff。它在场景中作为早期解锁的设施出现，不由普通娱乐设施或祭坛节点解锁。

扭蛋机当前不新增补粮、维修或工人维护需求，也未设性能升级分支；系列收集度承担其成长。第一批2套×6件收齐后补货新4套×6件，已拥有收藏不回池，原仪器持续使用，不重新激活。具体摆放方式待定，详见[13](13_神秘扭蛋与系列收藏.md)和[14](14_Demo阶段推进与内容补货.md)。
