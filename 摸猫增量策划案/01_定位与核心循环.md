# 01｜定位与核心循环

v0.26｜2026-09-18。入口：[00_索引](00_索引.md)。

## 游戏定位（已确认）

这是一款发生在空间站舱室里的多猫增量游戏。玩家直接用鼠标与场景互动，饲养具有奇妙能力的外星猫，追求更高产量、更快毛层积累和更少重复劳动。延续俯视角2D像素与全屏场景方向，不设置需要玩家操控走动的人物。

语气轻松、诙谐，设施可以荒诞，反馈要明显。当前采用普通饲养主题，已停用公司讽刺主题、猫作为消耗原料的加工产线和旧图层擦除。

## 三层循环

| 循环 | 玩家在做什么 | 为什么继续玩 |
| --- | --- | --- |
| 单次收益 | 猫长毛 → 选择立即收或继续叠层 → 抚摸收割 → 毛球自动入库 → 花钱增长 | 同一只猫越来越能产，场地内猫和工人逐渐增多 |
| 阶段成长 | 解锁设施 → 收益提高但工作增多 → 手动熟悉新操作 → 招募工人并分工 → 再解锁下一机制 | 每个阶段改变玩家要关注的事，旧劳动逐步被接手 |
| 周目成长 | 从猫咪获得代币 → 扭蛋增加系列buff → 收完当期收藏 → 开启新周目并继承加成 → 接触更多新系列 | 更快重建经营，持续发现神秘文明的收藏 |

“需求”来自玩家主动选择增量项目后需要承担的工作。不是猫按时间发布一连串必须满足的愿望，也不通过强制新增生活需求替代增量核心。

## 玩家逐渐获得的决策

| 决策 | 收益与代价 |
| --- | --- |
| 一层就收，还是多攒几层 | 立即获得升级资金，或等待更高总产出 |
| 钱花在猫、设施还是工人 | 扩大产出来源、引入新收益机制，或减少现有劳动 |
| 猫留在场地，还是送进设施 | 产毛、加速就绪、赢取道具与提供全局加速之间安排猫咪 |
| 各岗位安排几名工人 | 在补粮、收割、搬猫、清虫、维护之间分配有限执行能力 |
| 先强化现有设施，还是解锁新设施 | 提高当前循环效率，或接受下一轮新工作 |

## 拓展原则（设计提案）

每个新主体应交代“新收益、对旧机制的影响、新操作、工人如何接手”四件事。扩展不必每次新增货币或新界面；优先让旧猫种、旧设施和已有岗位出现新的使用价值。

保留玩家选择解锁节奏的空间。已解放的劳动应交由岗位承担，新瓶颈主要来自新任务和任务密度，不靠周期性撤销玩家已经购买的自动化能力。

详细生产见[02](02_产毛叠层与收割.md)，联动见[05](05_新需求与设施联动.md)，阶段节奏见[10](10_游玩流程与引导.md)。

## 长期目标（已确认）

神秘扭蛋机是长期成长中心。每次抽取必得尚未拥有的收藏，系列收集度越高，对应buff越强；当期收藏集齐后引导进入下一周目。游戏通过初次接触、收益变化与新信号促使玩家继续，不直接宣布“主线是集齐全部扭蛋”。详见[13](13_神秘扭蛋与系列收藏.md)与[14](14_周目循环与继承.md)。

## 周目的玩法变化

新周目同时提供新收藏和新操作：首轮到日光浴，第二轮引入蟑螂与娱乐，第三轮引入祭坛与信号干扰。玩家带着永久加成快速完成熟悉部分，再面对新的劳动瓶颈并交给工人。原设施长流程因此分摊到多轮，防止每轮只是重复相同操作、抽取更多收藏。
