## 工人是劳动自动化的主体（已确认）

毛球精灵小帮手是场景内能自主行动的外星工人。新增任务越多，玩家越需要招募更多工人，再通过职责帽把固定工作交给固定工人。不要为每项劳动增加一台全自动替代机器。

工人可接手玩家执行性操作；设备维修单独要求先购买“工人维护功能”节点。产物自动入库，不存在收集掉落物的岗位。旧精灵的所有性能数值、静电精灵体系和持有上限不直接继承。

## 岗位与执行内容

祭坛指派、维护及维护解锁保留为后续扩展，当前一小时Demo只使用其余岗位。

| 工作 | 工人执行的动作 | 条件与边界 |
| --- | --- | --- |
| 抚摸收割 | 找到达到升级目标层数的猫，完成随层数增加的互动，结算后进入工作CD | 初始门槛1层；CD结束后再开始下一轮，产物自动入库 |
| 补粮 | 将可用猫粮补入喂食器 | 商店解锁与采购是独立步骤；代购预算待定 |
| 日光浴搬运 | 把符合条件的CD猫送入有空位的区域 | 猫就绪后自行离开；不额外创建出区搬运工作 |
| 娱乐设施安排 | 将选定的猫送入娱乐设施 | 不自行占用玩家指定留在其他岗位的猫 |
| 祭坛指派 | 执行玩家给出的祭坛猫咪安排 | 祭坛容量与猫的其他占用需一致 |
| 清虫 | 处理存在虫害的喂食器 | 操作效果与人工清虫一致，巨型猫只能部分缓解 |
| 维护 | 捶打修复黑屏娱乐设施 | 维护节点未解锁时不能执行；解锁后仍需工人时间 |

上表明确职责范围；具体寻路、操作时长和挑选目标属于下列设计提案。

## 任务执行建议（设计提案）

**收割任务：工作CD结束 → 找到达到目标层数的猫 → 前往并完成互动 → 产出入库 → 进入工作CD → 下一轮。**

补粮、搬猫、清虫等仍执行对应岗位流程。新增产出后CD是否也影响其他岗位尚待明确，不默认让全体工人或所有任务共用一个冷却。

- 同一个维修或清虫目标默认只派一人，避免几个工人挤在同一台机器前；协作加速如需加入应另设规则。
- 目标被玩家提前完成或猫被移走时，工人取消过期任务，不重复扣粮或重复发奖励。
- 玩家可随时亲自处理任务，不必先解雇工人；同一次交互只结算一次。
- 没有目标时显示“待命”，缺猫粮时显示“缺粮”，路径不可达时显示“无法到达”，让玩家能看出工人为何停工。
- 清虫和维修工人无需玩家一直开着对应窗口；打开窗口只用于观察或接手。

## 职责帽与策略（设计提案）

给工人选一个固定岗位，界面显示各岗位人数和等待任务数。更换职责是调整现有劳动力，不自动招募新工人。

收割门槛改由“积攒层数收割”等级决定，初始1层、每级＋1层，不再把免费1—8层滑块作为新的默认规则。玩家选择是否付费升高门槛；购买后降档、重置和逐工人覆盖设置未定。搬运岗位建议提供目标设施和允许使用的猫。预算代购、跨岗位临时支援、维修优先级暂不作为已确认功能。

## 积攒层数与工作CD（2026-09-21最新确认）

| 项目 | 新规则 |
| --- | --- |
| 初始收割目标 | 1层，帮助早期反复回款；首层始终存在 |
| 层数升级 | 0级收1层，1级收2层，2级收3层，以此类推；每级只提高1层门槛 |
| 玩家选择 | 自行选择是否买下一级，不自动升级，不要求点满才能推进其他主体 |
| 与原搬运升级关系 | 替换“稳稳抱猫”等搬运性能分支，不删除工人搬猫岗位 |
| 收割互动 | 实际收割层数越高，需要的互动时间越长 |
| 产出后CD | 本工人结算一次产出后进入自己的工作CD；结束后再收割 |
| CD缩减升级 | 独立缩短工作CD，不直接改变目标层数、猫咪长毛CD或互动时长 |

目标层数作为最低可接单门槛整理，猫已经高于门槛时不丢弃多出的毛层；具体奖励按实际结算层数处理。互动开始后层数变化的锁定方式仍待定。升级最高级不能使目标超过猫可达到的毛层上限；若暂用8层上限，最多允许目标到8层，但本次不据此确定分支一定7级。

CD是否可与移动／其他岗位重叠、工作效率buff是否影响CD、目标作用于全体或单工人，以及原搬运升级的已购等级如何迁移仍待定。不能默认把旧搬运满级直接转成高层目标，导致旧存档突然停止早期回款。

本批现已试玩实装，当前运行值见17第13.3节；第12节是改前记录。未定正式参数继续保留。

## 2026-09-28｜当前目标：工人仅保留收割（待实装，覆盖前述多岗位设计）

用户确认保留工人为收割的主要解放双手途径，取消分工制度与全能能力。工人仍按既有目标层规则找猫、移动、互动、结算后进入自身CD；不是取消所有自主寻收目标，也不改为逐次点击工人才能工作。玩家保留手动收割、生产配置和设施安排的主导权。

| 项目 | 新方向 |
| --- | --- |
| 保留能力 | 仅收割；支持既有手动／工人防抢收重复结算 |
| 保留成长 | 招募路线N10、工效U11、积攒层数U12、工作CD缩减U13及仍适用于收割的既有增益；不擅自删除或重定价 |
| 取消能力 | 补粮、搬猫、娱乐／祭坛安排、清虫、维修，不再让同一收割工人兼任 |
| 取消分工 | 不再按补给／搬运／清虫／维修等岗位切换；不恢复职责帽作为解锁其他工作的方法 |
| 尚未决定 | 非收割劳动的专用替代体、旧岗位与已购帽／维修节点迁移；先保留人工入口 |

只收割的分组或目标层设置不等于多岗位分工，是否保留其现有界面需按07依赖梳理。暂停或冷却期间不能偷偷继续旧后勤岗位。更新后验证早期单层、后期攒层及混搭路线可用。
