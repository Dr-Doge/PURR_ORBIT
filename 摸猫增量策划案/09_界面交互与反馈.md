## 场景布局

沿用全屏俯视角2D像素场景与鼠标直接操作方向。空间站舱室内可见猫、工人和摆放的设施。屏幕上方用紧凑信息条显示毛球与主要提示，底部放商店、升级树、库存、分工入口。详细内容按需展开，不恢复旧常驻大侧栏挤压场地的布局。

升级树使用可拖动、缩放、纵向延伸的独立面板；商店购买实体与树上研发区别显示。具体分辨率、UI尺寸和菜单暂停规则见D11，旧效果图不作为本轮界面成品。

## 主要操作

祭坛指派、外星猫范围与黑屏维修仅用于后续内容，当前Demo不显示可操作入口。

| 玩家动作 | 操作对象 | 游戏响应 |
| --- | --- | --- |
| 鼠标在猫身上来回移动 | 悬停后停步的猫，且不在收割反应CD中 | 抚摸完成后收割，产物飞入库存提示；不需要拾取 |
| 拖动猫 | 日光浴、娱乐设施 | 送入设施，显示接受或无法放入的原因 |
| 指派猫 | 密语祭坛 | 加入可用槽位，显示全局速度增益 |
| 点击设施并补粮 | 喂食器 | 从可用猫粮中补给；购买资格与现有库存清楚区分 |
| 打开内部窗口后连续点击 | 生虫的喂食器 | 击杀蟑螂，直到清理完成 |
| 连续点击捶打设备 | 黑屏娱乐设施 | 画面恢复后恢复运行 |
| 选择工人并分配职责 | 小帮手／职责面板 | 工人执行指定类别任务；维修要求对应节点已解锁 |

拖动和抚摸的输入冲突需要原型验证。建议按住后拖动用于搬猫、无按键移动用于抚摸，避免准备搬走猫时先意外收割。

## 简单且明显的反馈（设计提案）

| 状态 | 玩家应一眼看见什么 |
| --- | --- |
| 毛层增加 | 以脚底为支点短暂膨胀后恢复，替代跳起；恢复到当前毛层对应体型，毛层越多仍越大 |
| 收割完成 | 体态变化、一次清晰收益数字与入库动效 |
| 巨型猫 | 与普通猫明显不同的体型 |
| 静电传导 | 一次范围闪光，受影响猫同步反馈 |
| 招财判定 | 清楚的抛币正反面；额外奖品与原奖励分开显示 |
| 外星猫 | 绿色轮廓、黑色大眼、球头触角，选中显示加速范围 |
| 喂食器有虫 | 设施异常标记，窗口内直接看见蟑螂与减产提示 |
| 娱乐设施故障 | 显示屏黑掉、停止奖励提示；修复后屏幕重新亮起 |
| 工人忙或无事可做 | 岗位图标和简短状态，任务积压时提示需要人手 |

强反馈聚焦整体体态、颜色与同步变化；不为每层毛加入大量细碎动画。猫群规模增长后，合并同一时段收益数字，选中对象再展示细节。

面板操作不应穿透到场景。自动入库不代表自动出售；库存内的出售流程需要明确确认数量，神秘扭蛋机从场景设施进入，使用本轮独立收藏展示，不沿用旧代币扭蛋参数。

## 神秘接触与扭蛋界面（规则＋表现提案）

首枚代币已入库时突出其图案，触发猫咪形象存在交付仪器。仪器在场景中具有猫图腾、投币口与旋钮；点击后可投币并转动旋钮。交付与形态为已确认设定，具体镜头、拖转手势与演出时长为提案。

首抽后展示“获得了什么”“所属系列收集度如何变化”“具体加成提高多少”，随后回到场景感受收益。收藏页区分当前批次可抽系列、已得系列与尚未开放的神秘轮廓；信息组织为设计提案。

第一批12件收齐后补入第二批24件，提示新信号，不出现重启确认或清零清单。原扭蛋机持续使用，补货不自动消费下一枚代币。第二批抽空后禁用投币且不扣币，建议允许继续经营。界面能显示收集进度，但不采用“主线：集齐全部扭蛋”的任务宣告。

## 阶段内容预告（设计提案）

第一阶段树和商店中的娱乐设施显示“首批收藏完成后开放”，与缺钱、缺研究前置区分；第二阶段在原场地开放资格，既有节点和等级保留。后续祭坛等如需预告，标为“后续内容”，不显示可购买按钮或第三周目入口。

收藏界面显示本批x／12、随后x／24，以及累计x／36。第一批已完成套装继续陈列，第二批计数归零不代表失去旧收藏。首遇只播一次，新批次不用再交付或重新激活仪器。

## 008｜鼠标悬停让猫停步（已实装）

## 2026-09-23｜抚摸反馈改版（待实装；具体表现为提案）

**已确认方向：**限定猫身区域来回移动的输入保留；替换围住猫体、抢占视线的圆环式抚摸进度表现；增加明显脱手容错；猫咪视觉与动画差异是改版重点。此前单击收割提案不采用。

| 交互阶段 | 建议表现 | 保持的边界 |
| --- | --- | --- |
| 指向猫 | 轻量目标提示，猫身完整可见 | 不用大圈覆盖体态，不悬停即产出 |

| 进度积累 | 动作逐渐有蓄势感；脚下短横条作为准确进度辅助 | 位置／样式是提案；不固定百分比数字压住猫，不为每猫常驻整套UI |
| 短暂脱手 | 体态逐渐恢复，进度在容错窗口内保持，辅助条淡显 | 收回视觉姿态不等于清空数据，返回继续原进度 |
| 收割完成 | 一次明确体态释放、毛团喷出、收益数字与入库反馈同步 | 一个真实结算对应一次奖励表现，不按鼠标事件无限堆特效 |
| 反应冷却 | 保留produce表演，结束后回到可抚摸状态 | 自然长毛、抚摸、产出三个状态可辨；纯视觉变体不增加禁收时间 |

反馈丰富不等于一直全屏闪烁。主反馈落在当前猫身体，背景工人的产出简化；收益数字可合并，毛团／音效做数量上限。脚下条避让、屏幕边缘与遮挡、多猫未完成进度的显示范围需原型核验。原美术资产保留，新增变体不代表已有动画要全部重做。
