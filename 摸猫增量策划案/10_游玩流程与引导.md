# 10｜游玩流程与引导

v0.26｜2026-09-18。入口：[00_索引](00_索引.md)。

## 用户指定的跨周目体验顺序

**工人 → 喂食器 → 猫粮分支 → 喂食器转化 → 日光浴 → 日光浴转化 → 蟑螂危机 → 工作分配 → 娱乐设施 → 娱乐设施转化 → 密语祭坛 → 密语祭坛转化。**

第三周目的祭坛段另有已确认联动：安装祭坛 → 娱乐设施黑屏 → 手动捶打恢复 → 工人维护解锁 → 分工维修。

顺序跨三个周目逐段开放，不再是一周目内的完整流程：第一周目止于日光浴；第二周目增加蟑螂与娱乐；第三周目增加祭坛与信号干扰。各段内顺序仍是体验指引，不自动等于每个节点的硬性前置；转化成功不作为推进条件。事件还需满足对应周目、设施安装和原触发条件。

早期另有一条长期目标引导：**首枚猫咪代币 → 神秘存在交付仪器 → 首抽获得系列buff → 带着收益变化返回经营。**它与局内设施顺序并行，不排在祭坛之后。

## 从开局到多系统运转

下表列出跨周目的完整阶段，不要求首轮体验全部。第一周目覆盖开局至日光浴，第二周目重点是蟑螂、工作分配与娱乐，第三周目重点是祭坛及维护；转化分支的具体逐轮等级待定。“引导方式”为设计提案。

| 阶段 | 玩家面对什么 | 获得的突破 | 引导方式 |
| --- | --- | --- | --- |
| 开局 | 猫长好第一层，玩家急需启动资金 | 抚摸收割，快速看到毛球入账 | 直接突出可收猫与鼠标动作，不先弹长篇教学 |
| 工人 | 反复收割开始重复 | 首个小帮手接手操作 | 让玩家看见工人完成一轮，再解释招募更多的价值 |
| 喂食器 | 想让一次收割得到更多 | 喂食范围增产 | 首次补粮与产出变化一起展示 |
| 猫粮分支 | 想进一步提高设施收益 | 解锁、购买不同效果的猫粮 | 清楚区分树上解锁与商店购买 |
| 喂食器转化 | 希望获得巨型猫 | 转化几率提升，巨型猫高产；第二周目出现虫害后才用到吃虫能力 | 先说明概率，不承诺买节点立即变猫 |
| 日光浴 | 等待毛层CD成为关注点 | 将CD猫送入区域并等待就绪 | 只引导一只猫完成进入、停留、离开 |
| 日光浴转化 | 猫群开始值得集中安排 | 静电猫带动范围产出 | 用一次清楚范围反馈展示能力；未转化也可继续 |
| 蟑螂危机 | 喂食器不再增产且发生减产 | 打开窗口连点清虫，巨型猫部分缓解 | 指向受影响的旧设施，让玩家理解问题来源 |
| 工作分配 | 收割、补粮、搬猫、清虫争抢人手 | 更多工人＋职责帽固定岗位 | 先安排一个清虫或补粮岗位，再开放自由分配 |
| 娱乐设施 | 毛球之外需要更高价值收益 | 用部分猫的产毛时间换道具 | 提醒被占用猫暂停产毛，奖励自动入库 |
| 娱乐设施转化 | 希望产物带出更多附加收益 | 招财猫正面额外给换金道具 | 抛币时同时保留原奖励反馈 |
| 密语祭坛 | 希望整个场地运转更快 | 指派猫提供全局加速 | 同时说明会干扰娱乐设备，黑屏可捶打恢复 |
| 密语祭坛转化与维护 | 想进一步提速，也需管理故障 | 外星猫局部加速；解锁工人维护接手维修 | 两条方向分别提示，不将转化设为维修前置 |

## 叠层策略何时教

初次收割教“长好可以收”，获得一小段稳定收入后教“多等几层会更多”。设计提案：选中猫时对比现在收的收益与下一层预期，帮助玩家自己发现等待收益，不用强制把全场猫锁住等待。

工人可减少重复操作，但不能把玩家想攒层的猫全部提前收掉；目标层策略与引导一同验证。

## 如何判断节奏有效（设计提案）

每个阶段观察：玩家能否说清新增收益，能否找到新问题，能否自己完成处理，能否看见工人接手后的空闲。按这些结果调整价格与间隔，不先把整段流程写死为固定分钟数。

## 从第一周目走向下一周目

| 时间点 | 已确认体验 | 引导提案 |
| --- | --- | --- |
| 早期首次代币 | 接触神秘存在并获得扭蛋机 | 让首次代币足以完成一次首抽体验，避免只展示还买不起的机器 |
| 获得第一件 | 收藏和对应buff增加 | 给出简短前后收益对比，直接回场景体验 |
| 持续抽取 | 每次都得到新收藏，系列加成逐步变强 | 不靠重复品、兑换碎片或额外任务稀释目标 |
| 当期全部获得 | 半强制引导下一周目 | 奖池空、新信号出现，提供重启入口；暂留方式见14提案 |
| 第二周目开局 | 继承收藏buff，更快发展 | 精简已学教学，让玩家马上感到首轮积累的价值 |
| 再次启用仪器 | 新增更多可抽系列 | 旧收藏仍展示且生效，新收藏代表这一轮探索空间 |

本周目完成由收藏收齐判定，不额外要求所有升级满级。通过抽取费用与代币节奏让本周目已开放设施有机会被体验，不能为补足时长随意新增未确认的重开门槛。


## 每次重开的新鲜感

| 周目 | 熟悉部分怎样处理 | 本轮新教学 |
| --- | --- | --- |
| 第一周目 | 从基础收割开始建立认识 | 工人、喂食、日光浴与首次神秘接触；不教清虫或黑屏维修 |
| 第二周目 | 永久buff加快旧阶段，减少重复讲解 | 熟悉喂食器出现蟑螂，手动清虫后安排工人；新增娱乐与产毛取舍 |
| 第三周目 | 更快恢复之前经营能力 | 祭坛提供全局速度，同时干扰旧娱乐设施；捶打后解锁工人维护 |

未到对应周目，只预告后续内容，不投放该事件教学。暂留旧周目不能提前购买下一周目设施，收完当期收藏后的重开因此同时提供新的玩法与新系列。


## 两小时Demo的后续校准

用户新增约2小时目标。当前数值诊断、dc价格结构参考及周目分配建议见[16_数值与节奏分析](16_两小时Demo数值与周目节奏分析.md)。其中30／40／50分钟、节点扩充、有效生产贡献与收藏池规模均属提案，尚未替换当前Demo；主体周目资格、工人接手劳动及不要求旁支满级的规则不变。
