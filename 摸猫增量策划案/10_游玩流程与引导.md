## 一段连续经营

**抚摸与攒层 → 工人 → 喂食器 → 猫粮与巨型转化 → 日光浴与静电转化 → 首批收藏收齐、仪器补货 → 蟑螂 → 工作分配 → 娱乐与招财转化 → 全部36件收齐。**

早期并行引导：首枚代币 → 神秘接触 → 仪器首抽 → 加成回到经营。它不排在其他设施之后。设施顺序用于引导、前置和定价设计，不要求每条旁支满级，也不要求随机转化必定成功。

## 一小时体验预算（设计提案）

| 累计时间 | 玩家关注的变化 | 要产生的体验 |
| --- | --- | --- |
| 0—3分钟 | 收第一层、首枚代币和首抽、第一位工人 | 看懂赚钱和收藏加成，开始摆脱反复抚摸 |
| 3—10分钟 | 猫数增长、喂食器、首次补粮和猫粮选择 | 收益明显上涨，同时需要新的照料操作 |
| 10—18分钟 | 日光浴、搬猫、叠层收益与转化分支 | 学会等一等、合理安排猫，看到工人接手搬运 |
| 18—25分钟 | 稳定生产、补强短板、完成首批12件 | 有效升级持续可买；没有无事可做的等币尾段 |
| 约25分钟 | 新信号和第二批补货 | 原场地原样保留，新增24件与第二阶段资格 |
| 25—33分钟 | 旧喂食器出现虫害、手动清虫、职责帽 | 先看懂减产和处理方式，再用工人解决任务冲突 |
| 33—43分钟 | 娱乐设施、放入猫、首次中奖和卖出 | 理解部分产毛能力换取道具收益；招财转化非硬门槛 |
| 43—53分钟 | 娱乐分支、猫群规模、岗位与攒层策略 | 通过配置改进继续加速，旧系统仍有投资价值 |
| 53—60分钟 | 补齐剩余收藏、完成最后一套 | 成果展示；若已经没有新选择则应提早完成，不硬拖至60分钟 |

快玩家可以提前补货，慢玩家可以晚于25分钟；后段引导按实际阶段触发，不按墙上时间强行投放。

## 怎样教而不打断经营

开局先突出一只可收的猫与鼠标动作；玩家得到资金后再显示“多攒几层赚更多”的对比。工人完成一次可见操作后再解释岗位，不在首屏倾倒全部系统。

第一阶段不出现清虫教学；第二阶段的首次风险从有效条件开始计时，不把第一阶段的未清理时间带成满场虫害。给一次容易理解的清虫体验，再让招工与分工成为可负担的选择。职责帽的具体前置仍是提案，不能用强制等故障反复发生填时长。

娱乐场景突出“在里面不长毛”“中奖自动入库”“出售另操作”；不能把新的神秘代币解释成招财抛币奖励。低概率转化未发生时仍能正常经营和推进收藏。

## 补货与结束

第12件是补货条件，原猫、工人、设施、研究、资源与buff继续保留，不显示重开确认或清零清单。建议只弹简短新信号，开放第二批24件，随后回到原场景。没有重新交付仪器或重学前段的流程。

第36件完成Demo收藏，建议允许继续经营；祭坛、外星猫及维修留作后续预告。界面不必直说“集齐扭蛋是主线”，但要让玩家看懂剩余收藏和每件的效果。

## 2026-09-21早期回款流程调整（待实装）

猫从开局就有第一层，小帮手初始也按1层门槛收割。先让玩家感受到“互动产出→工人CD→再次产出”的持续回款，再介绍两条自选投资：升级积攒层数，提高单次收益但延后回款；缩减工人CD，提高执行频率。毛层更多时互动也更久，不将层数升级描述成没有代价的纯增产。
