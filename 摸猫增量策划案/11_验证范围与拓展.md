## 核心验收

| 检查场景 | 新版应得到的结果 |
| --- | --- |
| 同条件等待多层与多次收一层 | 各层同CD，多层收益显著更高；不收割不变成库存货币 |
| 人工／工人收割与娱乐结算 | 单次入库，无拾取岗位；出售独立 |
| 第一批还有1件未得 | 第二批不可抽，无需点满性能分支 |
| 获得第12件 | 首批完整保留，补入24件新收藏；无重复抽取，不顺带扣下一抽的币 |
| 补货前后对比 | 猫、工人、设施、研究、资源、代币、毛层、CD和岗位不重置；不重复发开局物资 |
| 收藏加成前后对比 | 首批buff持续生效，不因补货再乘一次；新增收藏只增加自身效果 |
| 补货中退出／读档／重复输入 | 不重复补货、扣费或发奖；阶段与收藏进度一致 |
| 首阶段已装日光浴 | 首阶段无虫；进入第二阶段后原设施直接满足安装条件，不要求重装 |
| 第二阶段尚无日光浴 | 不触发这一来源的虫害；实际安装后才开放风险 |
| 首次进入第二阶段 | 新虫害计时从资格满足后开始为实现建议；不追算首阶段未打理时间 |
| 虫害与处理 | 取消喂食增益并减产；手动可清，巨型只吃部分，工人可接手 |
| 娱乐及招财反面 | 娱乐猫暂停长毛，中奖入库；招财反面不吞原奖励、不发代币 |
| 猫、工人和设备规模增长 | 收益、补粮压力与工人吞吐共同可观察，工人不会破坏攒层策略 |
| 收藏或节点已有足够资金 | 不提前开放第二阶段设施；特殊转化不越过来源设施范围 |
| 第36件及之后 | 收藏完成，建议保留场景经营；空池不扣币、不暗开第三批、不强制周目 |
| 后续内容预告 | 祭坛与维修不能在本Demo付费购买，也不能成为完成条件 |

## 时长如何验证

分别记录首工人、首币、喂食、日光浴、首批完成、首虫害、职责分工、首台娱乐、首次出售与最后一件的累计时点。同时记录净收入、币速、每种收藏加成和工人任务积压。

对比完整经营、只买猫、不购买、先娱乐、先工人、单层收割与攒层等策略，避免主要设施反而拖慢收藏。允许主动舍弃支路，不通过强制建齐或点满树修补经济问题。

25＋35分钟只是预算。先以6—10名首次玩家观察理解和疲劳，再扩样本估计时长；约50—70分钟可作首轮调参观察区间，不是已验证结果或硬性门槛。离开窗口的时间单独记录，不用挂机凑够一小时。
