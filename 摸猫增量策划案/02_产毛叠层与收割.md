# 02｜产毛叠层与收割

v0.27｜2026-09-18。入口：[00_索引](00_索引.md)。

## 已确认的生产规则

| 环节 | 规则 | 玩家理解 |
| --- | --- | --- |
| 长一层毛 | 参与产毛的猫经过一次生产CD，增加一层毛 | 等一会儿就有毛可收 |
| 继续等待 | 不收割时继续按同样的CD积累下一层；相同增益条件下不会越长越慢 | 可以继续攒，不必长好就收 |
| 叠层增益 | 每增加一层都有额外产物比例加成；多层一次收割应远高于等时长多次收一层 | 等待能换来更高总收益 |
| 收割 | 玩家通过抚摸交互收割，也可交给工人执行；猫咪行走中同样可以收割 | 不必等猫停下来 |
| 入库 | 已结算毛球与其他产物自动入库 | 不需要捡地上的掉落物 |

开局预期为反复收第一层，尽快赚到启动资金；增长后，玩家才有条件安排一部分猫积累更多毛层。等待收益强，并不意味着开局必须等待很久才能购买第一项升级。

## 行走与新增毛层反馈（用户已确认）

猫咪自身只有毛层积累CD，没有行走CD。自主移动与长毛、抚摸收割彼此独立；有已完成毛层时，猫咪行走途中也能直接收割。抚摸不让猫停下，收割不强制改道或附加等待；到达移动目标后即可选择下个目标。

每新增一层毛发，以短暂膨胀后恢复大小作反馈，替代轻微跳起；膨胀以脚底为支点。动画结束后恢复到**当前毛层对应的体型**，保留毛层越多体型越大的机制，不退回无毛层大小。动画本身不阻挡收割或继续行走。

## 鼠标交互（沿用方向与补充提案）

沿用在猫身上来回移动鼠标的抚摸动作。单次收割需要多少有效移动、是否允许中断后继续，尚待试手感。设计提案：猫在可收割时给出清晰外形变化，玩家开始抚摸后显示简短进度反馈，完成后只结算一次。

一次结算后是否清空全部层、未完成的下一层CD是否保留，属于D01待定，不在本轮假定。工人使用相同收割规则，不能凭空额外产一份。

## 增益来自哪里

祭坛和外星猫的设定保留为后续扩展，不计入当前一小时Demo的生产来源。

| 来源 | 已确定的影响 | 尚不能默认的结果 |
| --- | --- | --- |
| 高能喂食器与巨型猫 | 增加产物数量 | 喂食后是否永久锁定已长毛层的加成 |
| 日光浴 | 拖入CD猫，停留至产物就绪并自行离开 | 是否立即长一层、代收已有毛层或经过独立处理时间 |
| 密语祭坛 | 比例提高全局生产速度 | 是否加快工人移动、维修和娱乐轮次 |
| 外星猫 | 缩短周围猫咪的毛层生产CD | 多只外星猫加速的叠加方法 |
| 静电猫 | 自身产毛时带动附近其他猫产出一次 | 是否增长层数、结算存量或直接额外发产物 |

## 事件要区分（设计提案）

区分“长出一层”“开始收割”“完成产物结算”“产生附加奖励”，便于确定静电、招财和转化各在何时发生。不能因为每长一层就自动发钱而取消收割，也不能让附加奖励无穷触发下一次奖励。

目标层数收割是工人策略提案：玩家可选择尽快回款或等待指定层数，由工人照办。它尚未成为用户确认的正式分支，见[06](06_工人与职责分配.md)。

毛层上限、公式、特殊效果的结算顺序集中见[08](08_资源经济与数值框架.md)及[12](12_待定决策与变更.md)。

## 与神秘代币的联系

猫咪是神秘代币的来源，首枚代币触发早期接触。具体按毛层、收割次数、时间或其他事件判定尚未确定；不能默认攒一层或多层就一定获得代币。人工和工人是否同概率、静电及附加奖励能否参与代币判定见D15。产物仍自动入库。
