# 《桌上开箱》基础玩法 Demo

这是根据 `docs/策划案/` 构建的 Godot 4.7.1 三维白盒纵向切片。

## 当前包含

- 7 个游戏日与每日市场新闻、价格波动、日终推进和最终资产结算。
- 16:9 固定桌面视角；桌面、背景墙、拆箱垫与回收告示牌由 CSG 白盒构建。
- 快递盒可不限量按 ¥1 购买；快递盒和盲盒都会作为刚体落下、碰撞并散落在桌面上。
- 点击未拆盒进入详细查看；未开盒状态保持固定视角，不参与拖动旋转。
- 封条环绕盒盖与盒体的接缝，上下滚动鼠标滚轮即可连续推进撕开进度；整体键程提升至原先约 10 倍。
- 快递盒上下两面各有独立封条与盒盖：先开上盖，自动翻面后再开下盖；四块侧壁随后保持原面积，以连接边为轴折成约 10°/170° 的扁平平行四边形并回到桌面。
- 高级盲盒拥有更长的多圈封条，需要更多次滚轮操作；撕完后会自动开盖并立即弹出内容物。
- 内容物以较小的黑色剪影流畅弹出、落到画面中心后显色，并播放缓慢旋转、渐隐渐亮的圆形放射光晕。
- 光晕依次为白、绿、蓝、紫、金、彩虹，对应常见、少见、稀有、史诗、传说、隐藏；它作为固定的屏幕背景独立存在，不随内容物模型旋转。
- `肥嘟嘟伙伴`、`LADUDU 精灵怪`、`夜班小队`、`泪包宝贝`、`星港机修铺` 五档盲盒；内容物名称、数量、稀有度、概率与价值均以 `13_盲盒系列图鉴.md` 的明细表为准。
- 五个系列分别包含 4、5、6、7、9 件可开出内容物；每件拥有独立万分比权重，购买时锁定具体结果。
- 系列价格与解锁门槛均为 `10 / 100 / 1,000 / 10,000 / 100,000`；少见档保本、稀有档锚定 10 倍盒价，配对系列史诗档为 50 倍，隐藏单件爆率低于 1%。
- 开完的空盒留在桌面；将它推出任意桌边并落到桌下即可自动结算回收。
- 快递空盒基础回收价为 ¥2–3，盲盒空盒为 ¥1；未拆盒意外掉落会被送回桌面。
- 内容物拥有独立鉴赏界面，可自由旋转，并显示名称、品级、所属系列、概率与当前市价。
- 必须选择按市价直接出售或保留库存，才会返回主桌面。
- 藏品持有/出售、库存总价值、31 格开盒藏品收藏册和首次发现奖励。
- 日期可无限推进，不再存在七日结束限制；日切只更新市场与流程事件。
- 不再提供阶段性 Demo 资金补助，高级系列完全依靠经营收入解锁。
- 幸运度使用一个整体升级按钮，总共可购买 15 次；费用按 ¥50、¥100、¥1,000、¥5,000、¥10,000 起步并继续按数量级增长，避免单次稀有结果连续买空多级升级。
- 五个系列的吸收速度不同：盲盒 1—5 分别在整体升级第 5、10、15、20、25 次达到最终概率。
- 同一次整体幸运升级对不同系列的概率改变量不同；概率峰值会逐渐由常见档向该系列实际拥有的高级档移动。
- 升级栏只显示整体升级和五个系列的吸收进度；具体概率改到拿起盲盒时显示。
- 聚焦盲盒后，右侧会按图鉴逐件展示该系列全部内容物的名称、稀有度、当前概率和当前售价；不再创建微型 3D 子视口，避免影响主场景曝光和生成位置。
- 快递拆箱也拥有独立熟练度，累计处理 10、30、60、100、150 个快递盒升级，并提高空盒回收收益。
- 右上角新增“行情”入口；内容物按系列陈列，点击图标可查看以日期为横轴、市价为纵轴的历史曲线。
- 今日行情改为玩家正对墙面上的长条发光显示器；两条文本以连续世界坐标位移组成无缝跑马灯，不再按字符跳动。
- 左侧购买栏限制在屏幕内，内容超高时可使用鼠标滚轮和滚动条浏览。
- 空盒解除拖动时会强制唤醒刚体并给予向下速度，越过桌边后不会再悬空等待碰撞。
- 回收结算时会在掉落位置弹出绿色收入浮字。
- 三个盲盒系列分别积累熟练度，累计开盒 5、15、30、50、80 次升至对应等级，最高 5 级。
- 每级熟练度使对应系列所有藏品的市价增加 12%，满级累计增加 60%。

## 操作

1. 点击桌面上散落的未拆盒，将它拿到眼前。
2. 上下滚动鼠标滚轮，逐段撕开环绕盒盖接缝的黄色封条。
3. 快递盒会依次打开上盖、翻面、打开下盖，再自动压扁回到桌面。
4. 盲盒封条撕完后盒盖自动弹开，内容物同时以剪影形式弹出并落定。
5. 内容物落定后可自由旋转查看，再选择出售或保留。
6. 回到桌面后，按住空盒推出任意桌边，让它自然掉到桌下。
7. 左侧购买盒子和推进日期；右上角打开库存与收藏册。

用 Godot 4.7.1 打开项目并运行即可。
