# 03｜摊位陈列与顾客系统

## 当前 Demo：角色池与可视客流（2026-09-07）

- 五类顾客（穷学生、普通爱好者、补全党、土豪父母、收藏家）各使用三款独立角色资产，分类之间不复用。
- 上班族、休闲游客、街坊长者使用独立的九款纯路人资产，绝不被选中为购买顾客。装机店老板另有专用资产。
- 同时在街上出现的角色避免使用相同模型。普通爱好者仍为主要的潜在购买顾客。
- 初始街道最多三名流动行人；每次摊位位置升级增加三人的上限，同时缩短入场间隔，安全上限为二十二人。19:00 后继续逐渐减少入场。
- 双向客流分开行进，中间区域用于绕行；检查人物间距，遇到阻挡侧向变道，无法安全通过时停步等待。进店与离店同样参与避让。
- 模型池配置：`scripts/stall_demo/city_pedestrian.gd` 中的 `MODEL_POOLS`。

## 摊位空间

固定桌面被划分为三个功能区：

1. **陈列区**：靠近顾客的一侧，包含有明确吸附点的货架、展示台或桌垫。
2. **操作区**：桌面中部，用于放置和开启盲盒、查看内容物。
3. **设备区**：桌面边缘，放置手机、包装、特殊展示盒和装饰。

陈列区使用插槽逻辑而非完全自由堆放，以保证顾客能够寻路、拿取，玩家也能清楚识别售价与空位。模型仍以实体形式显示，并允许不同尺寸占用 1—2 个插槽。

## 场景尺度基准

- 当前`stall_demo.tscn`中手动调整完成的桌面与`CSGAnimePedestrianStreet`大小关系，是后续场景制作的权威比例基准。
- 桌面、货架、盲盒和藏品使用摊位局部尺度；顾客、背景行人、步行路线和街道道具使用步行街局部尺度。
- 顾客与背景行人必须挂在步行街根节点下，继承其缩放和位移。禁止再用未缩放的世界坐标补偿人物高度或路线位置。
- 调整整条步行街的根节点缩放后，人物身高、脚底高度、行走范围、移动速度和顾客驻足位置应按比例同步，不改变桌面物品大小。
- 顾客站在桌前路面而非桌面上；货架商品正面朝向街道顾客一侧。

## 上架流程

1. 某款摆件首次开出时只播放新发现演出，不强制弹出定价界面；玩家可直接将其计入库存。
2. 玩家在开盒结算中点击左下角`定价上市`，或从手机库存选择上架时，才打开定价界面；同款后续上架自动沿用记住的价格。
3. 商品进入空陈列位后自动吸附、校正朝向并生成小型价格牌。
4. 顾客看中商品后弹出报价气泡；玩家完成讲价或直接接受后，顾客拿走模型，陈列位变空，现金跳字结算。

玩家可随时点击货架上的商品，打开定价卡修改当前挂牌价。新价会同步成该款今后上架的默认价；定价卡也提供“撤回库存”，便于留藏或交付任务。

收藏保护规则：首次获得的单件默认标记为“收藏保护”，不能被误上架；玩家可在详情中主动解除。重复款默认可售。

## 定价设计

首版不使用任意数字输入，采用五档：

| 档位 | 建议价倍率 | 效果 |
|---|---:|---|
| 清仓 | 0.70 | 成交快，适合回笼现金。 |
| 便宜 | 0.85 | 较高购买率。 |
| 建议价 | 1.00 | 默认平衡档。 |
| 加价 | 1.20 | 利润更高，顾客更容易犹豫。 |
| 收藏价 | 1.50 | 主要等待高预算或强偏好顾客。 |

价格牌显示实际金额，不向玩家暴露复杂公式。

## 客流生成

客流量由以下因素共同决定：

- 摊位位置等级：基础路过人数的主要来源。
- 时段：午后高峰高于上午和晚间。
- 星期与事件：周末、漫展或雨天产生不同客群。
- 摊位吸引力：陈列数量、小隐藏／大隐藏展示品、招牌、灯光和装饰。
- 拥堵上限：同一时间最多容纳一定数量顾客，避免画面混乱。

“摊位位置”是明确的升级线。升级不移动玩家主视角，而是更换桌面前方街景、招牌和客流参数，表现从偏僻角落逐渐进入主通道。

## 顾客决策流程

顾客使用可视化状态推进：

**路过 → 被摊位吸引 → 走近 → 浏览 1—3 件商品 → 看中并报价 → 玩家讲价 → 购买或离开。**

每件商品的购买吸引分由以下信息组成：

- 顾客对系列／主题的偏好。
- 商品品质类型与是否为当前缺少的收藏。
- 实际售价相对建议价的高低。
- 摊位声望与服务升级。
- 少量随机浮动，用于避免结果完全机械。

顾客看中商品时不会立即扣货，而是在商品附近弹出带金额的报价气泡。玩家点击气泡进入简化讲价界面；若暂不处理，气泡保留短暂耐心时间，超时后顾客离开。详细规则见《10_讲价与连开机制》。

购买不是简单选择全场最贵商品。顾客先筛选预算内商品，再根据偏好和性价比加权选择。

## 首版顾客类型

| 类型 | 行为 | 经营意义 |
|---|---|---|
| 路过学生 | 预算低、受便宜和可爱款吸引 | 消化常规重复款。 |
| 普通爱好者 | 预算中等、偏好某一系列 | 构成主要成交。 |
| 补全党 | 寻找指定款，愿意小幅加价 | 奖励丰富陈列。 |
| 收藏家 | 出现较少，关注小隐藏和大隐藏 | 支撑高价商品，但不能稳定刷出。 |
| 随行游客 | 受摊位外观吸引，偏好鲜艳商品 | 奖励装饰与展示升级。 |
| 穷学生 | 预算极低，常以身份为理由大砍价 | 提供幽默低价报价，也提醒玩家及时拒绝。 |
| 土豪父母 | 不熟悉系列但预算高，重视孩子是否喜欢 | 可能主动给出高于普通顾客的报价。 |

## 可读反馈

- 顾客头顶只显示短暂图标：喜欢、太贵、没有想要的、预算不足、等待报价、成交。
- 点击顾客可查看一句需求，例如“想找蓝色的精灵怪”，不显示底层概率。
- 日终报告聚合流失原因，帮助玩家调整，而不是要求实时盯住每个人。
- 售出时由顾客伸手／取货或商品飞向包装袋，避免仅用 UI 数字表示。

## 防滥用规则

- 顾客购买前锁定商品，玩家不能在付款瞬间改价。
- 极高定价不会被随机顾客无条件接受。
- 摊位吸引力存在合理上限，不能靠堆满隐藏款让客流无限增长。
- 同款铺满会降低摊位丰富度，但某些批量需求事件可暂时反转这一规则。
