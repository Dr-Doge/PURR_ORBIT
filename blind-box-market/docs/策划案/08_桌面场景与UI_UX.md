# 08｜桌面场景与 UI UX

## 设计方向

界面以“真实桌面上的工具”承载主要功能，搭配少量清晰 HUD。整体应有参考作品的轻松、直接和强反馈，但布局、视觉语言、图标与文案全部原创。

## 桌面功能区

| 区域 | 位置 | 功能 |
|---|---|---|
| 拆箱垫 | 中央 | 放置当前快递箱或盲盒，执行 3D 交互 |
| 待处理架 | 左侧 | 显示已购买且未拆封的盒子 |
| 回收框 | 左下 | 回收普通快递箱材料 |
| 市场平板 | 右侧 | 买盒、看行情、转卖未拆盒与藏品 |
| 订单夹 | 右上 | 查看、接取与交付限时订单 |
| 收藏册 | 后侧 | 查看 32 个藏品格位、配对合成与首次发现状态 |
| 日历按钮 | 画面上方 | 查看日期并结束当天 |

## 常驻 HUD

- 左上：第几天／总天数。
- 右上：当前现金和当日净变化；大数字使用紧凑缩写。
- 下方中央：当前交互提示，仅在需要时显示。
- 侧边：最多 3 个已接订单的简要进度。
- HUD 不遮挡箱体封条和向上拖动路径。

## 主要界面

### 市场

每个盒型卡片展示：

- 箱体缩略图、系列名、基准盒价与今日进货价。
- 涨跌箭头、三日趋势和主要价格原因。
- 本系列完整概率权重与每件内容的今日潜在价值。
- 隐藏／传说款价值、相对盒价倍率和其对今日盒价的贡献；配对系列额外显示“单件价与合成款价”双行。
- 已持有数量。
- “购买”按钮；持有时额外提供“转卖”入口。

### 藏品库存

- 默认按系列分组，并按常见、少见、稀有、史诗、隐藏／传说排序。
- 每项显示数量、稀有度、公开概率、基础价值、今日价和涨跌。
- 支持出售单件、出售全部重复品、跳转匹配订单。
- 配对组件显示“配对进度 x／2”或“x／3”，集齐后显示“合成”按钮与合成款预览。
- 合成确认页展示消耗清单、合成款基础价值与今日估值；合成不可逆，需二次确认。
- 传说款与合成款使用显著但短促的视觉层级，避免持续闪烁。

### 订单

- 卡片突出目标、期限、奖励、稀有度倍率和可匹配数量。
- 可交付时按钮变为高对比色。
- 过期订单淡出并在日终统一反馈。

### 日终结算

- 今日工作收入、交易收益、订单收益分栏显示。
- 库存估值涨跌与现金变化分开，避免误以为未出售涨幅已经到账。
- 同时显示完整总资产与紧凑缩写，防止百万级以后失去数量感。
- 主按钮“进入第 X 天”，危险操作前不使用同样配色。

## 交互优先级

1. 模态窗口打开时，UI 获得输入，3D 场景停止响应。
2. 无模态窗口时，鼠标射线优先检测当前箱体热点。
3. 桌面功能物件只在未进行撕封／取物时响应。
4. `Esc` 关闭最上层界面；若无界面则打开暂停菜单。

## 视觉语言

- 桌面基调：暖灰木纹、柔和环境光。
- 交互色：青绿色；上涨：偏暖橙；下跌：低饱和蓝；危险／过期：红色。
- 五档稀有度使用白、绿、蓝、紫、金红，并同时配合名称、边框层数和图标形状，不能只靠颜色区分。
- 不单靠红绿表达涨跌，同时使用箭头、正负号与文本。
- 字体至少 16 px 等效字号，主要按钮高度不低于 40 px。
- 0—999 显示完整整数；1,000 以上主界面使用 `K／M／B` 紧凑格式，悬停、确认窗口和结算页显示带千分位的完整值。
- 禁止科学计数法；涨跌百分比保留一位小数。

## 反馈层级

- 普通操作：按钮压下、轻音效、数字跳动。
- 成功拆封：纸胶声音、盒盖弹开、短镜头反馈。
- 常见／少见使用基础揭晓，稀有／史诗逐级增加灯光和价格停顿，传说与配对单件使用金红专属揭晓。
- 配对单件揭晓时增加“配对进度”提示；合成完整款时触发全屏合体演出。
- 史诗以上价格跨过 `K／M／B／T` 单位时，数字动画短暂停顿一次以强化膨胀感。
- 完成订单：订单夹盖章、奖励飞向现金栏。
- 市场大涨：早间新闻与对应卡片同步脉冲一次。

## 可访问性

- 简化拆箱模式。
- 镜头震动强度：关闭／弱／标准。
- 音量分为主音量、音乐、环境、交互四类。
- 支持窗口化与常见 16:9 分辨率；最低目标 1280×720。
- 所有关键操作提供文本提示和可重新查看的帮助页。
