# 07｜限时订单系统

## 系统目的

订单将“抽到什么”转化为短期目标，为玩家提供高额但有期限的回报，并推动其在直接出售、继续持有与继续开盒之间选择。

## 订单结构

每个订单包含：

- 订单 ID 与客户昵称。
- 需求条件。
- 数量。
- 创建日、截止日和剩余天数。
- 基础奖励、行情加成与最终奖励。
- 可匹配的库存列表。
- 状态：可接取、已接取、可交付、已完成、已过期。

## 三类 MVP 订单

### 1. 指定款订单

- 需求某个确切藏品，例如“线团猫 ×1”。
- 奖励随目标稀有度显著增长，传说款订单是全局最高回报来源。
- 只从玩家已解锁系列中生成。

### 2. 主题订单

- 接受任意满足主题标签的藏品，例如“办公主题 ×2”。
- 奖励中等，允许混合不同系列。
- 用于消耗重复的常见款与少见款。

### 3. 稀有度订单

- 接受任意稀有、史诗或传说款。
- 奖励随稀有度和市场报价放大。
- 后期出现，提供从千级直接跳向百万级的冲刺目标。

## 生成规则

- 每天早间最多新增 1 个订单。
- 订单池同时最多存在 3 个未完成订单，包含“可接取”和“已接取”状态。
- 默认期限为 2—3 天，首个教学订单期限为 3 天。
- 订单需求必须来自已解锁且当日可购买的系列。
- 指定款订单生成时，目标盒在剩余期限内至少保证有一次上架机会。
- 不连续生成相同目标，避免单一最优策略。

## 奖励公式

接取订单时保存所有合格藏品的当日报价快照。交付时使用：

`价值基准 = max（接单日报价快照, 交付日市场价）`

`订单奖励 = Σ（价值基准 × 对应奖励倍率）+ 固定奖金`

### 指定款倍率

| 目标稀有度 | 倍率 |
|---|---:|
| 常见 | 1.25 |
| 少见 | 1.40 |
| 稀有 | 1.70 |
| 史诗 | 2.25 |
| 隐藏／传说 | 3.00 |
| 配对单件 | 3.00 |
| 配对合成款 | 3.00 |

### 其他订单倍率

- 主题订单：每件 1.30 倍，再加“件数 × 当前系列基准盒价 × 0.05”。
- 稀有度订单：稀有 1.60 倍、史诗 2.00 倍、隐藏／传说 2.75 倍。
- 指定款固定奖金为目标系列基准盒价的 25%。
- 接单后锁定报价下限与倍率；市场上涨仍会继续抬高交付收益，市场下跌不会削弱订单。
- 指定款订单可以要求配对单件，也可以要求合成款；合成款订单的期限默认 3 天，避免玩家来不及合成。
- 以合成款为例：星港机神·合体基础价值 1,350,000,000，爆火上限 27,000,000,000，指定订单最高可放大至约 81,000,000,000，承担终局夸张数值爆发。

## 接取与交付

- 玩家可先查看订单再决定是否接取。
- 接取不收押金，也不占用藏品；仅把订单加入跟踪栏。
- 满足条件后可一键选择符合物品，也可手动勾选。
- 交付前展示将消耗的藏品、直接出售价值、倍率和订单额外收益。
- 交付后物品永久移除，奖励立即到账。

## 到期处理

- 每次日终递减剩余天数。
- 截止日当天仍可交付，点击结束今天后才判定过期。
- 失败无现金处罚，只显示错失收益并释放订单槽位。
- 距离到期 1 天时，桌面订单夹与 HUD 同时警示。

## 公平性

- 显示目标所在系列以及该系列完整的概率权重。
- 不生成玩家无法购买的系列订单。
- 不要求同一个传说款多件；要求合成款的订单默认期限 3 天且仅在对应系列解锁后出现。
- 配对单件订单会明示“该藏品可与配对件合成完整款”，避免玩家把组件贱卖。
- 若连续两个指定款订单失败，下一个订单强制生成主题订单。

## 验收条件

- 接单、匹配、交付、过期四条路径都能正确结束。
- 同一藏品不能同时交付给多个订单。
- 日切与读档不会重复发奖或重复扣除物品。
- 奖励始终高于交付物品在接单日的直接出售总价。
- 合成款订单的百亿级数值不会溢出、截断或错误显示；组件与合成款不能同时交付给多个订单。
