# 03｜3D 拆箱交互

## 目标

让拆箱动作具备可学习、可重复、反馈强的手感，同时避免依赖复杂布料或破坏物理。所有结果由受控进度与动画驱动，3D 模型负责呈现。

## 交互状态机

`IDLE → INSPECTING → SEAL_HOVERED → PEELING → OPEN_READY → LIFTING → REVEALED → RESOLVED`

- `IDLE`：箱体进入桌面。
- `INSPECTING`：玩家可轻微旋转观察箱体。
- `SEAL_HOVERED`：射线命中封条，封条描边并显示手形光标。
- `PEELING`：按住鼠标左键并向右拖动，累计撕开进度。
- `OPEN_READY`：封条移除，盒盖打开或松开。
- `LIFTING`：再次按住左键向上拖动，内容物逐渐离开盒体。
- `REVEALED`：物品完成亮相，显示名称、稀有度和今日价格。
- `RESOLVED`：玩家选择出售、保留或交付。

## 阶段一：寻找封条

- 封条是箱体上的独立可交互区域，碰撞层只响应交互射线。
- 鼠标悬停时提供描边、轻微抬起和短提示音。
- 首次教学可用微弱闪光提示位置；后续箱型可改变封条位置，但不能藏在相机不可见处。
- 若 5 秒未找到，提示“转动盒子寻找封条”。

## 阶段二：右滑拆封

### 输入规则

- 光标位于封条起点时按住鼠标左键开始。
- 以按下位置为原点，主要读取屏幕空间水平位移。
- 建议首版阈值：完成距离为视口宽度的 18%，垂直容差为完成距离的 35%。
- 向右有效拖动增加进度；轻微回拉不清零，只小幅回退。
- 松开后保留 80% 的当前进度，避免重复劳动造成挫败。

### 表现

- 封条末端跟随指针，主体按进度从盒面剥离。
- 进度经过缓入缓出曲线映射到预制动画。
- 25%、60%、100% 处触发纸胶拉伸声；完成时触发清脆断裂声和轻微镜头震动。
- 快递箱和盲盒使用同一逻辑，仅替换轨迹、材质与声音。

## 阶段三：上滑取物

### 输入规则

- 箱盖打开后，内容物顶部出现可抓取热点。
- 按住鼠标左键向上拖动，读取屏幕空间竖直位移。
- 建议首版阈值：完成距离为视口高度的 22%。
- 下拉只会轻微回退；松开后物品缓慢落回当前安全位置。

### 揭晓节奏

1. 进度 0%—70%：只显示包装或轮廓。
2. 进度 70%：声音降低，加入短暂停顿。
3. 进度 100%：物品吸附到展示点并转向相机。
4. 卡片依次揭示稀有度、公开概率、基础价值、今日价格与相对买入价倍率。
5. 数字从盒价快速滚动到藏品价格，史诗和隐藏款在跨数量级时增加停顿与镜头推进。
6. 配对组件额外显示“配对进度 x／N”和“集齐可合成完整款”，防止玩家误把组件当普通隐藏款贱卖。

五档稀有度均有独立颜色与音阶，但为控制工期只制作三套动画模板：常见／少见共用基础模板，稀有／史诗共用强化模板，隐藏·传说使用专属模板；配对组件沿用专属模板并叠加缺角标记。单次完整揭晓仍不超过 2.5 秒。

## 相机与旋转

- 默认固定俯视斜角，相机只做小幅跟随和反馈震动。
- 按住鼠标右键可有限旋转箱体，限制俯仰角，松开后保持角度。
- 开始撕封或取物后锁定箱体旋转，避免手势冲突。
- UI 面板打开时禁用 3D 射线输入。

## 容错与辅助

- 提供“简化拆箱”选项：长按封条自动完成撕开，长按内容物自动取出。
- 提供鼠标灵敏度和镜头震动开关。
- 可交互目标同时使用颜色、形状和光标变化，不仅依赖颜色。
- 指针离开窗口或 UI 抢占焦点时安全取消当前拖动，不改变资产状态。

## 验收条件

- 从封条悬停到揭晓，全流程无需键盘。
- 任何帧率下进度均由累计位移计算，不依赖帧数。
- 连续快速拖动、窗口失焦、半途松手不会跳过或卡死状态。
- 同一组件可配置快递箱、五个盲盒系列、五档稀有度、配对组件标记和不同封条轨迹。
- 亿级价格滚动和缩写显示不会阻塞揭晓动画或超出卡片边界；配对进度提示在 720p 下不遮挡物品。
