# 《毛球计划》美术／技美日志

记录规则：按有明确证据的制作日期记录，同一天的相关工作合并。没有可靠制作日期的内容统一放在 **2026 年 10 月 8 日补录**，用序号区分；该日期是整理日期，不代表当天制作完成。后续按实际制作日期继续追加。每条尽量说明“做了什么、怎样使用、现在是什么状态”。

## 2026年9月21日

接入短毛、巨型、静电、招财四种猫的待机、行走和产毛逐帧动画，并整理对应的动画配置。游戏根据猫的状态切换画面，脚底位置保持稳定，让行走和产毛时的猫不会明显跳动。

加入空间站背景、窗外宇宙、标题以及喂食、毛球、扭蛋机、代币等界面素材。玩家摸猫收获时会看到毛层标记和飞向界面的收获反馈；获得代币时也有对应特效。美术与原有玩法分支合并后，报告核对了素材保留和实际显示效果。

## 2026年9月22日

第一代资产画布 JominFrame 记录了绿幕视频的处理流程：从视频选取片段、抽帧、去绿背景，再用统一裁框处理整段动作；随后逐帧排除或恢复不合适的画面，预览透明动画，导出 PNG、动画配置和压缩包。这样可以从原视频追溯到最终序列，也能在不重做视频的情况下修改选帧。该工具的导出仍是候选素材，未自动接入游戏。

## 2026年9月28日

制作可在 Godot 中编辑的 3D 空间站场景，布置地面、墙面、窗户、相机和灯光，并加入墙地贴图与窗洞效果。猫和设施仍使用平面动画，通过 Sprite3D 放入 3D 场景接受光照和投影；鼠标位置会映射回原游戏坐标，使玩家看到的点击、拖动位置与实际操作一致。新增外星猫的行走和产毛序列，旧 2D 场景保留供对照。

短毛三花猫改用四向动作图集，区分侧面、向上和向下的行走与待机，并加入抚摸、舔爪、产毛画面。先后调整图集版本、向上动作尺寸、产毛播放和脚底定位，避免切换方向时大小突变或陷入地面。后续运行资源采用 `cat1new2`；动画播完仍须遵守游戏原有的收割反应时间。

## 2026年9月29日

继续调整猫的细勾边、静电猫亮边、专用补光、动作缩放和原地休息表现，让猫在浅色地面、重叠或转向时更容易辨认。补充静电猫 `Cat2new` 动作图集，同时保留 `cat1new3`、`Cat1new4` 两组三花猫候选图集；当前游戏使用 `cat1new2` 和 `Cat2new`，候选图集并未切换为运行资源。

修整空间站窗洞遮罩和浅灰色窗框内沿，使宇宙画面留在窗口内。与团队最新场景和工具合并后，补充猫咪动作、描边、移动、抚摸与窗户的渲染和自动检查；整合报告记录 7374 项检查通过。这个数字是当时的自动检查结果，不等于真人美术评审，也不表示已重新导出 Windows 执行文件。

同日建立第二代“猫咪工作室”：按“猫 → 方向参考图 → 动作 → 视频 → 处理版本 → 导出”整理多只猫的制作流程。制作时可先核对每只猫的侧面、向上、向下参考图，再查看动作所用原视频和透明帧；连贯性与位置修正先预览、确认后应用。它从第一代画布复制初始数据，之后两边独立保存；导出的动画仍需手动导入游戏并在场景中检查。

## 2026年10月8日｜无明确制作日期内容统一补录

以下项目的来源文件没有足够证据确定具体制作日，因此统一登记在整理日。序号只用于区分事项，不表示当天完成的先后顺序。

1. **猫咪概念与毛量状态实验。**本机制作了猫咪概念图、正常／长毛／最大毛量的状态表，并迭代轮廓与像素边。毛量主要用外形变大表达，避免在身体内部堆过多碎毛纹。这些文件位于本机 `Purr Orbit/output/imagegen/`，不是当前游戏运行图集。
2. **绿幕单图导出与修正。**将三花、白猫、灰刺毛、金猫的三个毛量状态分别导成绿底单图，并修正左脸颊线条伸出轮廓的问题。纯绿背景方便后续抠像，但仍需逐张检查色值、透明度和不同状态的一致性；日志没有把这批图标为已通过最终验收。
3. **第一代画布的其他迭代。**JominFrame 把参考图、视频、透明处理和导出连成可保存的节点流程，支持从已有视频重做本地处理、恢复任务和预览候选修复。节点连接决定实际输入；重新查询已有任务不等于再次提交付费生成。确切迭代日期未逐项登记，工具源码与数据位于相邻 `Gaming` 工作区，不在本 GitHub 仓库。
4. **本次文档核对。**美术日志 01—05 记录了已入库素材、素材实验和两代工具的边界；本机记录的第一代画布 49 项测试、第二代工作室 21 项测试通过。测试覆盖本地流程，不证明付费生成质量，也不证明工具导出已接入游戏。
