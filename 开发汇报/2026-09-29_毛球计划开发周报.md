# 《Purr Orbit／毛球计划》开发周报

本周主要完善了现有Demo的操作体验和场景表现，搭建了可直接演示玩法循环的测试场景。同时，针对“互动单一、成长缺少变化”的反馈，开始探索从单只猫逐步发展到多猫收割的新流程。

## 本周开发记录

| 工作内容 | 进展与结果 |
| --- | --- |
| 调整升级树与成长节奏 | 将猫咪、设施、工人和三种成长路线整合到同一张升级树；开放Demo中的现有机制，并调整升级费用与代币获取节奏，让玩家更快接触不同玩法。已完成试玩实现，最终平衡仍需真人测试。 |
| 改善摸猫反馈 | 保留鼠标来回抚摸的操作，将围住猫的大圆环改为脚下短进度条；鼠标短暂离开后，进度保留3秒，减少反复重来的挫败感。设施改为一次服务一只猫，减少集中堆叠。 |
| 修复猫咪移动与拖放问题 | 修复猫咪上下抖动、原地反复转向的问题；允许短暂重叠，持续重叠后再主动走开。拖放不再强制挪到其他位置，操作更自由。 |
| 整理场景并接入3D空间站 | 场景、界面和角色节点可以直接在编辑器中查看与调整；整合3D舱室、灯光和阴影，以3D空间搭配2D猫咪表现，作为当前默认主场景。 |
| 更新猫咪动画 | 接入新版三花猫的四向移动、待机、抚摸和舔爪等表现，并同步到正式场景与测试场景；修复素材整合中的脚底定位问题。 |
| 建立独立玩法测试场景 | 预置12只猫、2名收割工人和完整设施，可以直接测试收割、补粮、设施安排、升级和扭蛋等流程，不必每次从零开始。工人仅负责收割的新规则已在此场景验证，尚未全面迁入正式主场景。 |
| 加入猫咪人设库初版 | 测试场景中的猫拥有独立名称、关键词和诙谐简介，读档后保留身份。目前使用分类词库和离线预生成文本，尚未接入在线AI生成。 |
| 整合版本并交付可执行程序 | 最新美术与测试场景已合并并推送至Git；另导出Windows主场景版本0.27.0.16，完成启动检查，方便直接运行展示。 |
| 探索分阶段收割玩法 | 提出“近景逐根摘毛→一次摘多根→工具梳毛→房间内多猫收割”的成长方向，并讨论“毛发、毛团、毛线球”的整数兑换与升级衔接。目前为设计讨论，尚未实装，汇率和节点费用未定。 |

## 当前进展与待解决问题

当前已经具备可运行的3D主场景、更新后的猫咪动画，以及可快速展示完整经营流程的独立测试场景。最新美术整合完成497项检查，覆盖基础玩法、动画、鼠标操作和测试场景；可执行版本也已通过导出与启动检查。

下一步的重点是验证“升级是否真正改变操作体验”。现有版本仍以重复摸猫为主，新提出的分阶段收割流程尚未制作原型。近期场景与美术更新没有重新验证长期游玩节奏，不能据此认定整体时长或趣味性已经达标。

## 下一周工作安排（建议）

| 工作 | 预期产出 |
| --- | --- |
| 梳理单猫到多猫的成长流程 | 明确每一阶段的操作、升级目标和进入下一阶段的条件，避免要求所有旁支点满。 |
| 制作单猫收割原型 | 优先验证逐根摘毛、批量摘毛和工具梳毛三种形式，观察升级前后的操作差异。 |
| 配合原型制作反馈表现 | 围绕摘毛、成撮产出和整只梳理制作夸张但清楚的猫咪反应，并录制短演示片段。 |
| 试算资源兑换与升级费用 | 明确毛发、毛团、毛线球的换算规则，控制首次升级等待，检查早期投入在后期是否仍然有效。 |
| 进行小范围试玩与复盘 | 重点观察初期操作是否有趣、何时开始重复疲劳，以及玩家是否期待解锁下一种收割方式；据此决定后续接入范围。 |

下一周以小范围原型验证为主，不同时全面重做现有系统。本安排为汇报用建议，具体实装内容在方案明确后登记。
