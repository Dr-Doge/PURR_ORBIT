# 《毛球计划》技美日志

记录范围：为美术生产制作的画布工具、媒体处理、质量检查和导出流程。按日期记录，后续继续按实际日期追加。第一代画布中原记录未标明日期的迭代，本次按指定口径归入 **2026 年 9 月 24 日**。猫咪和空间站素材的制作、填入游戏另见[美术日志](毛球计划_美术日志.md)。

## 2026年9月22日

第一代资产画布 FrameStudio 建立了绿幕视频转动画素材的处理流程：上传或生成视频，选定片段，以最多 20 FPS 提取原始帧，去绿背景和绿边，再以整段统一的裁框与缩放处理透明序列。统一裁框保留动作本来的跳跃、起伏；如果每帧都单独居中，角色反而会在播放时抖动。

时间轴可对照原视频与透明帧，逐帧排除、恢复或隔帧选取，再预览透明动画。导出 PNG 序列、JSON、Godot `.tres` 和压缩包时，原始帧与选用帧分开保存，便于回溯“哪段视频、哪些帧”形成了当前版本。导出完成只代表得到候选资产，仍需在游戏中导入并检查。

## 2026年9月24日

按本次整理口径记录第一代画布的其余工具迭代：将参考图、视频、透明处理和导出组织成可保存的节点图。使用时先放入图像参考节点，再连接视频、去背景和导出节点；处理任务读取实际连线，不会随意拿项目里最近的一张图片。节点可拖动、缩放、分叉，一个视频也能送到多个处理分支，方便比较不同抠像或选帧结果。

为减少重复制作，工具保存项目、节点连接、任务 ID 与处理版本。已有视频可只重做本地去背景和导出；刷新或重启后查询已有生成任务，不等于再次提交收费生成。参考图可上传、粘贴或单独调用图像编辑；对透明帧的颜色异常、闪帧和像素稳定修正只生成候选，先对照预览再应用。复杂绿边、角色自身绿色部位或视频原有形变仍需人工逐帧检查，工具不能自动保证成品质量。

以上节点画布与后期扩展的原始记录未逐项注明制作日，9 月 24 日是本次指定的归档日期。源码、项目和媒体数据在相邻 `Gaming/tools/asset-canvas/` 与 `Gaming/output/asset-canvas/` 工作区，不在本 GitHub 仓库；使用方法和边界见[04 资产画布日志](../美术日志/04_资产画布制作日志.md)。

## 2026年9月29日

建立第二代“猫咪工作室”，把第一代自由节点图常用的猫咪流程整理成“猫 → 方向参考图 → 动作 → 视频 → 处理版本 → 导出”。制作一只猫时，先核对侧面、向上、向下的参考图，再为每个动作检查实际引用的图片、提示词和原视频；同一动作卡可回看透明处理历史和导出结果。原节点画布仍保留高级入口。

新增按猫分组的动作批量处理和质量候选。已有导出默认跳过，已有视频优先走本地处理，避免一个批量操作重复触发付费生成。连贯性候选从原片重新选真实帧，位置候选用统一画布和固定平移／缩放对齐脚底；两者都先预览，确认后再应用。候选与原导出版本绑定，旧候选不能覆盖后来改过的版本。动作改名会同步到 JSON 与 Godot 动画名，避免界面名称和导出资源不一致。

第二代从第一代复制初始数据，之后各自保存，不会自动同步；源码和数据位于相邻 `Gaming/tools/cat-studio/`、`Gaming/output/cat-studio/`。导出的动画包还需手动放入游戏并核对场景引用、透明边、方向、脚底和播放速度。完整步骤与验证范围见[05 猫咪工作室日志](../美术日志/05_猫咪工作室制作日志.md)。
