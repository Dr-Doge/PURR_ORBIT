# 猫咪动作工作室（独立新版）

双击 `启动猫咪工作室.cmd`，访问 http://127.0.0.1:8766 。

原版 `tools/asset-canvas` 与 `output/asset-canvas` 保留。新版代码在
`tools/cat-studio`，数据在 `output/cat-studio`。初始数据由 SQLite 备份和
素材文件复制得到，不通过链接共享可写文件。后续两边不会自动同步。
密钥文件没有复制；可使用既有环境变量或在新版连接设置中填写。

## 使用

1. 左侧选择猫或添加猫，上传主图。
2. 每只猫独立添加动作，可用模板或自定义描述。每个动作可选择这只猫的独立方向参考图。
3. 批量制作按猫分组逐项勾选。已有导出默认跳过，已有视频只运行本地处理。
4. 调整 / 对照将视频、修复前透明帧、最终结果放在同一个时间轴中。
   支持片段、总帧数、尺寸、抠像强度、颜色修复、像素色板、循环、播放帧率和删帧。
5. 每次本地处理保留历史结果；恢复版本会追加记录。收起动作可在角色区恢复。
6. 多动作导出为 PNG ZIP，单个动作完整素材包包含序列帧、JSON、Godot 资源和预览。

原节点画布位于 `/advanced.html`，读取新版自己的数据。
批量执行复用后端的两个任务线程；刷新或关闭网页不会取消已提交任务。
重启后不会自动重复提交收费任务，已取得任务 ID 的视频可继续查询。
费用确认列出收费任务数，不提供未经计价接口验证的金额估算。

## 验证

`python test_workflow.py`：覆盖独立参考图/提示词、跳过已完成、
本地处理分流、重复提交防护、历史恢复、方向参考图、收起恢复，以及真实视频处理和导出。
收费生成路径使用 mock 验证路由，不代表新的付费模型调用已经实测。

历史数据缺少处理前帧时，对照区会明确标注无法提供原始对照。
旧数据可能缺少视频时间映射；此时按已保存的采样帧率估算对应位置。

## 六项改进（2026-09-29）

- 角色页直接展示侧视图、向上、向下三方向。按已有名称识别方向，并可手动从完整图库重新指定。方向上传与生图独立保存，现有动作的参考连线不会被批量改写。
- 动作卡片显式显示参考图、原视频、透明处理和导出入口。原视频有独立播放器和浏览器原生播放控件，保留同步逐帧对照。
- 卡片可直接改名，生成新的当前导出包，同步 JSON / Godot 动画名；支持中文。
- OpenAI 生图 / 参考图编辑入口恢复，连接设置包含 OpenAI 密钥和图像模型。生图不自动提交视频。
- 连贯性算法重新读取所选原视频片段，提取最多20 FPS、最多约120帧的实际画面。非循环动作完整保留；循环模式按首尾姿势及速度差寻找更合适的接缝，至少保留65%片段。不会改变时间顺序，不用重复帧冒充补帧，也不能修复原片缺失的动作。重新取帧会恢复此前手动排除的源帧。
- 位置算法使用每个动作选择的基准帧，计算主体底部中心。每个动作只做一次固定平移/缩放，所有动作共享画布和容纳动作范围的缩放，保留整段跳跃和起伏。可选统一基准姿势高度，但不同姿势不应强行等高。

两类算法先输出候选，不替换当前素材；前后预览后应用，保留旧版本。
位置对齐针对所选的当前导出版本；以后从视频重新处理会生成新版本，需要再次检查或对齐。
候选基于旧导出的版本 ID；如果当前结果已被更新，应用返回409，防止覆盖较新编辑。
动画算法窗口可找回最近未应用的预览。

运行 `python test_quality.py` 验证算法、方向图上传、改名导出、候选版本隔离及真实视频处理。
