# FrameStudio 动画资产画布

本仓库保存代码快照；原工作副本的 `samples/` 媒体和本机／服务器部署配置未复制。下文提到的示例导入或部署步骤需要相应文件另行提供。

## 画布与串联改造

画布支持四向平移及负坐标摆放，连线画布按实际节点范围扩展，“适应画布”包含所有可见节点。选中节点按 Delete 或 Backspace 移除该节点和连线；文本编辑期间不触发删除。删除标记持久化，图片、视频及导出文件保留。

右键空白→Sprite Sheet 改造，节点有动作和 Image 两个输入。普通 Sprite Sheet 或改造后的 Sprite Sheet 输出可连接动作输入，任意 Image 可连接外观输入。任务使用实际连接的素材与网格参数，禁止形成循环。

普通视频节点独立创建；点击“一键生成 Sprite Sheet”才创建/复用并连接透明处理、导出两步，确认生成后自动后处理。普通“生成视频”只生成视频。已有画布连线保留。14项本地测试通过，浏览器验证负坐标、双输入连线、两种删除键及删除持久化；未提交付费任务。

视频生成节点现在可直接选择 Seedance 2.0 Mini、2.0、2.0 Fast、2.5；节点模型自动保存，提交任务时固定所选型号。未单独设置的旧节点使用连接设置中的默认型号。浏览器验证切换与刷新保存，12项本地测试通过；其他型号的实际付费生成仍待账号权限与参数验证。

本机网页版：浏览器画布 + Python/FastAPI 后端。只监听 `127.0.0.1:8765`。

双击 **启动画布.cmd**。启动脚本会检查依赖，必要时从 requirements.txt 安装，并在后台启动服务及打开浏览器。项目、任务和素材位于 `output/asset-canvas/`，不会覆盖已有 Seedance 素材。

## 已实现

- 角色项目、拖动节点、画布平移缩放、节点位置持久化。
- 上传 PNG/JPG/WebP，上传 MP4/WebM/MOV，免费载入现有金猫示例。
- GPT 图像生成与参考图编辑接口；在连接设置填写独立 OpenAI API Key 后可使用，未配置时仍可上传参考图。默认模型可修改；实际模型权限依账号而定。
- 复用 `tools/seedance/seedance.ps1` 的 API 桥接，默认 Seedance 2.0 Mini；生成前确认数量，单次提交立即保存 task ID，失败不自动重提。该桥接是已跑通的本机命令行脚本，并非伪装的 Ark CLI 调用。
- 两个后台任务并发；本地视频处理串行，防止内存同时暴涨。重启后任务标记中断；有 Seedance task ID 时支持继续查询。
- 批量生成、批量透明处理，显示真实任务状态与原始 API 用量（保存于任务记录，不伪造余额）。
- 截取时间段、1–30 FPS、64/128/256/512 像素、绿幕阈值、柔边、去绿边、往返循环、帧筛选。
- 精灵图改造：导入原版等格Sprite Sheet并预览逐帧动作；将原图、当前项目角色参考图和提示词一起提交GPT图像编辑，生成新版后切分、打包并提供原版/新版对比。支持明确列数、行数、有效帧数和FPS，无格间距；不保证AI严格保留每格动作，结果需验收。原版切帧无需API。
- Seedance生成确认框可勾选“自动去绿幕、抽帧并打包”，串联生成和本地后期。
- 整段统一裁框与固定缩放，保留原有上下位移；不会逐帧把跳跃重新“对齐到地面”。
- RGBA PNG、透明 APNG 预览、PNG 序列帧、JSON、Godot SpriteFrames `.tres` 和 ZIP。
- 原始输入和不同处理版本均保存，每个动作单独导出。

## 验收边界

抠图是可调节的颜色键算法，绿色主体需换背景或另行处理。没有自动保证肢体正确、修复 AI 形变或完美匹配原图颜色；需查看透明预览。GIF 仅作棋盘格预览，真实透明在 PNG/APNG 内。生成端未配置/未进行付费调用时，不声称已经验证账号或费用。此版本批量处理后需手动验收，不自动把新生成视频送入游戏项目。

方向目前以动作模板和独立参考项目管理；没有自动创造正确的背面或正面图像。

## 密钥

支持进程环境变量及 Windows 用户环境变量 `ARK_API_KEY` / `OPENAI_API_KEY`。网页输入仅保存在服务内存，重启需重新输入；不会返回、写入项目数据库或浏览器存储。现有 Windows 用户 ARK 密钥会自动识别。**已配置仅代表存在密钥**，不是有效性或余额检查。

- 输入/输出端口支持类型匹配的自由连线、替换输入；右键端口/连线断开。连接保存在项目，处理使用实际接入的视频，导出使用接入的透明帧。一个输出可接多个处理分支。
- 精灵图原图→改造→输出也支持连接；角色参考图目前为项目共用。
- 默认顺序提取20 FPS，无AI补帧或自动丢帧。完整 source_frames 帧库与筛选后的 frames 分开保存；固定整体裁框不因删帧变化，APNG全帧替换避免透明区域残留。
- 逐帧编辑：原视频对照、播放/暂停、上一帧/下一帧、时间轴、手动排除/恢复、隔帧保留、全部恢复。可选择保持片段时长或固定播放帧率。完整帧预加载后才播放。
- 单一示例重复打开不再复制，旧的未编辑示例副本已归档（文件保留）。既有非示例项目不会自动改变取帧参数。
- 9项本地测试通过，覆盖20FPS时序、完整帧恢复、裁框稳定、APNG图像、保持时长及真实连线的数据路由。浏览器验证左右/中键交互、右键菜单、拖动端口、帧删减即时预览。未调用付费生成。
- 提高采样帧率不能修复原片已有的重复帧、解剖错误或首尾动作不一致；仍需查看原片和选取合理的循环区间。GPT API提供生图/图像改造，不参与本地去绿幕和抽帧。

### 去绿幕易用性调整
加入温和/标准/强力预设（阈值45/25/12）、直观强度滑杆和说明。预设一键本地重处理；像素风默认不柔化。去绿染覆盖不透明与半透明像素，不再保留8级绿色偏色。含新增边缘/主体色测试共10项通过。绿色角色部位仍可能被误抠，强力不适用于所有素材。


### Image → 视频生成 → 去绿幕 → Sprite Sheet

项目支持多个独立 Image 节点。通过顶部按钮/右键添加，上传图片或在画布按 Ctrl+V 粘贴系统剪贴板中的图像文件；文本框内粘贴不截获，纯图片链接不当作图片下载。Image 支持独立 GPT Image 2 生图，按需勾选当前图片编辑参考。官方模型 ID 为 gpt-image-2，图片1024×1024 PNG，可选择自动/纯绿/透明背景（透明能力仍为预览）。节点连线决定每个 Seedance 视频任务使用哪张图片，生图不自动提交收费视频。

制作绿幕：有alpha的图片本地合成纯绿底，不改变完全不透明的主体像素；无透明区域的图片需要明确提交GPT编辑，修改后检查主体细节。旧项目主参考图迁移为主Image的界面和功能，已有文件/连线保留。原精灵图改造目前仍使用项目主Image作为外观参考。

11项隔离测试通过，新增独立图片保存、不污染其他图片、透明图绿底、API生图适配与Seedance使用实际连接图的验证。没有执行付费生成；OpenAI Key尚未配置。剪贴板粘贴的系统兼容性需要用户实际复制图片验收。流程不限定猫，适用于其他主体；绿色主体、发光、半透明或复杂背景需检查抠像结果。

官方说明：https://developers.openai.com/api/docs/models/gpt-image-2
