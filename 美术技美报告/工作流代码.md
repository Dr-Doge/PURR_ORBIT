## 目录和运行

保留了原工作区的 `tools/<工具名>/` 层级，因为两套后端都按相对路径查找 `tools/seedance/seedance.ps1`。从本目录启动时，新项目数据默认写到 `工作流代码/output/asset-canvas/` 或 `工作流代码/output/cat-studio/`；这些目录已被 Git 忽略。

在 Windows 上分别进入工具目录，运行 `启动画布.cmd` 或 `启动猫咪工作室.cmd`；默认地址为 `http://127.0.0.1:8765` 和 `http://127.0.0.1:8766`。也可以先安装各自 `requirements.txt`，再运行 `python server.py`。本地启动脚本会检查依赖，必要时尝试安装。图像和视频生成需要各自服务的 API Key；不配置时仍可使用上传和本地处理功能。**不要把密钥写入仓库。**

`cat-studio/setup_copy.py` 只用于首次从同一 `工作流代码/output/asset-canvas/` 复制数据到独立的 `output/cat-studio/`；新仓库没有原数据时无需运行。两套工具之后各自保存，不会自动同步。
