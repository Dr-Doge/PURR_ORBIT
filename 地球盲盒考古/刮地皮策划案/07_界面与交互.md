# 07｜界面与交互

## Jomin 独立模式补充 · 已确认

点数反馈复用旧 `scratch_board.gd` / `ea/board.gd` 的上浮淡出跳字：普通奖励为浅色，稀有 +10 为金色大字（普通 18、稀有 28 字号）。检查未发现独立铜币飞行/旋转动画或对应素材，当前复用的是原有点数收集反馈。

左上角增加铲子小图标和数量；当前实现显示“空闲 / 已拥有”，另列作业中、返回中数量。点击地皮后，空闲铲子从图标飞出并恢复正常大小；完成挖掘后缩小飞回图标并消失。点击飞出中或挖掘中的铲子可提前召回，立即清除该处裂纹与进度条；再次派遣从零计时。返回结束才重新计为空闲。每把铲子保留独立的圆形裂纹和小进度条，暂停同时冻结飞行和作业。

右侧旧升级列表替换为铲子数量、共享强度、共享范围三类卡片，可滚动浏览。分别显示数量或等级、下一次升级效果、价格、余额不足差额或达到上限；进度条按本任务锁定的耗时显示。旧天赋入口隐藏；库存与手动清理仍保留。此补充仅作用于 `shovel_demo.tscn`，具体参数见 [06](06_EA数值设计.md)。

## 主界面布局

**启动菜单（已确认）：**启动时先显示“开始游戏”“读取存档”“设置”，不自动继续上次进度。当前实现中，开始游戏从零开局；读取存档才恢复进度，无存档禁用读取。设置应用或取消后返回开始菜单，偏好独立保存；菜单停留及退出不保存游戏进度。进入新局后沿用自动保存规则，菜单说明后续保存将替换当前进度。

**已确认：**左侧保留挖掘窗口；右侧栏中间大部分区域为常驻道具购买与升级列表，鼠标滚轮在栏位内滚动。购买升级不再通过按钮打开新窗口。深度计移到右下角最底部，以五行紧凑堆叠。设置移入Esc菜单，点击设置后打开独立窗口UI。

| 区域 | 内容 | 布局／行为 |
| --- | --- | --- |
| 左侧主窗口 | 刮地、地层图片、废料跳字、未知土块入库提示、机器人 | 保持主要操作面积 |
| 右栏顶部 | 废料余额、库存与天赋入口、简短状态 | EA建议固定，不随升级列表滚走 |
| 右栏中部大区域 | 手动升级、机器人、分析仪、系列机器、通用机与开盒速度 | 常驻纵向滚动，卡片内直接购买 |
| 右栏最底部 | 五层深度计 | 固定锚定底部，紧凑排列，独立于升级列表 |
| Esc菜单 | 返回游戏、设置等 | 设置入口放这里，不占升级列表 |

以上区域关系按用户要求；具体尺寸为后续布局调整项。以“长列表直接浏览购买”为参考方向，不要求复制参考游戏的具体美术或尺寸。

## 常驻购买与升级栏

**EA建议：**每张卡片显示名称、当前等级、下一级真实效果、价格和购买按钮。强度项优先显示“当前适配层→升级后适配层”，再提供数值详情；遇到难挖层给出“强度不足”的明确反馈。分析仪卡片说明只提前显示系列，不揭晓具体款式。

按手动、机器人、识别、开盒自动化分组，组标题随列表正常滚动；保留滚动位置，购买后原地更新。满级项显示已满级，未解锁项显示条件，余额不足显示差额，涉及推进预留时显示预留原因，不弹出独立商店窗。

滚轮仅在鼠标位于列表矩形内时改变列表偏移；光标在地面、深度计或其他窗口时不滚动列表。列表点击与滚轮事件不穿透到挖掘，拖动滚动条不购买道具。内容不足一屏时无需滚动；屏幕较小时优先压缩装饰与卡片间距，仍保留中部滚动空间和底部深度计，最低分辨率待布局验证。

库存和天赋仍可通过入口打开，其打开方式不等于购买升级界面也弹窗。工作台打开时保存其输入焦点，不能把甩沙或抛光拖动传到背景地面。

## 右下五层深度滚轮

**已确认：**上下滚动的深度计滚轮／轮盘表现，最近五层由浅至深紧凑堆叠；一层完成后向上隐藏，新层从最下方补位。按本轮规则，达到自动收尾阈值时由系统补齐残余、结算为100%，然后退场。

**EA建议：**固定外框，条目在框内纵向移动，边缘裁切或淡出形成滚轮感；它自动显示深度，不受玩家鼠标滚轮切换。每行显示实际层号、小地皮缩略图、进度填充和百分比，图片相同也凭层号区分。当前鼠标作业层高亮，最浅未完成层保留基准标记。不显示该层古物系列，也不默认把层数解释成米数。

“最近五层”沿用 [02](02_地层挖掘与掉落.md) 的活动层建议。进度为本层面积清除比例；真实原始值达到 [06](06_EA数值设计.md) 阈值后清尾跳100%，不是把显示舍入值作为逻辑条件。

| 时刻 | 从上到下五行 | 行为 |
| --- | --- | --- |
| 接近完成 | 21层97.9%、22层42%、23层8%、24层0%、25层0% | 保持各层实际状态 |
| 21层触发收尾 | 21层100%、22层42%、23层8%、24层0%、25层0% | 自动清残余、结算掉落、开始上滚 |
| 补位后 | 22层42%、23层8%、24层0%、25层0%、26层0% | 保留已有进度，26层从底边进入 |

示例数字仅说明状态。补层不重置机器人平面位置或库存工序；显示动画不阻塞逻辑。连续完成多个顶层时逐层结算、合并滚动，边缘裁切保证最多可见五行。降低动态效果时直接补位或淡切；读档恢复稳定五行，不重放奖励或历史动画。

## 未知库存与三阶段工作台

无分析仪时未清理物统一放入“未知土块”，无系列标签、系列筛选、真实款式缩略图或精确市价提示。分析仪购买后可显示潜在系列，具体款式仍未知；第二阶段鉴定后才显示真实藏品并登记，详见 [03](03_古物清理与收藏.md)。

工作台按顺序显示“连点剥土 → 按住来回甩沙 → 可选擦拭抛光”。阶段进度单独呈现，每步完成显示加价反馈；前两步之间可提示继续，有工序衔接天赋时自动切换工具。第二步结束明确提供“保留／出售／继续抛光”，不把可选步骤包装成未完成错误。

甩沙模式提示“按住古物并来回移动”，静止不涨进度；抛光模式提示“按住拖动擦除表面污渍”。未知阶段只显示基础市价的加价比例，鉴定后显示当前准确售价、抛光后售价与差额。估值反馈不能伪装成废料已入账。

## Esc菜单与设置窗口

**已确认：**新增Esc菜单，将“设置”放入其中，点击后打开新窗口UI。

以下为 **EA建议**：

- 在主游戏或工作台按Esc打开暂停菜单，暂停挖掘、机器人及开盒机器并保留当前工序；松开所有正在抓取/刮除的输入状态，恢复时不沿用旧按住动作。
- 菜单提供“返回游戏”“设置”“保存并退出”。设置打开独立模态窗口，游戏保持暂停；包含音量、显示、输入辅助、降低动态效果及保存/读取等设置页项，具体设置清单后续完善。
- 设置窗口内Esc或关闭按钮只关闭设置、返回Esc菜单；菜单内Esc或返回游戏才恢复。未保存的设置按明确的应用/取消处理，不能因为关窗误退出游戏。
- 退出前保存；读取存档后重建库存、活动层与界面，保持暂停直到返回游戏。旧版存档升级策略另行验证。
- 窗口和菜单阻断背景点击与滚轮，禁止在设置时误买升级、挖地或甩沙；模态窗口内的滚动只作用于该窗口。

打开普通库存或手动清理时仍沿用EA建议：在线自动化继续，手动挖掘停止；只有显式暂停菜单停止全部模拟。右侧升级列表本来就在主界面，无所谓“打开商店时暂停”。
