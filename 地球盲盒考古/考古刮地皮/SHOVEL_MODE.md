# Jomin · 自动挖土铲子

入口：`scenes/shovel_demo.tscn`。当前分支按 F5 启动此模式，原 `ea_demo.tscn` 可按 F6 独立运行。

当前强度每级 ×1.2。点数普通随机 1～5、2% 概率金色大字 +10，使用旧版上浮淡出反馈；未发现独立铜币飞行动画。实际奖励与跳字一致，重复召回、读档不重抽奖励。

- 点击地面派遣一把空闲铲子，从左上角图标飞出并放大；抵达后计时、跳动、裂纹渐显，结束后圆形土层消失。
- 铲子挖完缩小飞回图标，然后隐藏。点击飞出中或挖掘中的铲子可提前召回，原位置裂纹和计时立即归零；返回结束才可再次派遣。已领取点数保留且不重复计奖。
- 右侧可购买更多铲子，以及全体共享的强度和范围升级。两种新升级只影响新派遣任务；旧升级、天赋购买和鉴宝机自动处理暂时停用，手动库存、鉴定、抛光保留。
- 按整个圆内最浅的残留地层选层，中心落在洞里也不能跳过上层；只有整个圆内没有上层残土，才能挖下一层。占用中的上层也会阻止越层。同层重叠部分不重复清除或计奖，继承原版出土、层百分比和清尾。
- 独立存档 `user://shovel_save.dat` 保存每把铲子的飞行、任务、已发收益、数量及全体升级等级；旧版不符合选层规则的在途任务会召回。原玩法存档不受影响。

规则归 [04](../刮地皮策划案/04_购买升级与自动化.md)，可调价格及动画参数归 [06](../刮地皮策划案/06_EA数值设计.md)，UI 归 [07](../刮地皮策划案/07_界面与交互.md)。运行参数位于 `scripts/shovel/model.gd`。

素材使用 `assets/Jomin Assets/shovel1-transparent.png` 和用户原始 `A_jomin_Crack.png`，原始铲子文件保留。

## 验证

Godot 4.7.1 下运行：

- `--headless --script res://tests/test_shovel.gd -- --test`：购买扣点、数量上限、十把并行、占用区域、去重收益、暂停、飞行/挖掘存读档、旧存档迁移及 UI。
- `--script res://tests/capture_shovel.gd -- --test`：空闲、飞出、三把并行、返回、入库、满额截图，输出至 `user://shovel_fleet_*.png`，不覆盖正式存档。
- `--headless --script res://tests/probe_shovel_income.gd`：第一层完整圆形区域收益抽样，供首版价格调优。
