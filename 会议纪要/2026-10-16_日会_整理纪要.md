# 2026-10-16（周五）毛球计划日会整理纪要

## 核心结论

- **周日版本锚定一个「5 分钟可玩原子流程」**：脏猫出现 → 玩家手动梳毛得第一桶金 → 买第一个自动设施（猫砂盆）→ 猫进设施后变脏 → 再梳得第二笔钱；在交互中可升级工具（单面梳 → 双面梳、买其他工具）。核心产出交给玩家手动操作，自动产出比例很低。周日以主场景为主，两只猫先后出场、可上手玩，可能再录一段视频。
- **梳毛美术方向定了但未达标**：从「脏乱擦除」改为**图层毛发 + 梳子交互**，大方向可行；当前问题是材质像羽毛/羽绒服绒毛、与猫本体视觉不统一、消散太轻。要**增大贴片、加描边、统一毛发朝向、消散改为下坠、梳时模型同向挤压**，并优先用**双层贴图**（底层贴图 + 上层效果）尝试；猫的拉扯/形变动画参考写实视频与《VR 宠物护理大师》。
- **机制分层（已定）**：短毛猫砍掉复杂机制（打结、工具切换等），只做「刮脏」；复杂机制（打结毛团、不同硬度的猫、工具切换）留到后续的长毛猫/新猫上，类比《刮鱼鳞》从小型鱼到深海鱼的难度递进。
- **锻造盲盒系列重构（已定）**：武器线拆成**手持系列**与**载具系列**两条独立系列，机甲移出去另作系列；定位统一为**工艺品/手办（收藏品，非真实武器）**，加底座或支架强化手办属性；补**二 D 参考图 → 锚定一个系列出原画 → 场景参考图/玩法参考图**四件事为 to-do。

## 会议要点

### 梳毛玩法改版与美术表现

- **改版成果**：ruohaojing（景若颢）把原「很脏很乱、反复擦」的梳毛改成**图层毛发 + 梳子交互**，梳下去即梳掉，认可「真的在梳一个东西」的反馈感；判定区目前只有一点，边缘仍需手动摆。
- **当前美术问题**：毛发像羽毛/羽绒服露出的绒毛，缺纹理与朝向一致性；像一层覆盖图层，无描边；精细度太高、太小，与猫本体画风割裂；离猫太远、颜色分布与猫本体无关导致突兀（后已按正下方毛色匹配）。
- **已定的改进方向**：贴片增大（宁可多刮几下）、加描边、统一毛发朝向、消散改下坠（增加重量感）、刮时所有模型向同方向挤压、地面可加掉落毛发（并做轻度/中度/重度三档脏污）、**梳子上不留毛发**（梳子有按住/不按住的交互，留毛不好）；优先保留「同样线条粗细与细节度、面积稍大 + 刮时有 stretch」。
- **双层贴图（候选，建议尝试）**：一层做类似贴图的高分段，另一层叠加效果——参考昨天讨论，方向可试。
- **参考游戏**：《VR 宠物护理大师》（操作台形式、工具切换、吸尘器/推子/驱虫药等，本质是图层操作 + 拉扯形变）；写实宠物美容视频（炸毛→顺毛两态、直接覆盖、拉扯/抖动）对细节有参考价值；另外讨论到某款「梳毛小游戏」表现太简陋、无参考价值。**拉扯/形变动画被明确认为比较重要，要做一点尝试。**

### 游戏机制与玩法设计

- **大逻辑（已定）**：仍是「哪里脏了梳哪里」，但有四团脏物表现诡异，应改为**打结的毛团**而非单纯美术问题。
- **差异化（已定）**：不同猫有不同处理效果——硬毛猫需快速梳、慢速梳易损坏梳子；慢速才能梳掉某些毛结（普通速度梳不掉）。
- **工具切换（已定方向）**：引入多种工具（扫帚/刷笔刷、驱虫药、镊子等），场景里放工具架、点击高亮互动，按脏污类型切换；参考《VR 宠物护理大师》的镊子为点击式。
- **分层机制（已定）**：**短毛猫砍掉复杂机制**，复杂机制（打结、硬度差异、工具切换）只在后续长毛猫/新猫上做，类比《刮鱼鳞》——初期小型鱼只有鱼鳞、一刮就掉，深海鱼才有寄生虫/藤壶等特殊处理；后续猫的任务也可更简单。

### 周日版本目标与开发计划

- **目标流程（已定）**：脏猫过来 → 梳毛得第一桶金 → 买猫砂盆（第一个自动设施）→ 猫开心、场景内移动 → 很快又跑进设施变脏 → 拖回来再梳得第二笔钱；这是一个原子单元。可在交互内升级工具（单面梳→双面梳、购买其他工具）。
- **猫变脏的表现（已定简化）**：时间不足，**不做变脏动画**，用状态切换代替（走进设施/图层后面停留片刻，出来即变脏）；但**需要保留杂乱状态的行动动画**。要设计「猫为什么会从 A 状态变 B 状态」的合理理由（走进去再出来，而非凭空变化）。
- **交付口径**：周日晚上交付，以**主场景为主**，两只猫（普通猫 + 机器猫）先后出现在编排流程里，可直接上手玩，并考虑录制视频演示。
- **分工**：主要玩法由 ruohaojing（景若颢）与 jominchen（陈则名，转写「泽明」）负责；主场景交互与相机交互以 ruohaojing 的场景为主，两人后续再商定衔接方式（一人为主、一人接）；方遥岳负责完善设计参考图。
- **压力口径**：会议明确**不要为了汇报让动作变形**，按正确方法推进，优先完成四项设计图任务；不追求在周日全部完成。

### 机器猫（第二只猫）

- 沿用**橡皮擦玩法**擦污渍，不是梳毛；有**顽固污渍需多次擦拭**；可先用除锈剂等，形成工具切换玩法。
- 可加**抛光环节**，完成后高光更多（可加图层实现，比梳毛简单）；当前高光对比不足，要更「布灵布灵」。
- 与毛团生产的结合不必强解释（它不作为游戏前期形态），擦拭后产出饱满即可。

### AI 生成资产与成本

- **生成方式**：以画布为起点，用 agent 统一调控每只猫；问题是抽卡概率仅约 20–30%，需反复试错、烧 codex 与 CD token。
- **成本**：一只猫约 **250 元人民币以上**（含 codex）；不含 codex、只算 candy 约 **六七十元**。未来若量大可申请 CD 资源降本。

### 锻造系统与盲盒系列（方遥岳汇报）

- **两条线**：冷兵器（猫条 → 猫抓棍 → 鱼骨头 → ……，参考瑞文剑/符文猫剑/亚托克斯）与现代科技（激光笔 → 逗猫球发射器 → 左轮 → 霰弹枪 → 猫雷特 → 火箭筒 → 导弹发射车 → 战斗机 → 机甲 → 核弹 → 航空母舰 → 宇宙飞船），分四个阶段/等级呈现，越到后面越夸张（剑顶大厦/塔/长城/星系）。
- **定位（已定）**：统一为**工艺品/手办（收藏品，无实际功能）**，航空母舰也按手办/模型处理（乐高式、细节少、纯色块弱化真实感）；加**底座或支架**（剑用木头背板/剑架托起）强化手办感；比例做 Q 版、更风格化。
- **系列结构（已定）**：**手持武器**一类（仍可做得很夸张：激光枪、爆弹枪、星球能量枪），**载具**一类（猫猫车 → 宇宙飞船），机甲移出去另作系列，可做约 4 个开端/8 个系列，每个系列可留隐藏款。避免「手持武器直接跳成载具」的跨度过大。
- **扩展性（已定）**：类型要砍到约 3–4 条有扩展性的线；每级都做扩展工作量太大；剑的几把之间缺明显渐进感，需补参考或删改。
- **标杆参考**：《锻剑模拟器》（转写「断剑/断电模拟器」）——25 级到 99 级外形无变化、只变名字，玩家体验会无聊，**内容释放要跟得上**；数值为失败减 100、破损减 1、维持加 0、成功加 1、大成功加 3.5，超频模式下易到约 30 级；我们的大成功若设定过高会一下到头、体验太短，需要更多模型支撑。参照 CS:GO 进化模式（越到后面越难用、最后返璞归真拿刀）。
- **美术流程（已定 to-do）**：① 补充其他系列的参考图；② 锚定一个系列出二 D 原画；③ 出场景参考图；④ 出玩法参考图。**四项不一定都要在周日完成。** 二 D 原画细节要调、复杂模型需拆分逐个生成再拼接，三 D 生产可走画布或 agent 形式。
- **场景（已定意向）**：锻造场景做**机械锻压机/液压机**形式，用罩子扣住毛团、一锤一锤砸（砸一次升一次才有视觉变化），砸完揭晓变化（纯图层即可），比三 D 打印更好做。
