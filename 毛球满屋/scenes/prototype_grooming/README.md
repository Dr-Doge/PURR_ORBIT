# 《毛球计划》双猫美容可玩Demo

引擎：Godot **4.7.1**。打开本工程，再打开 **main.tscn** 按 **F6** 运行当前场景。F5仍启动原有正式船舱版本。

本目录的三个 `*_art_preview.tscn` 仍是素材预览；`main.tscn` 才是完整服务玩法入口。

## 操作

- 按住左键拖动梳子／擦布，处理猫身可见脏污。松手后进度保留，停住不清理。
- 黄色“慢慢梳／擦”标记对应毛结／积灰，需放慢；“来回刷”对应粘附物，需两次有效处理。小幅抖动不算往复。
- 拖得过快且碰到尚未清理的污物，会出现不适反应并降低评价；在背景移动不扣评。
- 修甲时按住左键，从指甲一侧横向划到另一侧，在绿色虚线附近剪最合适。浅剪可补剪，粉红根部剪深扣评；每次手势只剪一根。
- 完成本单全部要求后自动入账并跳收益数字，无领取窗口，随后接待下一位。
- Esc／“暂停”可暂停。顶部按钮直接切到三花、机器、组合服务或修甲练习，“重试本单”重新开始当前服务。

自然顺序：三花梳理 → 机器擦拭 → 三花梳理＋修甲 → 重复。示范按钮不影响正常循环的可达性。

## 开发入口

`scripts/prototype_grooming/config.gd` 集中配置；`model.gd` 保存订单、局部清理、切深、评价和结算；`controller.gd` 处理鼠标与界面；`service_view.gd`、`foreground.gd`、`cleaning.gdshader` 显示素材、遮罩、指甲和碎屑；`assets.gd` 读取已导入资源并在内存裁取图集区域。

原型仅使用内存会话，退出清空测试钱包。正式主场景、旧测试场景、毛层系统与玩家存档不迁移。精确试玩参数及状态统一见策划17第29节。

验证入口：`tests/run_grooming_demo.ps1`。证据与限制：`reports/prototype_grooming_20261014/README.md`。本版本用于判断主交互手感，尚未做真人可玩性、长期经营数值或最终动画验收，也没有导出新EXE。
