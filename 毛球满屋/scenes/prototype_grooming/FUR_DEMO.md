# 灰白猫分层美容 Demo

Godot **4.7.1** 打开本工程，打开本目录的 **fur_demo.tscn**，按 **F6**。场景里的EditorPreview展示房间、台面和底层猫；运行后自动隐藏预览，生成真实可交互图层。F5仍进入原正式船舱。原main.tscn和旧测试场景保留。

## 怎么玩

- 按住左键沿头→尾方向轻柔向右梳，可在待处理处直接开始，不必每次回到猫头。抬起的尾巴允许向右或向上局部梳理。扫到可见身躯杂毛便整片脱落；轮廓毛需要四次交替有效梳理（两次往返）后整片掉落，同向重起和微抖不算。松手不丢进度，静止不清理。
- 梳子竖直，梳头在上、柄在下、齿面朝右；齿边旁的竖线就是作用范围，柄与梳背无效。普通猫速度上限1200逻辑像素/秒，毛结500；按1920×1080基准映射，拖动时显示当前速度，超限线变红。
- 打结毛：更慢地向右梳。灰尘：上下轻扫两个方向。跳蚤：对准它点击三次；它会小幅移动，不弹新窗口。
- 机器猫：可以快速来回擦，普通油污需要多次摩擦；积灰上下交替三次、油块左右交替四次。
- 修甲：按住横划过绿色参考线。指甲放在爪子后层，粉红根部露出；太浅可以补剪，剪深降低评价。
- 所有需求完成后跳金额、自动入账，再迎接下一位。顶部按钮可直接选择普通猫、机器猫、全套服务、修甲练习和重试；Esc暂停，声音可关闭。

正常循环：灰白猫梳理 → 机器猫擦拭 → 灰白猫梳理＋修甲 → 再循环。钱包纯内存，退出清空，不读取或修改原存档。

猫有原尺寸和宽高各半两种大小；第三单为小猫全套。顶部“尺寸”可直接切换本单大小，当前护理重新开始、钱包保留。大猫42片杂毛，小猫9片，每片始终96×72；毛片只在躯干与尾部出现，不放头部。按毛流统一朝向、小角度变化排列；工具也不随猫缩小。

## 开发与美术

新代码在scripts/prototype_grooming_fur/；继承v2的订单、修甲与结算模型，普通猫覆写为整片毛块／轮廓往返脱落／特殊需求。机器猫保留v2规则。两套场景拥有独立实例，修改本场景不会覆盖旧Demo。

Art/grooming_environment_v1/有独立房间背景、透明皮面金属台及灰白猫爪。Art/grooming_fur_v1/有顺毛底图、身躯毛块、边缘毛条、特殊元素与飞散素材。原PNG不改像素，运行时按索引裁取，灰／白毛块按底图采样配色。近景猫可见框约屏幕宽78%、高81%；金属支撑资产完整保留，当前近景以皮面和金属前沿为主。

参数最新入口：策划17第29.8节，29.5—29.7为之前版本。毛片逐像素跟随底图毛色，但刻意保留暗部对比，让待梳理区域更明显；灰白交界不变。大猫2个毛结／2片灰尘，小猫各1个，两者都有1只跳蚤，轮廓随猫匹配。数量、对比强度、速度阈值与特殊需求次数是试玩值。
