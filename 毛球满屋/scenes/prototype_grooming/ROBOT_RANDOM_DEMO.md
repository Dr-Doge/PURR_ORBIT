# 机器猫随机污垢独立测试

**可执行版：**`builds/毛球计划_机器猫随机污渍测试版_20261016_v0.27.0.20/毛球计划_机器猫随机污渍测试版.exe`，中文命名、0.27.0.20，直接运行当前005；源码F6入口保持。

**005最新：**污渍宽度约原1.8倍，分布到肩颈、背、腹和后躯；顽固积灰8次、油块10次有效单程，约4／5次往返。新参数17第29.11.2、报告reports/grooming_robot_coverage_20261016；F6入口不变。

Godot **4.7.1** 打开 `robot_random_demo.tscn`，按 **F6**。本场景属于IMP-20261016-004的独立交付；fur_demo顶部机器猫仍是旧固定布局，尚未整合随机版。

按住左键拖动擦布，允许快速、反向和多方向擦拭；可以在背景按下再移进机身。普通指纹／油迹半透明，分区逐步擦除；大块顽固污垢需数次有效换向，边擦边变淡。静止、点击和微抖不能清完顽固块。松开、暂停或失焦保留本单清理进度。

全部有效污垢清完后按既有框架跳出120、自动入账，随后接另一位随机机器猫。钱包为内存会话，退出清空。

- “新随机订单”：重新生成数量、位置、种类与尺寸，保留钱包。
- “重试本单”：按当前seed重新开始同一布局，保留钱包。
- seed框＋“按seed复现”：开发用复现，范围0—2147483647；初始样本6101604。
- “暂停”或Esc：暂停／继续，解除当前按住状态。

服务区域可在场景根节点Inspector的`service_polygon`编辑，坐标为机器猫底图0—1 UV；默认只覆盖主机身，排除脸、眼、脚和背景。先验证完整可见污垢形状及底图Alpha，再生成完整污垢贴图；随机尝试有限，失败转安全网格，仍无位置则减量并记录。修改区域后需重新运行；不能把背景或透明区当成可清目标。

配置与独立脚本：`scripts/prototype_grooming_robot/`。所有试玩参数统一见策划17第29.11节。验证入口：`tests/run_grooming_robot_random.ps1`；证据与限制见`reports/grooming_robot_random_20261016/README.md`。
