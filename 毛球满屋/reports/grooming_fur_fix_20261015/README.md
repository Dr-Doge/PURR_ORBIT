# 梳齿判定、限速与底层毛色修复

2026-10-15，Godot4.7.1。入口仍scenes/prototype_grooming/fur_demo.tscn。修复前提交7a314077；此前reports/grooming_fur_20261015保留为旧证据。

## 修改结果

- 梳子用原资产旋转为头朝上、柄朝下。原图中两端齿尖坐标校准后，梳齿旁竖线与实际范围共享同一几何配置：长110、厚12逻辑像素；鼠标位于齿边中心。柄和梳背没有清理判定，替代旧半径48的圆形范围。
- 普通猫明确限速为1200逻辑像素/秒，等于阈值仍可梳，高于阈值且齿边接触未处理毛发才扣评。毛结慢梳上限500。按帧汇总实际鼠标移动、100毫秒滑动平均，排除反应抖动，不再以相邻OS事件的微秒间隔判罚。机器猫保持快速擦拭。
- 毛片Shader逐像素采样其正下方底图，不再只用模块中心决定灰／白。跨毛色边界也正确跟随；保留约-8%至+4%的毛簇凹凸明暗。轮廓与毛结的深色外缘保留，飞散毛片继承相同配色。无PNG修色或重绘。

## 验证

30模型＋15GUI＋33专项＝78项通过。GUI发送实际鼠标事件；批量梳理按控制的逻辑帧时长刷新，属于脚本输入，不是人工手感验收。专项包含：齿边末端可梳而柄侧不生效、渲染齿端与判定重合；上／下身900px/s无扣评、1200边界允许、1500接触时扣评；密集事件不放大速度、反应抖动不参与计速，以及60／144／240帧速度一致。

实际GPU截图比较852个毛片可见采样点与隐藏毛片后的底图，RGB最大通道差平均约0.02781，最大约0.06667；不是简单只核对原图调色板。使用1920×1080及1440×810检查，当前截图01—07在本目录。人体工学手感仍需人工确认，不能将脚本无误当作玩家觉得好玩。

复现：PowerShell7执行 `& '毛球满屋/tests/run_grooming_fur.ps1'`，`-ModelOnly`只运行模型。当前参数17第29.6、任务18的IMP-20261015-003。正式场景、存档、旧v2与导出配置未改，无新EXE。
