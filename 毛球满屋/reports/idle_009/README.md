# IMP-20260921-009 idle与位移同步修复

2026-09-21，Godot4.7.1；未提交或推送，未写正式玩家存档。

用户确认：播放idle时必须停在原地。旧动画以相邻两次显示刷新的位置差推断移动，重复刷新会把本模拟步的移动错误改成idle；悬停、拖动、搬运标志也可能掩盖已经发生的位移。

现在model只读记录每个模拟步前后的位移（含工人搬运），cat_visuals在该步内保留已经观察到的移动状态；任何非零位移（含亚像素）禁止idle。反应期仍优先produce，其余移动用walk；下一模拟步确认没有位移才idle。悬停仍使真实自主位移停止，解除后原路继续。记录不入档，读档清除，不改变运动、费用、收益或CD参数。
