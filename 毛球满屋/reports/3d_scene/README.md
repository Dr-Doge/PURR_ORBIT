# 3D scene — 四面白盒

2026-09-24，新增独立入口 `res://scenes/3D scene.tscn`，保留原 `main.tscn` 和默认启动场景。

## 场景结构

- `scenes/whitebox_room.tscn`：可直接在 Godot 3D 编辑器编辑的地面、后墙、左墙、右墙四张平面；没有立体角色、设备或装饰模型。
- 水平相机配合偏移视锥形成一点透视，后墙保持矩形；柔和主聚光灯、冷色窗口补光和日光浴局部暖灯共同照明。四面只接收投影，避免平面自身产生阴影条纹。唯一保留的环境贴图是原有 `Art/universe.jpg`，在后墙窗口中按原周期旋转。
- `scripts/room_3d.gd`：沿用原模拟坐标，通过相机投影显示 2D 猫、设备、工人和特效，通过射线与地面相交还原鼠标坐标。实体按前后位置统一排序。
- `scripts/hud_3d.gd`：右上功能栏展开/收起，保留补给、成长、工人、仓库、仪器、暂停和帮助；工人等入口仍按原解锁条件显示。展开时阻止房间操作。
- `scripts/scene_3d.gd`：复用原主控制器、模拟、弹窗、经济与存档，不引入会议中尚未实现的新机制。两场景使用同一正式存档格式与路径。

## 白盒边界

猫、设备与工人现为真实受光和投影的 Sprite3D 平面，复用原动画帧与美术。`actor_lighting_3d.gd` 同步当前动画、翻转、尺寸和脚底锚点；`actor_card_3d.gd` 将原程序绘制的工人和娱乐设备绘成透明贴片。原圆形阴影已移除，阴影来自透明轮廓裁切后的实时渲染。UI、毛层徽标和操作提示保留 2D 绘制。仍然是平面剪影投影，不模拟立体猫身体；没有增加立体角色模型或新贴图。
