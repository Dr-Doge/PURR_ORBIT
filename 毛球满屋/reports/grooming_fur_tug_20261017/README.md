# 2026-10-17｜初始猫纯梳毛、拉扯回弹与慢落毛发

任务IMP-20261017-001。Godot4.7.1，F6入口`scenes/prototype_grooming/fur_demo.tscn`。本轮不改机器猫独立场景、不导出EXE、不提交或push。

## 当前体验

只保留灰白初始猫及身躯／轮廓普通毛片，两种尺寸仍是同一种猫。毛结、灰尘、跳蚤、修甲、机器猫切单、疼痛／评分入口已从这个原型运行链撤下；保留旧场景、源素材与机器猫独立实现。

按住左键向右梳两遍。每一遍需要实际有效行程，不能按鼠标事件数计次；一次连续扫过，即便经过贴片透明空隙，也只算一遍。反向返回或松手后可开始下一遍。第一遍拉松后回弹但不掉，第二遍回弹完成、形变归零的同一步才隐藏原毛片并生成完整落毛片。

毛片沿屏幕右向拉伸，左侧固定；旋转素材仍沿正确屏幕方向形变。计数不改变源Alpha、不把毛片一半擦掉。初始猫不再出现速度惩罚。

松散毛团变大、每次只出1团；完整落毛片和毛团都向下慢落，没有向上喷发或大范围横向飞散。先保持可见再缓慢淡出。清完后猫留在台面上，落毛继续播放，可点“重新梳理”；不会短暂离场并自动切成机器猫或修甲订单。

## 参数与边界

数字是试玩选择，集中在`scripts/prototype_grooming_fur/brush_config.gd`，文档唯一入口17第29.13节。两遍为用户确认；有效行程12px、最大拉扯18px、回弹0.28s为本轮选择。毛团宽68—90px，粒子池32、每次最多1团、间隔0.14s；寿命3.2s、前0.9s不淡出、之后2.3s淡出；初速向下22—32px/s、重力10px/s²、限速55px/s、横漂≤6px/s、转动0.05rad/s。

32个槽位同时承载完整毛片和松散毛团，极快大面积操作超出池容量时不生成额外粒子，但清理不会被阻塞。素材仍为现有模块，未新增或修改PNG；落毛取原贴片配色。该测试只验证手感方向，精确弹性／重量与“是否更好玩”仍需真人确认。

初始猫使用同一类型、不会自动轮换服务；完成计数是展示辅助，未做养成、循环变乱、容器或经济升级。正式F5及存档不变。对比本批开始前，旧grooming基类、机器猫脚本／场景、project.godot及export_presets.cfg共33个文件SHA256一致。
