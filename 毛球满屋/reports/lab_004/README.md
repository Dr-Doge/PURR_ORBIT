## 开始测试

1. 在Godot打开`res://scenes/测试场景.tscn`，按F6。F5仍运行原正式场景。
2. 无须开发键：已有12猫、2名收割工人、全部现有设施。自由猫可来回抚摸；按住拖进空日光浴、娱乐或祭坛。
3. “舱室功能”中采购猫粮、投资成长树、出售库存或操作扭蛋。121毛球预算可买标准粮10份及首级工效／目标层／CD；若选择100份大包则自行取舍。工人只收割，玩家补粮、安排猫、清虫和维修。
4. 左上“猫咪档案”查看姓名、冷幽默简介和词条来源；“新增访客”明确为测试免费生成，可演示新身份抽样。
5. “测试台”提供虫害注入、推进干扰时钟、手动保存／读取测试档；“重置预置”重新建立完整初始状态，资源不会叠加。每次重新F6默认新预置，加载须显式操作。

当前预置：6短毛、2巨型、2静电、1招财、1外星；9只自由，另3只分别占用日光浴／娱乐／祭坛。2喂食器各6粮、库存40，2日光浴／2娱乐／1祭坛及仪器。主体研究已开，性能与ABC未满购，2币、收藏0。完整实际值唯一入口为策划17第24.1。
