# Cat1new 动画替换

仅短毛三花猫使用新素材，其他猫的资源及动画规则不变。九张原始图不改动，以 256×256 AtlasTexture 按行切分，共 75 帧。

- 主要位移轴决定四向：左右使用侧面及镜像，上下独立 walk/idle；停下保持朝向。
- 优先级：产毛 > 实际抚摸 > 移动 > 空闲舔爪 > 待机。悬停但不抚摸保持待机。
- 空闲累计约 9—15 秒后首次舔爪，之后间隔 12—20 秒空闲时间；20 帧、8 fps。移动、抚摸或产毛打断。仅表现，不暂停或改变模型行为。
- walk / idle / pet 为 8 fps，pet 循环。5 帧产毛动画覆盖原有约 1.1 秒反应窗口，沿用模型时钟与禁收规则。
- 新图透明留白更少，显示画布缩放至原来的 0.8，保持可见猫体大小相近；继续以实际不透明脚底定位，兼容 2D、3D 与真实轮廓阴影。
- 本次只更新美术表现，玩法蓝图、经济和存档不变。旧 cat1 资源保留供原模型冷却定义使用。

验证：test_cat1new 20 项，3D 场景 54 项、灯光 10 项、模型 125 项、悬停 39 项、idle 17 项，以及普通与外星猫动画回归通过。scene.png 为实际 3D 渲染。
