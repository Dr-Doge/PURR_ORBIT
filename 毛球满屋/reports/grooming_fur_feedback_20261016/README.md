## 新表现

普通毛区不再超过1200px/s立即扣评，反向通常只是不清理。未处理毛结要慢顺梳；只有手势起止都在毛结附近、持续过快或逆向硬拉，才累计负荷。整段经过毛结不算局部硬拉。>3000px/s的极端操作先受阻；背景与已完成区无害。先有0.22秒容错，然后黄／红提示，负荷达到1才扣3；松手／轻梳回落，重复扣评有2秒保护。多片重叠不倍增负荷，事件个数不等于施力。

普通毛片仍96×72，四类源形状按底层灰／白／混色取材，毛流归一、小角度变化、64×43间距、少量位置变化。大82片、小16片，两者同样包含四类，所有片均有近邻重叠，继续只放躯干／尾巴。

轮廓23片、7种原素材，增大并叠接背、腹及尾部，尾尖向内移避免顶栏遮挡。原猫描边不改；毛簇自身覆盖原边缘，四次交替有效行程后整片掉落，原描边自然显露。发现原取色把底图黑线复印到上层，因此改为运行时平滑毛色参考，排除描边与透明背景，源PNG字节不变。取消了试验中的底图局部重绘，最终采用正常叠层覆盖，避免产生伪影。
