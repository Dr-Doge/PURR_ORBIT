# v0.26 Demo 实现口径

这些是为了本轮可玩原型选定的**临时实现参数**，不代表用户已经确认正式数值。正式待定清单仍由[策划12](../摸猫增量策划案/12_待定决策与变更.md)维护。修改参数优先看 `scripts/data.gd`，结算与行为看 `scripts/model.gd`，界面看 `scripts/main.gd`，场景和鼠标看 `scripts/room.gd`。

## 已实现的循环

抚摸收割 → 用毛球研发／买猫与设备 → 工人接手重复劳动 → 收割自然毛层获得代币 → 不重复扭蛋提升系列buff → 抽完当期收藏后邀请重开 → 继承加成并开放下一阶段设施。

全屏场景没有移动人物，也没有掉落物拾取。设施自动喂食／运行轮次／就绪离场；工人处理收割、补粮、实际搬运、清虫和维护。购物预算与出售时机由玩家决定。

## 暂定参数与边界

| 项目 | Demo 实现 |
| --- | --- |
| 开局 | 2 只短毛猫，第一只已有 1 层毛，20 份标准猫粮，0 毛球 |
| 长毛与上限 | 基础每 6 秒 1 层，最多 8 层；同等条件各层同 CD；满层后不储存溢出层数 |
| 收割 | 鼠标累计移动 110 个场景像素完成；清掉全部已完成层，保留未完成自然 CD；工人默认等 3 层，可调 1—8 |
| 叠层收益 | `3 × n(n+1)/2 × 产量倍率`；1／3／8 层基础收益为 3／18／108；四舍五入到 0.1 毛球 |
| 数量扩展 | 猫、工人与设施没有额外购买上限；各类价格按已购数量乘 1.28，向上取整。两只初始猫不计入价格膨胀 |
| 喂食器 | 半径 200，每 8 秒为范围内在场猫消耗各 1 粮；料仓 40；增产状态持续 11 秒，三种粮食为 ×1.65／×1.95／×2.25；库存采购、设备补粮分开 |
| 巨型猫 | 饱食时自身 ×3，断粮时自身 ×1.4；再乘喂食倍率。每次进食移除所在喂食器 1 只虫；不包办全部清洁 |
| 日光浴 | 基础 2.2 秒补成 1 个毛层后离场，清除该猫的部分自然 CD；默认 2 槽，速度／容量可升级。仍需收割才成为货币 |
| 转化 | 仅短毛猫可转化；来源分别为喂食、日光浴完成、娱乐轮次和祭坛每 10 秒；基础 10%，每级 +8 个百分点，上限 4 级；特殊猫不再相互转化 |
| 静电猫 | 收割触发半径 185 的额外单层基础奖励，不吃掉邻猫已有毛层、不递归、不增加代币进度；不触发邻猫特殊技能，作为试玩中的防循环口径 |
| 虫害 | 第 2 周目起，本轮有日光浴，喂食器连续 38 秒未完成清理后出现 3 只虫；每只点 2 下；带虫时范围猫取消喂食增产，并降至正常基础产量的 65%；巨型猫按其断粮基础再乘 65% |
| 娱乐 | 单设备 1 猫，停止长毛；基础 5 秒／轮，55% 赢取价值 12 的道具；分支增加胜率、缩短轮次、提高价值和转化概率；只入库，出售另点 |
| 招财猫 | 在实际毛球收割或娱乐中奖后抛币，50% 正面追加 1 件价值 18 的道具；反面保留基础奖励，不奖励代币 |
| 祭坛 | 默认 2 槽，指派猫不产毛；每猫全局速度 +18%，每级再 +8 个百分点；影响自然长毛、日光浴和娱乐轮次，不加速工人、喂食耗粮或故障计时 |
| 外星猫 | 半径 180 内其他猫的毛层生产／日光浴速度 ×1.35；多个外星猫的同类光环不叠乘 |
| 干扰 | 第 3 周目起，本轮已摆祭坛，每 32 秒令一台尚未故障的娱乐设施黑屏；暂停轮次，点 6 下恢复；不以外星猫转化为前提 |
| 工人 | 行走 155 场景像素／秒，收割操作 1 秒，其余步骤 0.6 秒；搬猫有去程和搬运过程；目标被玩家移动时取消旧任务 |
| 自由照料 | 优先维修（有研发时）、清虫、补粮、收割、日光浴；固定岗位由第 2 周目的职责帽解锁；维护还需第 3 周目专门研发 |
| 首枚代币 | 本轮累计收割 3 个已生长毛层保证给 1 枚；之后按毛层积累进度，分别每 14／18／22 层给 1 枚；不是每次鼠标事件给币，静电额外奖励不计入 |
| 扭蛋 | 每抽 1 币；当期未拥有收藏等概率无放回。每轮新增 2／3／4 系列，每系列 3 件；共 27 件 |
| 永久buff | 每系列只对应产毛量、毛层速度、工人效率或售价中的一种；第一件生效，同效果按各件加成相加，再作用到相应系统；具体每件数值见 `data.gd/SERIES` |
| 重开 | 抽完当期全部收藏后邀请，允许暂留；明确确认才重开。保留已得收藏、buff与接触记忆；重置猫、工人、设施、研究、毛球、粮食、道具、剩余代币、当轮事件计时。初始配置同开局 |
| 下一轮扭蛋机 | 收藏加成开局立即生效；本轮再获得首币时重新激活仪器，旧收藏不返池 |

## 升级树对应

主体采用当前07的三路提案：工人 → 喂食器 → 日光浴；工人 → 职责帽 → 工人维护；喂食器 → 娱乐 → 祭坛，祭坛也作为维护前置。图上同时展示 12 个设施性能分支。分支无需满级，不恢复历史131节点和旧猫种购买树。

主体解锁只是购买资格，生产设施必须额外买实体并摆放。职责帽固定为第2周目、维护为第3周目；各设施四级性能旁支随主体开放。高级猫粮例外为两级、三种粮食。

## 试玩范围与限制

- 三周目属于本次实现范围，不等同于正式发行或未来公开Demo范围。没有第四周目内容。
- 美术为程序绘制的像素原型，尚未接入最终素材、音效或完整动画；抛币、静电范围、体型、收益与故障已有可视反馈。
- 舱室工人使用直线移动，设施不作为寻路障碍；没有复杂碰撞或站内扩建。实体摆放有间距约束。
- 工人没有预算代购和自动出售；设备安排采用空位填充，不是完整的猫名单排班系统。永久buff目前四类。
- 无离线收益；策略模拟可验证收支能走通，但无法替代真人对节奏、理解成本和疲劳的评价。
