## 分层与摆放

1. **底层**始终使用顺毛猫。毛色、脸、眼、鼻、爪与完整站姿在这层保持稳定。
2. **身躯内部**摆放独立杂毛模块，每片有独立ID、区域和完成状态。正确梳理命中后直接隐藏整片，露出底图；不要对这类模块做渐变橡皮擦。可用同一毛簇或fall素材做短暂飞散。
3. **轮廓上层**用毛条沿下层猫边缘摆放，连接边朝内、杂乱毛尖朝外。工具经过时局部擦除这一层Alpha；覆盖底图的部分露出整毛，轮廓外多余毛尖被擦掉后自然露出房间背景。
4. **特殊对象**独立摆在身躯范围内。打结慢顺梳，灰尘上下轻扫，跳蚤点击处理；这些是本轮原型选择，具体次数和速度未作为最终机制定值。

灰色模块只覆盖猫的灰区，奶白模块只覆盖白区；混色模块用于灰白交界。不要把所有模块随机混放到全身。主体块使用较弱的内部线条，避免排列后像一堆厚描边贴纸；边缘毛条保留朝外轮廓描边。

**同日修复：**模块选灰／白只能粗分，不能保证跨色区域一致。当前fur_demo运行时使用coat_cleaning Shader，让每个毛片像素读取其正下方底图颜色，保留轻微纹理明暗；飞散片继承相同配色。没有修改这些PNG，颜色不再由单个中心点主导整片。

脸、眼睛、鼻子、粉红耳朵等不是这些杂毛模块的覆盖目标。模块应约为猫身宽度的若干百分比，具体密度、尺寸与锚点需要试摆；PNG不是最终配准的整张轮廓遮罩。毛条转向与部分裁切必须根据实际边缘处理，不能把矩形格直接覆盖在猫外侧。

## 颜色与资源

毛发统一参照用户灰褐／奶白猫：代表性灰褐RGB约168/152/137、奶白约253/247/235，保留原有更亮／更暗的阴影；外轮廓为深棕。图集提取的主要颜色见[atlas_index.json](atlas_index.json)，仅做读取分析，没有修改素材。跳蚤采用辨认性深棕色，灰尘是局部浅灰米色，不引入整身黑泥。

[resources/](resources/)内35个.tres可按名字引用，不需要再裁切PNG。索引不是机械等分图集：通过Alpha>16的主要可见连通区域判断每个模块实际边界，保留跨标准格的毛尖，并给4px余量；极低Alpha边缘不参与边界测量。原图的透明区域可能保留RGB／低Alpha信息，不能把RGB背景颜色误当成实体脏污。

全部图片由内置imagegen生成，完整[生成Prompt](生成Prompt.md)包含顺毛底图的定向修整。索引工具为`tools/index_fur_assets.py`，只读PNG、输出资源与JSON；运行`python 毛球满屋/tools/index_fur_assets.py`可重建。当前已在新独立原型实装毛块脱落、轮廓擦除和三类特殊需求；模块仍是试玩美术，最终配准与动画待人工评估。
