# 《Purr Orbit》／《毛球计划》新玩法策划报告

2026年10月9日｜玩法设计讨论

## 一、游戏定位

《毛球计划》是一款以太空猫咪为主题，结合增量、轻度经营与放置的游戏。玩家在空间站中照看一群奇妙的猫型生物，从它们身上采集不断长出的毛发，获得资源，再用资源升级采集手段、培养猫咪并配置设施。

游戏整体采用无厘头、诙谐的表现方式。猫咪、工具和设施都可以脱离现实：毛发会长成夸张的“毛王”，微型小帮手在猫身上忙碌，宇宙跳蚤背着偷来的毛发逃窜。玩家在获得更高收入的同时，也不断看到新的动作和意外场面。

本次玩法调整重点是让成长直接体现在猫身上。早期玩家一根一根摘毛，之后逐渐能够扫过一片毛、触发连锁收获，并把重复劳动交给小帮手。猫的数量仍会增加，但单只猫的产能、采集方式与个性也是持续培养的重点。

## 二、玩家如何操作

游戏以船舱和猫身近景两个视角展开，通过鼠标滚轮往返切换。

| 视角 | 画面与操作 | 玩家主要关注什么 |
|---|---|---|
| 船舱视角 | 看到猫咪和设施；将鼠标悬停在猫身上，滚轮放大进入它的近景 | 哪只猫积累了较多毛发、各自产能如何、哪些猫需要处理异常，以及资源该投入哪里 |
| 猫身近景 | 猫的身体铺满主要画面，成为可操作的“地面”，背景仍保留船舱；玩家点击或使用工具收毛 | 直接收获资源、拔取毛王、处理毛结与跳蚤，观察小帮手工作和猫的反应 |

缩放应通过镜头靠近、猫咪姿势变化和毛发细节显现来衔接，让玩家感到自己正在靠近同一只猫。视角切换保留猫身上的毛量和当前状态。照看一只猫时，其他猫继续生长，已配置的自动化继续工作。

猫咪的毛发会随机出现在身体表面，不设置固定生长位置，也不限制同时存在的毛数。玩家暂时不收割，毛就持续积累；单根毛不会因为等待而变得更值钱。毛被摘取后结算入库，猫本身不会被消耗，之后仍会在随机位置长出新毛。

## 三、基础玩法循环

**观察猫咪 → 选择采集目标 → 收获毛发 → 投资升级 → 提高产能与采集效率 → 配置自动化 → 处理新问题并继续培养。**

| 环节 | 玩家做什么 | 为什么会进入下一环节 |
|---|---|---|
| 观察与选择 | 在船舱查看毛量、产能和异常，选择一只猫进入近景 | 找到当前值得集中收割或需要照看的对象 |
| 收获资源 | 摘取普通毛、处理毛王，让猫身上的毛转为可用资源 | 获得购买工具、设施和成长升级的资金 |
| 提高产能 | 增加单次摘毛产量、毛发生长速度或特殊毛出现概率 | 猫能提供更多资源，但原有操作逐渐处理不过来 |
| 改进采集 | 解锁移动触碰、范围连锁等手段 | 同样的时间可以收获更多毛，缓解重复点击的压力 |
| 配置自动化 | 给适合的猫安排小帮手，并配置船舱加成设施 | 稳定收入逐渐形成，玩家可以把注意力转向其他猫 |
| 处理新问题 | 解开毛结、击败偷毛贼、亲自采集特殊猫 | 维持收益，获得额外回报，并寻找下一步升级方向 |

这一循环中的瓶颈主要来自生产能力与采集能力的变化：猫长毛更快，玩家来不及摘；工具和小帮手提高处理效率后，玩家再追求更高产能或更特殊的猫。成长既增加收入，也改变操作方式和注意力分配。

## 四、玩家的成长流程

| 阶段 | 主要体验 | 逐步引入的内容 | 玩家感受到的变化 |
|---|---|---|---|
| 开始：认识一只猫 | 在近景逐个点击毛头，建立最直接的收获反馈 | 随机长毛、点击摘取、即时结算和猫咪反应 | 看懂毛从哪里来、怎么取得、能用来做什么 |
| 初步成长：改进手段 | 用采集所得购买升级，从逐根处理发展到批量处理 | 单次产量、生长速度、移动触碰、连锁收割 | 同样一次动作能收更多毛，成长在画面中明显可见 |
| 扩展：照看不同的猫 | 在船舱与近景间往返，比较各只猫的特点 | 多猫独立产能、buff设施、猫种差异 | 开始选择优先培养谁、把资源用在哪里 |
| 自动化：建立稳定收入 | 将重复采集交给猫身小帮手 | 招募、分配、效率升级与后台工作 | 玩家不再必须逐根收割，可以专注特殊目标和配置 |
| 持续变化：应对新情况 | 在自动生产之外处理需要亲手参与的内容 | 毛王、毛结、偷毛贼和不适配自动化的特殊猫 | 游玩节奏在持续收获、集中爆发和短时应对之间变化 |

这些阶段表示主要关注点的变化，具体解锁顺序仍可调整。进入多猫或自动化阶段后，玩家仍可随时返回任意猫的近景，继续使用已获得的采集手段。

## 五、主要交互与变化

| 内容 | 玩家如何互动 | 收益与影响 | 在游玩中的作用 |
|---|---|---|---|
| 普通毛发 | 初期逐个点击，升级后可用鼠标移动触碰收获 | 持续获得基础资源，未摘取的毛继续积累 | 构成最容易理解的基础收入 |
| 连锁收割 | 摘取一根毛时，带走一定范围内的其他毛 | 毛发积得越密，一次操作越能产生明显的批量收获 | 让工具升级与积累产生联系，提供大范围收获的爽感 |
| 毛王 | 连续点击拔取明显更大、更长的特殊毛发 | 完成后一次获得大量毛发；升级可提高出现概率 | 提供值得主动关注的爆发奖励 |
| 毛发打结 | 按住鼠标来回刷开局部毛结 | 打结区域暂时难以收割，其他区域仍可操作；解开后集中收获 | 插入一种不同的手势，让玩家自行安排处理顺序 |
| 偷毛贼 | 在规定时间内连续点击，击败快速移动的宇宙跳蚤 | 跳蚤盗取待摘毛发，存在时该猫所有收割暂停；击败可追回赃物并获奖励，失败则被它带走已偷毛发 | 制造短时需要关注的事件，在自动化后保留主动操作 |
| 特殊手动猫 | 按其特点亲自处理采集 | 自动化不适配时会带来负反馈，需要玩家改变处理方式 | 让新猫带来玩法变化，使近景长期有参与价值 |

事件需要有清楚的提示与可理解的后果。打结属于局部、可安排处理顺序的问题，偷毛贼则更紧迫；不能让所有猫频繁同时出事，使经营变成不断救场。

## 六、猫咪、升级与设施如何配合

每只猫都有自己的生长效率、待摘毛量和实际收入。船舱提供简明概览，近景呈现对应的生长与采集情况，使玩家能够判断一只猫是“生产不足”，还是“毛很多但收不过来”。

| 成长对象 | 主要作用 | 玩家需要作出的选择 |
|---|---|---|
| 猫咪 | 提供不同的生长特点、单根产量与特殊毛倾向 | 优先培养哪只猫，选择稳定生产还是更有特色的采集体验 |
| 采集工具 | 改变一次能够处理多少毛，以及如何处理 | 先提高单次收益、扩大范围，还是解锁更方便的操作 |
| 猫身小帮手 | 在猫身上独立执行重复采集 | 给哪只猫配置自动化，何时提高效率，哪些猫继续亲自照看 |
| 船舱buff设施 | 强化生长、特殊毛概率或采集效果等生产特点 | 为不同猫搭配合适的加成，形成不同的收益方式 |
| 装饰设施 | 丰富船舱氛围和荒诞趣味 | 塑造空间站的风格，不要求每件装饰都附带数值 |

设施不再采用把猫拖入其中加工产物的工作台形式。生产与采集的主体始终是猫，设施通过加成影响猫的能力，小帮手的具体工作则可以在猫身近景中看见。

升级树围绕单猫采集需要逐步展开，包括单次产量、毛发生长速度、连锁范围、毛王概率与自动化效率。玩家可以组合不同方向，例如更快生长配合范围收割，或提高毛王概率后亲自处理高价值目标。具体节点、成本与强度仍需进一步设计。

## 七、猫咪的个性与游戏风格

普通猫之外，其他猫种将围绕meme、彩蛋和反常识主题设计。它们的外观、动作、特性和文字介绍应互相呼应，让玩家看见猫就能对它产生印象，而不是只在属性面板中读到差别。

| 个性化层次 | 设计方向 | 希望形成的体验 |
|---|---|---|
| 猫种特点 | 各自有鲜明的采集特点与动作反馈 | 遇到新猫时，玩家愿意放大看看它有什么不同 |
| 个体身份 | 稳定的名字、外观细节、性格与诙谐简介 | 同种猫也能成为玩家认识的独特个体 |
| 相处经历 | 结合重要游玩事件增加趣味备注 | 玩家能记住自己与这只猫发生过的事情 |

工具、毛王、小帮手与设施也采用夸张、荒诞的表现。一次扫过猫身引发大片毛头弹起，或连点拔出一根过分巨大的毛王，都应能通过画面直接传达趣味和成长。

## 八、当前方案希望解决的问题

| 原有体验问题 | 新设计方向 | 预期改善 |
|---|---|---|
| 长期重复一种操作，过程平淡 | 点击、触碰、连锁、连点和按住刷毛逐步引入 | 玩家在追求同类资源时，持续接触不同的操作节奏 |
| 收益增加，但画面感受不明显 | 用毛发密度、批量收获、毛王和猫的反应表现成长 | 升级效果能够直接被看见和感受到 |
| 增量过于依赖增加猫数 | 提升单只猫的产能和采集能力，强化猫种差异 | 少量猫也有持续培养与配置空间 |
| 自动化完善后缺少事情可做 | 保留特殊目标、事件与手动猫 | 重复劳动减少后，仍有需要玩家判断和参与的内容 |
| 猫咪缺少记忆点 | 主题化猫种、稳定身份和个性动作 | 玩家能够认识并记住自己正在培养的猫 |

当前已形成基础循环与主要交互方向，后续重点细化猫种名单、成长节奏、升级费用、事件频率和反馈表现。新猫获得方式及毛发、毛团、毛线球的资源面额设计仍为候选，需要围绕上述核心循环继续确定。
