## 2. 参考帧怎样使用

### 场景与画风

参考用户两张船舱截图：[关门船舱原图](原始参考_关门船舱.png)、[开门船舱原图](原始参考_开门船舱.png)。

六张生成帧统一采用关门状态。保持金属地板透视、中央舱门、舷窗、植物、管线与暗暖灯光。环境有伪3D空间深度，猫是统一描边、扁平明暗的二维纸片精灵，不混入写实照片或毛绒3D模型。

### 关键帧与首帧的区别

六张是“交互发生时的关键效果帧”，不是都处于零进度：

- S1-01、S2-01已经有一次+3及毛球飞行。
- S1-02处于持续按住的约55%进度。
- S1-03处于拖动的约60%进度。
- S2-02正处于一次爆发，+1为该次基础收益、+8为追加收益。
- S2-03正处于高效部位的一次+6产出。

如果工具以图片作为视频首帧，使用本稿的“从已有状态继续”时序，不重新生成猫、重复发放开头已有奖励或突然归零。若工具仅把它当外观参考，则可以从普通待机开始，并在相同时长内安排同类操作。不要把两种起始方式混在一起。

生成帧为接近16:9的横图，剪辑工程设置16:9并等比适配。不要拉伸猫的体态。图中120、+3、+6、+1、+8及累积次数只用于说明交互，不是正式费用或最终收益。

## 4. 方案一：通过三种输入方式区分

### S1-01｜点击普通猫，8秒

参考：[S1_01_点击普通猫.png](S1_01_点击普通猫.png)。

```text
制作8秒的直接点击收割演示，使用对应参考帧，镜头固定。被操作对象是左侧普通三花猫，中央良子猫与右侧长毛猫只待机。

0—1秒：从图片里已有的一次点击结果继续。已有+3淡出，已有毛球完成飞向左上资源栏。鼠标暂不点击，不再额外结算这一次。

1—6秒：分别在约1.2、2.5、3.8、5.1秒进行4次清楚的左键点击。光标停在普通猫的身体上，每次短促压下、恢复，接触处只出现一次点击脉冲。按下与释放先出现，猫随后被点得轻微凹一下，再像软团子弹回，完成后只跳一次+3，毛球飞向资源栏。每次恢复同一普通体态，不逐次鼓大，不积累额外爆发。

6—8秒：鼠标停止点击并停在猫旁边，猫恢复普通待机，最后的毛球到账。静止悬停期间不产出。左下鼠标提示仅在各次点击时短亮，空档恢复，没有持续按住状态。

重点是“每点一次，反应一次，给一次”，4次新点击对应4次新+3。不出现长按进度，不要求点特定部位，不附加点击节奏考核。
```

### S1-02｜长按良子猫，9秒

参考：[S1_02_长按良子猫.png](S1_02_长按良子猫.png)。

```text
制作9秒持续按住收割演示。中央黑白良子猫是唯一目标，镜头与猫的位置固定。小手光标停在肚子上，左下鼠标状态表现为左键持续按住，不反复产生点击脉冲。

0—1秒：从参考图约55%的短条继续，鼠标已按住，不新增一次按下。短条按时间填到100%，良子猫的肚子缓慢鼓起，周期结束时身体噗地回弹，跳一次+6，毛球飞向资源栏。不是松手才结算。

1—3秒：鼠标仍然保持按住，几乎不移动，没有第二次按下。短条自动从0开始新一轮，按时间再次填满，肚子再次缓慢鼓起并释放，产出第二次+6。观众能看懂一次持续按住完成了连续两轮。

3—4.5秒：鼠标明确松开，左下按住指示熄灭，短条回到已完成的空状态或停止，猫恢复原样。这1.5秒里光标仍在附近，但不继续鼓起、不产出。

4.5—6.5秒：鼠标在肚子上重新按下并保持，按住状态再次亮起，一轮约2秒的时间积累完成，第三次产出+6。

6.5—9秒：松开，猫安静待机，残余毛球到账。左键不亮，不继续生产。

身体蓄势来自持续按住的时间，不来自离散点击次数。不移动鼠标也能进度增长；不需要连续点击，不要求精准松手，不出现小游戏成功失败判定。没有按住输入就停止下一轮。
```

### S1-03｜拖动长毛猫，9秒

参考：[S1_03_拖动长毛猫.png](S1_03_拖动长毛猫.png)。

```text
制作9秒按住拖动收割演示。只有右侧浅色长毛猫被操作，猫本体停在原位置，鼠标在身体毛帘内来回移动。左下鼠标提示表现为左键按住并移动。不是把猫搬走。

0—2秒：从参考图约60%的短条继续。小手保持按下，在毛帘的宽区域左右捋动，毛随着手势被拨开；有效鼠标移动使短条继续增长，达到100%后猫抖出一团毛，跳一次+6，再开始下一轮空进度。

2—4秒：小手保持按下，但明确停止移动。猫与短条停止累积，保持未完成状态，不能因为时间过去就自动填条，不能在静止时产出。这一停顿用于展示与长按方案的不同。

4—7秒：鼠标仍按住，恢复连续来回移动，短条继续累积而不是从之前的停顿重新开始。完成一轮后毛帘翻起、弹出毛团，再跳一次+6。手势宽松，不需要沿箭头描线或按固定方向反转。

7—9秒：松开，小手恢复普通指针，猫重新待机，毛球完成到账，不再产出。

猫脸、身体与地面锚点始终不变，只有毛帘随手势摆动。参考图中的短轨迹仅作为手势示意，可以短暂淡去，不增加永久路线考核。重点是“按住并移动才处理，静止保持不会自动处理”。
```

## 5. 方案二：统一点击，区分三种反馈与判定

### S2-01｜稳定反馈型，8秒

参考：[S2_01_稳定点击普通猫.png](S2_01_稳定点击普通猫.png)。

```text
制作8秒稳定点击产出演示。左侧普通三花猫是唯一目标，操作逻辑与方案一的点击普通猫保持一致，不为了区分片段新增规则。

0—1秒：图片已有的一次+3与毛球效果自然完成，不新增点击或重复发奖。

1—6秒：在约1.2、2.5、3.8、5.1秒分别点击普通猫的宽身体区域，4次均表现清楚的光标按下、释放与一次点击脉冲。每次猫身体短促凹下再弹回，跳一次+3，毛球飞向左上资源栏。每次幅度和收益一致，之后恢复普通大小。

6—8秒：光标停止点击，猫恢复普通待机，资源动画完成。没有更多收入。

重点是“一次点击对应一次固定反馈与固定产出”。没有累积条、没有越点越大、没有正确部位要求、没有多次点击后突然爆发。左下提示为单击，不是按住。中央和右侧猫不参与结算。
```

### S2-02｜积累爆发型，9秒

参考：[S2_02_积累爆发良子猫.png](S2_02_积累爆发良子猫.png)。

```text
制作9秒离散点击积累爆发的演示。中央黑白良子猫是唯一目标，身体位置固定，脚下没有长按进度条。只用肚子逐次鼓起表现积累。

0—1秒：参考图已有的一次爆发正在结束，+1与追加+8和毛球飞行自然收尾。这是之前那一次的结果，不重复计奖；肚子回到普通体态，开启新一轮积累。

约1.3秒：鼠标第一次点击肚子，清楚按下再释放，点击脉冲一次。肚子鼓大一小档，给基础+1，保持这一大小。
约2.5秒：第二次点击，同样一次按下释放，肚子再鼓一档，给基础+1，保持。

2.8—4.0秒：鼠标离开猫一小段或停在空地，完全不点击。肚子保持已经积累的大小，不继续变大、不自动爆发、不清零，也不产出。没有倒计时。

约4.3秒：第三次点击肚子，肚子到更明显的蓄势体态，给基础+1。
约5.5秒：第四次点击肚子，给这一次基础+1，随后身体突然噗地瘪回普通大小，追加单独的较大+8，毛球比前三次明显更多地弹出并飞向资源栏。只结算这一轮的追加爆发，不重新支付前三次已给过的基础收益。

约6.8秒：第五次点击，开始新一轮，肚子只鼓第一档，给基础+1，不再次直接爆发。
7.5—9秒：不再点击，保持新一轮的一档积累，资源动画收尾。

左下提示为一次次单击脉冲，不显示持续按住。鼠标停着不会自动加进度。4次一个爆发节点、基础+1与追加+8仅是演示例子，不加题目、指针或连打速度要求。重点是“每点积一点，中途能停，到节点额外爆发”。
```

### S2-03｜位置效率型，9秒

参考：[S2_03_位置高效长毛猫.png](S2_03_位置高效长毛猫.png)。

```text
制作9秒同样点击、不同位置不同效率的演示。唯一目标为右侧浅色长毛猫，镜头固定，猫停步。脸部是低效率区域，脸旁后方宽大的背部厚毛帘是高效率区域。高效位置从头到尾固定，不生成移动弱点或倒计时。

0—0.8秒：参考图已有的背部一次+6产出完成，已有毛球飞向资源栏，不重复发奖。

约1.2秒：鼠标移到猫脸上，做一次清楚的按下释放与点击脉冲。猫小幅抬头，普通抖一下，只跳+1，少量毛球入资源栏。
约2.5秒：再点同一脸部，仍是相同的小反馈和+1，清楚表明这里能产出但效率低。

3—4秒：鼠标移动到背部厚毛帘，位置没有变；宽厚毛帘边缘轻微亮起，作为可读的身体提示，不是弹出小游戏靶子。光标移动本身不发奖。

约4.0秒：点击厚毛帘一次，明确按下与释放。大片毛帘翻起、猫整个身体短促抖一下，跳+6，更多毛球飞向同一资源栏。
约6.0秒：再点击同一厚毛帘，仍然一次+6与相同强反馈，证明可以在这个位置快速重复收割，不要求每轮重新找位置。

6.8—9秒：鼠标移到空地，猫恢复普通待机，高效区提示变淡，位置不改变；毛球到账，不再产出。

所有操作都是离散点击，没有按住拖动、没有追毛头、没有点击顺序，不扣错点资金。+1与+6为演示收益差异。重点是“点对位置更高效”，不是只有动画不同却收益相同。
```

## 6. 后期合成与输入显示

文字、数字和准确时序可以后期统一制作。每段对应参考图的UI颜色和版式相近即可，不能把六段做成不同游戏。

若选择后期UI版本，在对应Prompt末尾追加：

```text
采用后期UI合成：不生成中文、余额或浮动收益数字，保留其位置供后期叠加。保留猫的反应、毛球入库、唯一光标和鼠标输入状态，动作仍按原段落发生。脚下进度条、左下输入提示也可以留出空位，由后期按对应输入绘制。不能因为UI后期制作就改变点击、按住或拖动的实际因果。
```

若光标也后期制作，再追加：

```text
本次不生成光标和鼠标状态图标，两者由后期统一补齐。猫的动作仍按原输入时刻发生。最终必须补出一次次点击的按下与释放、长按期间持续保持的按钮状态、拖动期间连续移动的路径。不要保留生成的第二个光标。
```

后期注意：

- 每次离散点击都有可见按下与释放、一次短脉冲，不只靠“咔哒”声音。
- 长按只在开始和重新按下时有按下动作，中间持续亮，不每次产出都显示再次点击。
- 拖动按住状态不断，手移动才进度增加，静止片段用于证明它与长按不同。
- 方案二良子猫在暂停点击时保持肚子大小，不能继续自行生长。
- 方案二长毛猫的+1与+6绑定实际点击区域，不能交换数字或用同等毛球量掩盖差异。
- 开头已有参考帧效果只做收尾，不增加新的奖励事件。六段分开比较，无需把每段初始120拼成连续真实账目。
- 不把相同时间内的示例收益当作平衡结论。素材用于判断交互是否可读、有反馈，不是比较哪套赚钱更快。
