# 《Purr Orbit／毛球计划》美容店主交互与Demo待办清单

日期：2026-10-14｜本次更新：用户实玩《Scale the Depths》后的交互定义。

**目标：先做可以连续接待猫顾客的美容Demo。**首版只使用两种基础操作：按住拖动梳理、按住划线修甲；不同处理对象提供技巧、演出和反馈变化，不为每只猫另做复杂小游戏。完成全部要求后，按评价直接发放金钱，跳数字和货币图标，不弹结算窗口。

详细规则：[美容梳理与修甲Demo交互规则](2026-10-14_毛球计划_美容梳理与修甲Demo交互规则.md)。待实装交接：[18号日志 IMP-20261014-001](../摸猫增量策划案/18_实装变更日志.md#imp-20261014-001)。本轮更新文档和任务，没有开发或构建游戏。

## 1. 本次已经确定的内容

| 项目 | 当前口径 |
| --- | --- |
| 操作数量 | 预期不超过三种基础变化；首版做梳理和修甲两种。对象差异不计为新的操作类型。 |
| 梳理 | 按住鼠标拖动；干净猫身底图上覆盖灰尘、打结和垃圾，符合对象规则时局部逐步擦除。 |
| 对象规则 | 同一拖动操作可通过速度、重复次数或往复方式区分处理技巧。具体对象映射和参数为试玩细化项。 |
| 质量限制 | 梳理过快、太大力会让顾客疼痛并降评价；普通鼠标以速度等可检测输入表达，不依赖压力传感器。 |
| 修甲 | 从指甲一侧按住划到另一侧，切线应穿过完美区间；太浅继续剪，太深碰血线、疼痛并降评价。 |
| 结算 | 本单全部要求完成后按评价发放金钱，只跳数字和货币图标，不弹窗、不点击领取。 |
| 内容差异 | 两种基础操作共用规则，以猫轮廓、覆盖物、耐受度和反馈形成差异。先一只做通，再比较两只。 |
| 当前资源边界 | 本原型服务报酬按最新要求为金钱单位；名称和与猫毛、毛球的长期关系待定。不自动改正式毛球升级树，也不扩成多币种经济。 |
| 后置内容 | 工具升级、完整树、自动化、毛毡／锻造、盲盒和复杂店铺经营不阻塞主交互Demo。 |

最小流程：**到店 → 看服务要求 → 进入近景 → 梳理／修甲 → 评价决定报酬 → 数字和图标直接结算 → 下一位顾客。**

## 5. 推进顺序和验收

**G02/G03/G08＋A01/A02 → D01—D03（梳理可玩） → G07＋A04＋D04（修甲可玩） → G05/G06＋A03＋D05/D06（评价和自动结算） → 第二只猫与D07 → D08连续试玩。**美术和参数细化可交叉推进。

Demo必须能实际展示：

- [ ] 半身已梳理、半身未清理，停手后原有进度保留。
- [ ] 同一按住拖动操作应对灰尘、毛结和垃圾，区别清楚而无新增小游戏。
- [ ] 正常速度顺利完成；故意过快引起疼痛和评价下降，原因立即可见。
- [ ] 同一指甲浅剪后可再剪；完美完成；剪深扣评，但订单不会卡住。
- [ ] 完成所有要求才发钱，同样服务有失误时报酬更少；每单只结算一次。
- [ ] 报酬只用数字和图标演出，无结算弹窗／确认领取。
- [ ] 不用开发菜单连续服务多位顾客，第二种猫沿用相同基本操作。
- [ ] 真实输入与两种窗口尺寸检查通过；模型测试不代替真人可玩性评价。

如果玩家只想跳过近景、认为规则像限速惩罚，先调整范围、对象规则和反馈，不用扩猫种或加经营系统遮盖问题。
