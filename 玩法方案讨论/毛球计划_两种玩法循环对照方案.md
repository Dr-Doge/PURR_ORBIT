# 《Purr Orbit》／《毛球计划》：两种玩法循环对照方案

2026-09-23｜待选方案，独立于正式策划案文集。本文仅用于讨论，不代表采用或实装，不修改现行游戏规则。

两种方案均采用俯视角2D空间站场景，以鼠标直接操作，没有需要控制移动的人物。以下仅列基础玩法，不规定数值、时长和完整升级树。

## 方案一：白天摸猫，晚上找猫

**白天照料猫咪赚毛球 → 用毛球准备夜间寻猫 → 晚上主动找猫并带回 → 次日猫更多、生产更多 → 支持下一次更有效的寻猫。**

| 环节 | 基本玩法逻辑 | 玩家怎样操作 |
| --- | --- | --- |
| 白天摸猫 | 保留现有摸猫、叠层、设施加成与工人分工；收割得到毛球 | 在猫身上来回移动鼠标收割，拖猫使用设施，点击补粮与分配工人 |
| 准备出发 | 毛球既能发展站内经营，也能购买寻猫消耗品、升级寻猫工具；玩家选择投入方向 | 点击选择探索地点、购买诱饵与升级工具，确认进入夜间 |
| 晚上找猫 | 进入短小的寻猫场景，通过观察和操作找到猫；本方案以主动寻猫替代直接花钱买猫 | 点击检查藏身处，拖放诱饵引出猫，操纵鼠标牵引工具将猫引入运输舱；具体组合待选 |
| 带猫回站 | 找到并带回的猫加入常驻猫群，下一天继续保留；不因日夜切换清空经营进度 | 查看带回结果，返回空间站安排新猫 |
| 下一轮成长 | 猫群扩大提高白天收入，工具成长让夜间能找到更多猫、探索新的地点 | 在扩大经营与提高寻猫能力之间选择升级，继续下一轮 |

**玩家的直接目标：**为了带回看中的猫群，先在白天赚够准备资金；猫带回来后，又能帮助下一次探索。

**方案成立的关键：**夜间需要有寻找、判断和操作的乐趣，不能只是付费后点一下领取猫。获得猫的效率也要成长，避免后期仍逐只重复同样的手续。

## 方案二：设施成长，每轮接待猫群

**预告下一批猫 → 用毛球建设和搭配设施 → 接待到访猫群并收割 → 猫群离开、结算本轮 → 改造空间站，接待下一批。**

| 环节 | 基本玩法逻辑 | 玩家怎样操作 |
| --- | --- | --- |
| 来访预告 | 每回合有一批猫来访，提前显示大致数量和停留特点；设施的吸引能力影响到访数量 | 查看下一批猫的信息，决定本轮侧重快收、攒层还是道具产出 |
| 建设准备 | 毛球主要投入设施数量、容量、效率和相互配合；空间站配置跨回合保留 | 点击购买或升级，拖动摆放设施，安排工人岗位 |
| 接待猫群 | 猫进入空间站，在这一回合停留；玩家按设施容量和收益目标分配猫 | 鼠标抚摸收割，拖猫进入日光浴或娱乐设施，补粮并处理故障 |
| 设施连携 | 喂食提高产量，日光浴帮助攒层，娱乐产出换金道具，祭坛加速；分配方式决定每批猫能带来多少收益 | 选择哪些猫继续收毛、哪些猫使用设施，并在需要时调整；工人接手重复劳动 |
| 回合结束与改造 | 本批来访猫离开，产物和设施保留；根据本轮拥堵或闲置情况改善下一轮 | 查看收益与未充分利用的设施，选择扩容、提效、增加吸引能力或改变搭配 |

**玩家的直接目标：**把空间站改造成更高效的接待场所，让同样一批猫产出更多，随后有能力接待更大猫群。

**方案成立的关键：**到访数量增加必须配合处理能力；只招来更多猫、却没有足够设施和人手，不会自动获得全部收益。设施提供加成和新机制，工人承担重复操作，不把设施全部改成替代工人的自动机器。

## 两种方案的主要区别

| 对照项 | 方案一：日夜双循环 | 方案二：设施主导的回合循环 |
| --- | --- | --- |
| 主要积累什么 | 寻猫所得的常驻猫群，以及照料和寻猫能力 | 持续保留的设施、配置和处理能力；猫群按回合来访 |
| 毛球主要花在哪里 | 站内经营与夜间寻猫两个方向 | 设施建设、升级、搭配与工人配置 |
| 操作变化来自哪里 | 白天照料与夜间寻找，两种玩法交替 | 每轮猫群条件不同，促使玩家调整设施和分配 |
| 想让玩家期待什么 | 下一晚能找到并带回什么猫 | 下一轮的新配置能处理多少猫、创造多少收益 |

日夜／回合的具体时长、切换条件、未完成互动处理与细化获取规则，待选择方向后再设计。
