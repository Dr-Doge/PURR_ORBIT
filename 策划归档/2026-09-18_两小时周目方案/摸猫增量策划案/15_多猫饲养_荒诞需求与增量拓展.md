# 空间站外星猫｜机制、猫种与设施联动总表

2026-09-18 v0.26｜玩法整理；已有三周目Demo，实现范围及临时参数见[工程说明](../毛球满屋/README.md)。文档导航见[00_索引](00_索引.md)，待定项见[12](12_待定决策与变更.md)，猫种见[03](03_猫咪种类与转化.md)。

**设施带来加成和新工作，工人接手手动操作。猫身上的毛需要收割，收割后的产物自动入库，不需要再次拾取。**

**节奏目标补充：** Demo预计约2小时；三周目时间分配、节点密度和代币改造的分析见[16](16_两小时Demo数值与周目节奏分析.md)。这些建议尚未替换下列已确认交互或当前试玩参数。

## 机制表

| 机制／阶段 | 怎么运作 | 玩家要做什么 |
| --- | --- | --- |
| **定时长毛** | 猫咪每经过一次产毛CD就长出一层毛；不收割也会继续积累，同等条件下每层所需CD相同 | 抚摸收割猫身上的毛，产物自动进入库存 |
| **多攒多得** | 每增加一层毛，都会增加额外的产物比例加成；攒多层再收，比相同时间内反复收一层的总收益高得多 | 在“现在收来用钱”和“继续攒毛赚更多”之间选择 |
| **开局积攒资金** | 预期开局先反复收第一层毛，尽快拿到启动资金 | 熟悉收割，购买升级，再招募工人接手重复操作 |
| **设施放大收益** | 喂食器提高产量；日光浴帮助猫咪更快就绪；祭坛加快全局生产，外星猫缩短附近猫的叠层CD | 补粮、搬猫、安排设施内的猫，让产量与叠层速度一起增长 |
| **工作逐步交给工人** | 新设施引入更多操作，工人可接手收割、补粮、搬猫、清虫等工作 | 招募更多工人，解锁职责帽后安排固定分工；产物不需要工人拾取 |
| **第一次神秘接触** | 首次从猫咪得到代币，神秘猫形存在交付刻满图腾的扭蛋机 | 投币、转旋钮，亲自体验首件收藏带来的buff |
| **越收集越强** | 当期扭蛋不放回、不重复；每系列一种buff，收集度越高越强 | 继续获得代币和新收藏，永久加成带回经营 |
| **周目再开始** | 收完当期所有收藏后半强制引导重开；旧收藏与buff继承，下一轮新增系列和玩法 | 带着加成更快起步，并体验新的设施与事件；清零清单待定 |
| **第一周目** | 生产设施只开放到日光浴；神秘扭蛋机早期出现；没有蟑螂和信号干扰 | 学习收割、攒毛、补粮、工人和日光浴，收集首批永久加成 |
| **第二周目** | 新增蟑螂事件与娱乐设施，祭坛仍未开放 | 清理喂食器、安排工人，并把部分猫送去赢取换金道具 |
| **第三周目** | 新增密语祭坛与信号干扰事件 | 为全局加速指派猫，捶打修复黑屏设备，再交给维护工人 |

**长期循环：**早期首代币 → 神秘接触与首抽 → 经营中不断收集 → 当期全部集齐 → 新周目继承加成，并开放更多系列及新的设施与事件。

**跨周目展开的设施体验顺序：**

工人 → 喂食器 → 猫粮分支 → 喂食器转化 → 日光浴 → 日光浴转化 → 蟑螂危机 → 工作分配 → 娱乐设施 → 娱乐设施转化 → 密语祭坛 → 密语祭坛转化。

第三周目的祭坛阶段新增维护流程：**安装祭坛 → 部分娱乐设施受干扰黑屏 → 手动连点捶打恢复 → 解锁工人维护 → 分配工人接手维修。**

前三轮按上表分阶段开放，段内顺序不代表所有节点的硬性前置。第一周目即使安装日光浴也不会生虫；第二周目起还需满足日光浴安装、喂食器久未打理等条件。第三周目起安装祭坛才开启干扰，不要求先转化特殊猫。

## 猫咪表

| 猫咪 | 获取方式 | 作用与联动 |
| --- | --- | --- |
| **短毛猫** | 唯一可直接购买的基础猫 | 积累毛层、接受收割；使用不同设施，有机会转化成对应特殊猫 |
| **巨型猫** | 高能喂食器转化 | 依赖猫粮，产物更多；进食时吃掉喂食器内的一部分蟑螂。替换旧长毛猫 |
| **静电猫** | 太空舷窗日光浴转化 | 炸毛圆球形象；自身产毛时带动周围一定范围内其他猫同时产出一次 |
| **招财猫** | 次世代猫用娱乐设施转化 | 每次产物产出附带抛币：正面额外给一个换金道具，反面不追加，原产物保留 |
| **外星猫** | 喵喵密语祭坛转化 | 通体绿色，大眼睛里只有深黑色，头顶一对圆球尖端触角；自带宇宙辐射，直接缩短周围猫咪的毛层生产CD |

特殊猫通过设施转化获得，原特殊猫购买／解锁节点改为对应转化几率升级。自动入库不等于自动出售。

## 自动化与设施表

| 设施／配件 | 玩家交互与作用 | 与其他项目的联系 | 升级方向 |
| --- | --- | --- | --- |
| **高能喂食器** | 自动喂范围内的猫，提高产物数量；玩家持续补粮 | 放大产毛收益；可转化巨型猫；第二周目起，日光浴启用后面临虫害风险 | 更高级猫粮种类、巨型猫转化几率 |
| **太空舷窗日光浴** | 将产毛CD中的猫拖入；猫停留至产物就绪后自行离开 | 帮助猫咪就绪，可转化静电猫；第一周目可用但无虫害；第二周目起安装才开启虫害风险 | 缩短单次时间、增加容纳量、静电猫转化几率 |
| **次世代猫用娱乐设施** | 将猫拖到拉杆＋显示屏设施上；占用期间不产毛，按轮次概率赢取换金道具 | 第二周目起开放，分走产毛猫并可转化招财猫；第三周目起安装祭坛后可能黑屏，停止产出换金道具，修复后恢复 | 获胜率、轮次速度、奖品价值、招财猫转化几率 |
| **喵喵密语祭坛** | 将猫咪指派进祭坛，为全局生产速度提供比例加成 | 第三周目起开放，帮助积累毛层并转化外星猫；安装后干扰部分娱乐设施，引入黑屏维修工作 | 猫咪槽位、单个猫咪的全局加成、外星猫转化几率 |
| **神秘扭蛋机** | 首枚猫咪代币触发接触，获得带猫图腾、投币口与旋钮的外星仪器；投币抽取新收藏 | 早期出现，承担跨周目长期成长；不同于普通娱乐设施 | 系列收集度增强buff；新系列随周目开放，未设普通升级分支 |
| **毛球精灵小帮手** | 招募工人，接手抚摸收割、补粮、搬猫、清虫等操作 | 设施增加工作量，需要增加工人并分工；收割时机应配合叠层策略 | 职责分配、工人维护功能；其他旧分支不自动继承 |
| **职责分配帽** | 给指定工人安排固定工作 | 将收割、补粮、清虫、搬猫等工作分给不同工人；维护功能解锁后可安排维修职责 | 解锁固定任务分配；具体帽种与分支另定 |
| **工人维护（升级节点）** | 解锁后，小帮手可接手黑屏设备的捶打维修 | 配合职责帽分配维修工人；恢复故障设备，不免除后续干扰 | 解锁维护能力；后续分支未定 |

喵喵密语祭坛：“人们观察到，猫咪有时会抬着头口中念念有词，似乎在和某种存在交流。”

## 新需求表

“新需求”指玩家追求设施加成时，随之增加的工作。

| 新需求 | 由谁引入 | 玩家需要做什么 | 影响与解决联系 |
| --- | --- | --- | --- |
| **猫粮补给** | 高能喂食器 | 在树上解锁猫粮，去商店购买并持续补入喂食器 | 维持加成并供应巨型猫；可分配工人补粮 |
| **太空变异蟑螂清理** | 第二周目起，日光浴安装开启风险；首轮不出现 | 喂食器久未打理生虫；打开内部窗口，连续点击清除全部蟑螂 | 不清理会失去加成并降低产量；巨型猫吃掉部分，也可交给工人清虫 |
| **娱乐设施黑屏维修** | 第三周目起，安装密语祭坛后部分娱乐设施受干扰 | 黑屏时停止产出换金道具；初期连续点击捶打设备，直到画面恢复 | 解锁工人维护节点，再安排工人维修；新增加成带来新工作 |
| **工作分配** | 新设施增加工作种类 | 招募更多工人，用职责帽分配固定工作 | 避免工人顾此失彼，让收割、补粮、搬猫、清虫及解锁后的维修有人负责 |
| **设施用猫安排** | 日光浴、娱乐设施、密语祭坛 | 按收益目标将猫拖入或指派进设施；执行操作可交给工人 | 日光浴帮助就绪，娱乐设施以停产毛换取奖品，祭坛提供全局加速；祭坛内猫是否继续产毛待定 |

**联动重点：**喂食器增加产量，速度类设施帮助更快积累毛层；从第二周目开始，日光浴给喂食器带来虫害，巨型猫和清虫工人缓解问题。第三周目祭坛提高全局速度，又使部分娱乐设施黑屏停产，需要先手动维修，再解锁工人维护。设施越多，越需要更多工人与明确分工。

待定：叠层比例与上限、日光浴及静电传导怎样处理已有毛层、祭坛加速的具体作用范围。**工人按目标层数收割为待设计建议**，避免工人总在第一层就收走。其余未定边界见[12](12_待定决策与变更.md)。
