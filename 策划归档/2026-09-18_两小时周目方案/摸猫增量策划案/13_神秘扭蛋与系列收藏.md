# 13｜神秘扭蛋与系列收藏

v0.26｜2026-09-18。入口：[00_索引](00_索引.md)。本轮新增用户确认机制；表现与试算提案另行标明，未实装。

## 设施定位（已确认）

神秘扭蛋机是游戏早期解锁的实体设施，也是跨周目成长的核心。它来自一个未知外星文明：机身雕刻猫咪图腾，正面只有投币口与旋钮，外形像扭蛋机，却带有第三类接触的神秘感。

玩家第一次从猫咪那里获得神秘代币时，一个神秘的猫咪形象存在主动接触玩家，并交付这台仪器。首次投币、转动旋钮、获得收藏与加成，让玩家亲自理解代币的价值。它不等于普通娱乐设施，也不由祭坛转化或工人维护节点解锁。

## 第一次接触

| 步骤 | 已确认的事件与交互 | 玩家获得的认识 |
| --- | --- | --- |
| 首枚代币 | 早期从猫咪处得到神秘代币，自动进入库存 | 猫咪还能产出一种特别的东西 |
| 神秘接触 | 猫咪形象存在出现，交给玩家刻满图腾的仪器 | 代币与某种未知文明有关 |
| 使用仪器 | 将代币投入投币口，转动旋钮，开启第一个扭蛋 | 代币能换到收藏 |
| 首次加成 | 获得收藏，所属系列收集度增加，对应buff生效 | 每次抽到新东西都能让自己变强 |
| 返回经营 | 带着加成继续照料猫、扩设施、雇工人 | 更愿意继续获得代币、再次使用仪器 |

**设计提案：**早期基础猫即可触发首枚代币，不把首次接触锁到招财猫或祭坛。首抽应能用首次获得的代币完成，并优先让玩家感知一个清楚的基础增益；首掉落保障和首抽安排仍需确定，不能让长时间随机落空破坏早期引导。

代币由哪些猫、哪些产出事件掉落，以及人工和工人操作是否有相同机会均未确定。招财猫现有抛币仍奖励换金道具，不擅自改回旧版“正面给代币”。

## 不放回、不重复的抽取（已确认）

| 规则 | 内容 |
| --- | --- |
| 可抽内容 | 当前周目开放系列中，尚未获得的收藏 |
| 不放回 | 一件收藏获得后，从可抽集合中移除 |
| 不重复 | 已拥有收藏，包括以前周目继承的收藏，不重新进入奖池 |
| 系列成长 | 每个系列对应一种buff，系列收集度越高，该buff越强 |
| 跨周目 | 已获得收藏与它们的加成继承，下一周目开放新的系列 |
| 本周目完成 | 当前周目所有可获得收藏均已获得；不是只买到系列入口，也不是每套抽到一件 |

抽取是随机决定“先得到哪件”，不再依靠重复品堆数量。系列内件数、稀有度权重、是否允许选系列、每抽代币费用待定；不放回并不自动表示所有剩余物品等概率。

设计提案：显示本周目剩余收藏与抽取费用，空池禁用投币并且不扣币；多次输入、退出或读档不应重复扣币、重复发收藏或回滚已抽出的物品。抽取后的收藏自动入库到专属收藏记录，无拾取步骤。

## 系列buff

每个系列持续强化同一项效果，第一件就有加成，不需要先集齐整套。永久收藏与普通换金道具分开：前者承担跨周目成长，后者主要承担本周目资金流。

| 系列效果候选（设计提案） | 更适合强化的环节 | 设计边界 |
| --- | --- | --- |
| 基础产毛量 | 下一周目最早的收割收入 | 第一件就能在基础猫上看出变化 |
| 毛层生产速度 | 更快积累毛层 | 与祭坛、外星猫明确叠加，避免CD失控 |
| 工人工作效率 | 更快突破重复劳动阶段 | 工人未解锁时不凭空出现自动执行 |
| 换金道具售价 | 娱乐与招财道具变现 | 不把永久收藏当作普通商品出售 |

这些是buff方向候选，不是已定系列名单。首轮两套对应什么、后续如何增加效果种类、满套是否有额外奖励均待设计；不默认解锁旧代币爆率加成循环。

## 神秘感的表达（设计提案）

采用猫咪图腾、短暂未知信号和含蓄的接触语言，让玩家感到这台机器在回应自己的行动。不要由角色直接解释整个外星文明或宣布“主线任务：集齐全部扭蛋”。

可以在收藏界面看清已有加成与缺少的收藏；隐藏叙事目的不等于隐藏费用和收益。具体扭蛋内容、美术、神秘存在身份、出现方式均未定，也不直接等同于可饲养的外星猫。

周目开放、重启与继承见[14](14_周目循环与继承.md)，参数风险见[08](08_资源经济与数值框架.md)。

## 与设施分期的关系

扭蛋机仍在第一周目早期出现，不随生产设施的后续周目门槛推迟。完成当期收藏推动下一周目，下一轮除新系列外还会开放新设施与事件：第二轮蟑螂与娱乐，第三轮祭坛与信号干扰。首轮代币来源不能依赖尚未开放的娱乐或祭坛系统。
