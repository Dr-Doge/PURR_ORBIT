# 毛球满屋｜这游戏怎么玩？

> 历史参考，未作为当前饲养方案启用。更早的摸猫规则见[归档旧00](../策划归档/2026-09-17_史莱姆养殖与生产线/00_简明策划案.md)；当前饲养方向见[00](00_简明策划案.md)与[15](15_多猫饲养_荒诞需求与增量拓展.md)。


**摸摸猫、攒毛球，把小房间慢慢变成猫咪乐园。**

| 我想做什么？ | 我怎么玩？ | 会有什么收获？ |
| --- | --- | --- |
| 先摸一只猫 | 把鼠标放在猫身上，轻轻来回移动，不用按键。 | 整只猫会明显摇摆，舒服够了就向上一弹、吐出毛球，再走到别处歇一会儿。 |
| 攒钱买东西 | 毛球会自动收进钱包，不用追着捡。 | 毛球就是钱，可以用来请新猫、买工具和升级。 |
| 让房间多几只猫 | 花毛球邀请新猫；一只走开了，就摸另一只。 | 房间更热闹，也有更多猫可以交给自动工具照料。 |
| 试试摸起来不一样的猫 | 在升级树依次解锁长毛猫、炸成圆球的静电猫、举爪招手的招财猫；不用把上一种升满。 | 长毛猫多摸一会儿掉一大团；静电猫一放电，范围内其他猫一起额外出货；招财猫摸舒服后洒出金钱特效并抛硬币：正面给1代币，反面什么也不给；代币用来扭蛋，抽带全局加成的收藏物。毛色可以按喜欢的选。 |
| 摸得更轻松、赚得更多 | 打开升级树，选每次多掉毛球、更容易翻倍、猫换位置更快，或让精灵更好用。 | 不用越玩越拼命甩鼠标，同样的操作能有更大收获。 |
| 歇歇手，让精灵帮忙 | 请毛球精灵自己找猫摸；之后解锁静电精灵，让周围一圈猫一起出货。 | 不动鼠标也能赚毛球；升级能让它们工作更快、范围更大。 |
| 让猫路过也赚钱 | 把固定逗猫棒放在猫常经过的地方。 | 每次真正路过都多掉一点毛球，但不会出代币；一直站着不会反复掉。 |
| 把猫聚在一起摸 | 手动摆一台电暖炉，猫进来后会留在附近活动。 | 我和精灵更好照料它们，暖区还能增加毛球产出。 |
| 多请几个帮手、多摆几件设施 | 先升那一类设施的持有上限，再花毛球购买。 | 四类设施各管各的数量；升级速度或扩房间不会自动增加上限。 |
| 看看猫又吐了什么怪东西 | 猫产毛球时，偶尔还会带出“猫猫辞职信”“量子纸箱”这样的梗藏品。 | 喜欢的留下，不想留的卖成毛球；首件会记进图鉴。 |
| 更容易遇到收藏物 | 升级猫种、手动或精灵对应的物品爆率，也可以升级幸运猫铃架。 | 更常掉东西；手动和精灵的升级分别管自己触发的那次出货。 |
| 想要更好的东西、卖得更贵 | 升“更好的物品爆率”，或者手动树里的物品售价倍率。 | 前者让掉出来的收藏更容易是高档货，后者让收藏卖得更贵，和代币不是一回事。 |
| 把房间布置得更舒服 | 摆上猫窝、猫抓柱和装饰设施，再给它们升级。 | 不只菜单数字变大：东西真的出现在房间里，还能让照料更快、毛球更多。 |
| 换个小游戏玩玩 | 去纸箱里找配对玩具，或者根据提示猜一句猫语。 | 玩的时候自动工具照常工作；回来看看攒了多少，再挑能买的升级。 |
| 临时加一把劲 | 从物品栏使用限时道具，比如加快自动照料的“羽毛狂欢券”。 | 一段时间内赚得更快，或更容易出收藏；想什么时候用，由我决定。 |
| 想继续强化以前的猫和精灵 | 回到原来的属性节点继续升级，不用再找一条同名分支。 | 树从下往上长；买完主节点就能看下一节点，旁边的强化想买再买。腾出的位置放逗猫棒、暖炉等新东西。 |
| 想多养某一种猫 | 去那种猫的分支里升持有上限，再花毛球邀请。 | 房间没有共用的总猫数上限；短毛猫满了，不会挡住我买长毛猫。 |
| 用代币抽点惊喜 | 打开独立的扭蛋页面，花代币抽收藏物。 | 抽到的收藏物会给全局加成，不用在房间里摆出来，也不需要在升级树里买扭蛋节点。具体奖池还在设计中。 |
| 把猫咪乐园越养越大 | 分别升级每种猫的数量上限，请来不同的猫，添工具、补图鉴、摆新设施。 | 从自己摸一只，变成满屋猫咪各自享受照料，毛球和惊喜不断出现。 |

本文是当前策划的口语版，不代表功能已经做完；具体藏品、设施、小游戏和道具名称仍可调整。详细规则见[简明策划案](../策划归档/2026-09-17_史莱姆养殖与生产线/00_简明策划案.md)。
