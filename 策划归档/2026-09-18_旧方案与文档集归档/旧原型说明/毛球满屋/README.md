# 毛球满屋 · 独立 Godot Demo

2026-09-15，依据[摸猫增量策划00 v0.9](../摸猫增量策划案/00_简明策划案.md)建立。这里是新工程，不使用舰队、刮地皮或旧经营项目的脚本、存档和启动配置。数值为策划中的EA候选，不代表最终平衡。

## 打开与游玩

用 **Godot 4.6.2或兼容版本**导入本目录的 `project.godot`，按 **F5**。入口为 `scenes/main.tscn`。

1. 选择“开始新的小猫生活”。
2. 鼠标悬停在猫身上来回移动，**不需要按键**。静止不增加满足度；离开保留进度。猫的整体摇摆／蓬大表达进度，不显示进度条。
3. 收到毛球后，在成长树升级徒手产毛、邀请第二只猫。免费研发毛球精灵，再在右栏购买真实精灵。
4. 精灵会走到猫旁边照料；你可以摸另一只猫。完成这段后会提示基础闭环完成，可以继续玩。
5. 成长树从下往上连续研发，旁支不阻挡推进。继续解锁长毛猫、逗猫棒、静电猫、暖炉与静电精灵。
6. 固定设施购买后到“摆放／收回设施”里手动摆下。右键取消摆放；库存也占本类数量。
7. 第一次真实自动产出后开放纸箱配对。小游戏里有房间预览，精灵继续赚钱；退出后可续同一局，不重复扣券。

右栏支持滚动。Esc打开暂停；小游戏中Esc也是真正暂停。库存与小游戏不暂停，成长树、摆放、设置和菜单暂停；失焦自动暂停并清除鼠标基准。

## 当前可玩的范围

- 短毛、长毛、静电猫及各自三种毛色；颜色只影响外观。
- 真实移动的普通精灵和静电精灵、手动摆放的逗猫棒和暖炉；每类独立持有上限。
- 自下而上的同一张主链树，手动／猫种／工具性能分支；没有产量一级、上限一级、满级或生产事件前置。
- 静电同时让范围内其他猫额外产出，包含移动猫，不清空其满足度、不递归传导。
- 梗收藏概率掉落、首次／连续保底、首件锁定、出售与永久发现记录；收益保留小数。
- 三件可见增益装饰；本Demo固定摆在预留位置。
- 六箱三对的纸箱小游戏、游玩券、续局、单次奖励；三种可使用临时道具，真正暂停时冻结计时。
- 开始菜单、新游戏／读取、手动保存、自动保存和退出保存；柔和的产毛提示音与毛球吸入特效。

**尚未开放的内容：**招财猫正面率、代币概率分支、扭蛋奖池与费用、后两种手部形态均未定，不擅自填数值。树保留招财主体及分支位置，邀请和未定分支不收费；独立扭蛋入口只解释当前状态。没有把招财猫做成普通产毛猫，也没有默认50%正面率。

这是简单闭环原型，不是文集全量版本：暂无猫语小游戏、免费练习局、收藏自动出售、任意家具搬动／收回、图鉴独立大页面或正式美术。房间采用程序化二维图形与安全区域选位，暂无复杂家具绕障；当前定义的猫种上限足以在同一地毯承载，不设置额外总猫数购买限制。

## 代码入口

| 文件 | 职责 |
| --- | --- |
| `scripts/data.gd` | 猫种、主节点顺序、已定义分支与价格；参数来源以策划00为准 |
| `scripts/model.gd` | 抚摸／猫状态、产出结算、自动化、交易、配对、道具、保存；不依赖画面粒子 |
| `scripts/room.gd` | 程序化房间与猫、整体反馈、世界坐标鼠标检测、摆放预览 |
| `scripts/main.gd` | 主界面、成长树、购买、库存、小游戏、暂停与输入隔离 |
| `tests/test_demo.gd` | 逻辑边界、存档、范围效果及零资金闭环模拟 |
| `tests/render_demo.gd` | 真实鼠标移动、引擎窗口截图、暂停／后台运行检查 |

人工位移只在同一只可摸猫内累计，并在每帧统一受速度上限约束。满足时由唯一入口结算；视觉毛球不发钱。普通精灵和人工共同照料时只采用最后达标来源的收益分支，共同照料不冒充独立自动收入。范围奖励保留独立来源，不重触发猫技能。

存档为本项目 `user://furball_demo_v1.save`，格式版本1。保存猫位置／进度／换位目标、工具分配／CD／摆放、各级分支、钱包、收藏保底、小游戏固定题面与奖励、消耗品、效果剩余时间及随机数状态。无离线收益。设置当前仅在本次运行生效。旧游戏存档不读取、不迁移。

## 验证

Godot 4.6.2、Windows、Compatibility、RTX 5060：

```powershell
godot --headless --path . --script res://tests/test_demo.gd
godot --path . --script res://tests/render_demo.gd
```

将 `godot` 替换为本机Godot可执行文件路径。在当前工程目录运行。

- **42项逻辑检查通过**，涵盖静止、单帧封顶、保留进度、移动锁定、主链零旁支推进、独立上限、静电不递归、保底、交易、防重复领奖、存档随机状态、工具CD和暖炉重叠。
- 零资金策略模拟：先升徒手产毛、邀请第二只猫，再购精灵；约38.2秒购入精灵，约49.2秒完成首次独立自动产出的基础闭环。此为程序操作时间，不是承诺真人一分钟完成，亦不表示后续内容只能玩一分钟。
- 真实窗口测试使用鼠标移动事件，不发送鼠标按键，验证可抚摸；成长树和菜单冻结，小游戏保持模拟；无脚本报错。
- 预览截图位于 `reports/room_start.png`、`room_grown.png`、`tree.png`、`minigame.png`等。成长画面用测试资金构造，只作界面展示，不冒充零资金路线。

未做无讲解真人试玩。下一步优先验证摸猫舒适度、换位距离、主链价格与自动化等待；新增规则和参数应统一维护策划00，01同步拆解，不直接复制dc数值。
