# 07｜舰桥界面与交互

## 构图与舰船缩放

**已确认：**保留舰桥舷窗：上方舰队、中间炮火通道、下方星球弧面、右側常驻操作栏。现有舰船缩小至四分之一，显示更大舰队；星球有真实可读的旋转效果。

**EA建议：**四分之一暂解释为宽高尺寸各缩至原比例，具体值见06；不是四分之一面积。炮口闪光、描边、选中框和鼠标命中范围单独保持清晰。舰名在悬停、选中或舰队列表中显示，不给每艘小船常驻长标签。按编队整齐分列，新舰从边缘补入，不因购买一个单位把所有舰船打乱。

星球纹理、设施和资源跟随经度转动，近侧出现地标视差与地平线遮挡；不以普通结构反复重生冒充星球旋转。焦黑烟区与有资源区在形状/纹理上区分，不能只靠颜色。

## 右栏与可视化树

顶部固定钱包、指挥占用、当前星球和普通资源剩余；中部为舰船/武器/装备/全局四类入口及所选节点的购买与升级详情；底部常驻星球环形罗盘、A/D移动提示、最终宝库阶段与驶离按钮。

点击“升级树”展开可缩放树图，主体与分支层级见12。右栏仍常驻，提供当前选中节点的升级按钮；不把可视化树降为旧版一长串无关系卡片。

武器主体按12的前置链连线；尚未满足时显示“先研发上一武器”，并注明“不要求满级”。性能支线保留自己的等级与价格，不能让树图误导玩家先升满才能继续。

舰级主体提供“编辑模板”“改装现役”“购买”入口。自定义界面显示舰体、普通槽/特殊槽、可拖入模块、总价、指挥点、甲/生命、对地与拦截能力。普通槽自由使用，母舰禁装理由直接显示。对库存、额外购买和现役改动分别列账，确认前显示总费用。

## 操作

| 输入 | 行为 |
| --- | --- |
| 无输入 | 舰船自动垂直轰炸，掠袭舰自动回收，防空自动拦截 |
| A / D 按住 | 绕星航行，持续转动星球；基础轰炸不停 |
| 屏幕左右航行按钮 | A/D的鼠标替代，按住移动，便于纯鼠标试玩 |
| 左键固定防御/宝库 | 持久集火，显示参与编组；不要求重复连点 |
| 右键 | 取消集火，恢复垂直作业 |
| 左键普通地面 | 显示地区存量；不额外发炮、不增加收入 |
| 左键资源/宝藏 | 标记优先回收 |
| 中子炮就绪后点目标 | 未自动化时执行一次手动发射，独立于普通持续集火 |
| 滚轮 | 右栏内滚列表；树图内缩放，不改变星球角度 |
| Esc | 关闭当前子窗口→暂停菜单→返回舰桥 |

区分“选中集火”与“已准备中子打击”模式，后者显示范围预览并允许右键取消，不让任意UI点击发射中子炮。宝藏与敌人重叠时按明确光标提示选择，选中已掉落宝藏不改变集火对象。

## 无长教程的教学

开局及跨星教学的触发、短句、完成判定与跳步规则统一见 [13_开局引导与机制教学](13_开局引导与机制教学.md)，节流参数见06。UI只呈现当前相关步骤，采用右栏目标卡、对象轮廓和短句定位；不弹全屏说明，也不要求先点击才开火。

首次推荐购入舰保留空槽供现役改装教学，初始赠送舰保持原配；若玩家已买满槽或提前改装，不再指向不存在的空槽。引导卡提供“定位”“稍后”“关闭操作引导”，设置可恢复；正常敌情与资源状态提示独立保留。

## 反馈与菜单

普通命中显示资源喷出；特殊结构/来袭单位显示实际伤害和独立甲/生命条。小炮保持清脆反馈，大舰齐射、激光、中子炮形成不同形状、节奏和声音；数字聚合与震动上限见06。敌袭警示始终高于己方粒子，不让舰队越强越难看清威胁。

Esc设置、升级树、配装与确认窗口暂停模拟，防止阅读时挨打；藏品窗默认不暂停并提示。所有覆盖窗口阻止背景输入，关闭后不继续执行此前按住的A/D。设置含静音、降低震动、减少粒子、合并数字。阶段奖励不连续强抢焦点。
