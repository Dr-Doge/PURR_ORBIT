# 12｜可视化升级树

## 树的层级与职责

**已确认：**舰船、武器、装备、全局升级分别独立；每个项目有自己的主体及分支，不能升级一种炮顺带增强其他炮。

**已确认（本次修改）：武器主体层层解锁，必须先解锁上一种武器，才能解锁下一种；不要求上一种武器满级。**“解锁”指完成主体研发，不要求购买、安装或持有实物，也不要求购买任何攻击力/装填等级；出售模块不会撤销研发前置。星球许可与研发费用仍需满足，取得后续许可不能跳过前置。

**EA建议顺序：动能炮 → 防空炮 → 穿甲炮 → 激光炮 → 中子炮。**防空放在前段，保证第二星首次敌袭前可购买拦截能力；穿甲紧随其后用于导弹井。具体顺序为本稿安排，用户确认的是逐级解锁规则。武器主体之间有前置，主体内性能分支仍独立，不共享等级、不要求满级；本次不把该前置规则扩展到舰体或装备。

**EA建议：**四个页签共享树形交互。主干负责解锁新的主体，主体子节点负责购买/配置，向外分出性能支线；支线等级不作为其他项目必须购买的前置。星球抵达提供研发许可，许可不等于免费舰体或武器。

```text
远征进展（只发许可）
├─ 舰船：护卫舰 → 巡洋舰 → 战列舰 → 歼星舰
│          └生命/护甲   └生命/护甲   └生命/护甲   └生命/装填/特殊槽
│        空天母舰 ─ 生命 / 护甲 / 机库
│          └ 掠袭舰 ─ 载量 / 航速
├─ 武器：动能炮 → 防空炮 → 穿甲炮 → 激光炮 → 中子炮
│          每个主体独立分出：攻击力 / 装填
├─ 装备：衬板 / 损管舱 / 供能器（候选）
│          每个主体独立分出：该装备强度
└─ 全局：指挥容量
           中子自动火控（仅歼星舰中子炮）
```

上图舰体箭头表示展示顺序和许可进程，**不要求先满级、拥有或消耗上一舰体**。母舰与运输线平行开放，避免被攻击线解锁卡住回收。中子炮已确认装歼星舰特殊槽，研发、槽位解锁、购买安装与自动化分别设节点。

## 三球开放顺序（EA建议）

- 教学星：护卫舰、母舰、掠袭舰、动能炮与基础舰体/武器/运输分支；先展示购买，再引导修改配装；指挥扩容首级可见。
- 第二星：抵达即给巡洋舰、防空炮、穿甲炮许可；武器必须先研发防空，再研发穿甲。完成首个固定防御后给激光许可，且必须已研发穿甲才可研发激光；激光不是第二星通关必需解法。
- 第三星：抵达给战列舰与歼星舰许可；支持大量购买、批量配装和高阶分支。研发中子需同时满足已研发激光、抵达第三星及歼星舰主体已研发；不要求激光满级或安装。歼星特殊槽另行解锁，首次手动发射中子后可购独立自动火控。常规炮也能通过全部目标，不强制购买中子。
- 装备候选随首次改装教学开放基础项，供能器随第二星开放，不把必需防空槽位锁在装备支线里。

## 节点与输入

节点明确显示状态：前置武器未研发、未获许可、可研发、已研发、可升级、当前等级、满级。武器主干使用有方向的前置连线；锁定节点显示“先研发××”，已满足前置但缺星球许可时显示实际许可条件。右侧常驻栏显示所选节点的效果、当前→下级、价格和受影响对象；不可购买时显示具体原因，不只变灰。

点击主体打开舰级配装或模块详情，点击支线升级当前项目。长按和滚轮不自动花钱；批量升级须显示总价并确认。树支持拖动和缩放，进入树时暂停战斗，保持舰队损伤与冷却。退出回到原右栏滚动位置。

全局默认只扩指挥，不放“全部伤害×倍”的通用节点吞掉独立武器分支的意义。升级数值与等级上限统一读取06。
