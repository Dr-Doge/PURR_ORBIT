版本 v0.3.2。事件驱动，不以倒计时强制结束；时间目标、价格、数量仅见06。本篇各阶段细节为EA建议。各阶段教学触发、提示短句及适应玩家操作的规则统一见13，不以本表阶段顺序硬锁玩家。

## 三颗星球的完整体验

| 阶段 | 玩家实际看到和做什么 | 完成事件 |
| --- | --- | --- |
| P1自动第一炮 | 初始舰队已轰炸，掠袭舰搬回资源，观察收入 | 首笔到账 |
| P1首次移动 | 当前地面焦黑停产，按A/D找到明亮区域 | 在另一地区提取资源 |
| P1购买与改装 | 买护卫舰，扩指挥，打开模板/现役槽位，装入或换出动能模块；尝试载量升级 | 至少一次购买、一次有效改装、一次分支升级 |
| P1最终宝库 | 所有地区掠空，罗盘标宝库，航行并集火 | 宝库击破，稀有物与金属运回 |
| P1驶离 | 显示本星已无资源，突出驶离与下一星情报 | 玩家主动前往P2 |
| P2防空准备 | 抵达给巡洋/防空/穿甲许可，在安全区域先研发防空、再研发穿甲并配装；不要求武器升满 | 部署防空与穿甲能力；非强制弹窗锁 |
| P2处理威胁 | 导弹预警、敌机出现；防空自动拦截，玩家集火固定炮；穿甲破井后普通火力接管 | 固定防御摧毁，理解甲伤/肉伤 |
| P2扩军 | 树上扩指挥、造多艘巡洋舰、扩母舰与掠袭舰，获得激光许可 | 新增炮口和吞吐产生明显提升 |
| P2结算 | 绕完整颗星球，宝库出现、集火、回收 | 驶离至P3 |
| P3舰队高潮 | 研发战列与歼星，批量配装，继续升级独立武器和运输 | 形成大规模混编舰队 |
| P3中子演示 | 先确保激光主体已研发，再研发中子、解锁歼星特殊槽并安装；手动打击后可购独立自动火控 | 观察高强度爆破与资源涌出，非通关硬条件 |
| P3收官 | 处理更密敌袭，掠空全部地区和防御，攻破最终宝库 | 全部货物入库，展示远征成果 |

P1的操作教学标记用于统计与提示，不因跳过改装就禁止离开；玩家能自由选择消费顺序。P2/P3若阵容缺解法，可继续采集未掠地区或原价改装，不能以宝库内唯一蓝图锁住宝库自身。有限预算恢复见06/10/11。

完成Demo后可查看舰队、树和收藏，允许开始独立新远征；不自动重置或在已枯竭星球偷偷刷新资源。正式版继续寻找更多星球，当前不制作占位第四星入口。

## 开发拆分与交付边界

1. 先验证旋转＋有限地表＋自动垂直轰炸＋最终宝库＋跨星球账本，替换旧版再生结构。
2. 加入舰体槽位、模板/现役改装、指挥上限、四类升级树及母舰机库，验证有限资金可纠错。
3. 加入三类敌袭、自动拦截、特殊目标集火、失能与撤离恢复。
4. 补齐激光、歼星特殊槽和中子、三球节奏、批量操作与大舰队表现，做完整试玩。

以上为实施顺序；用户后续已明确授权读取新文集并实装`fleet_demo`。已打通三球原型并覆盖六种舰船与五种武器；这不等于下方全部细项和真人体验均已验收。非武器装备仍为EA候选。

## 必须验收

- 星球转一圈设施数量与资源总额不变；普通地面无生命条，黑区不再产出；没有索敌偷移落点。
- 炮弹按命中时角度求交；激光按固定伤害步结算；中子不重复覆盖同一地区；高火力不超发预算。
- 离屏资源和在途货物保留；最后一份金属能收回；宝库只生成一次，未击毁防空不能误触发终局。
- 指挥、机库、槽位、模块库存约束同时有效；模板编辑不免费改现役；退役/重购不能刷新生命或冷却。
- 每个主体与分支只作用于指定项目；主干许可/研发/实物购买明确区分；中子只能装歼星特殊槽。
- 未研发上一武器时，后续武器即使有许可和资金也不能研发；上一武器刚研发、攻击/装填均未升级时即可满足前置。出售或拆下上一武器不撤销前置，存读档保留研发链状态。
- 防空能拦截导弹/敌机，不能打地面；普通舰炮不自动索敌防空设施；集火与中子手动指令不串线。
- 空袭并发有上限，转动和存读档不清空威胁；离开区域的固定炮停止发射但不恢复血量。
- 钱花光、只买运输、全部船失能、卖掉付费武器、保留全部首件收藏等情况下仍可恢复推进。
- 先验证逐步资金可达而非只算总预算；测回收尾声、航行搜索和修复停顿，不能把等待当作增量内容。
- 菜单内不挨打、输入不穿透；高数量模式仍能看清炮口、危险与资源；提供降低特效选项。
- 引导须通过13的按序、跳步、误操作、跳过与跨星恢复路径；只验证真实到账、航行后产出、现役安装和拦截结果，不把看过提示当作学会。全过程不额外赠资源、不重复扣款、不更改敌袭时钟。
- 实测06的教学时间目标，分别记录包含读界面的总时长与暂停扣除后的模拟时间；初始满槽舰、购买满槽舰、模板编辑但未改现役等情况均不能卡住教学。

新存档须版本化，记录各星地区存量/设施状态、旋转角、最终宝库阶段、船体ID与损伤/冷却、模块实例/模板、指挥/机库、每条分支、导弹/敌机/波次、掉落/在途/库存、解锁与免费资产恢复标记。不默认迁移v0.2存档；失败迁移不覆盖旧档。

另存13定义的引导版本、已验证事实和关闭偏好；读档后按当前世界状态选择相关提示，不重新执行教学交易或重置阶段。
