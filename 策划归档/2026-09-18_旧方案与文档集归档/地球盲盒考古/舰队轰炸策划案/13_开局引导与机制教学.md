# 13｜开局引导与机制教学

版本v0.3.2。用户要求设计开局引导；下列具体步骤、文案和调度均为**EA建议**。2026-09-11已实装状态驱动提示、真实事实、定位和关闭／恢复；部分反馈与节流细节未全量验收，尚未做无讲解真人试玩，边界见09。目标是让玩家尽快会玩，并能跳过已掌握的操作，不要求完整读完机制说明。

## 引导原则与呈现

以“先看到结果→产生具体疑问→提示一个动作→验证变化”组织。第一星学会赚钱、航行、扩军与夺宝；第二星遇敌后学防空、研发链与穿甲；第三星再介绍特殊槽和中子。不会在开局讲完所有舰种和数值。

进入后立即自动轰炸，不加必须读完的背景故事或“点击开始开火”。屏幕角落用副官短句赋予身份：“可汗，舰队已就位。夺取资源，壮大部族。”右栏固定当前目标，舷窗只突出当前动作对象；首次弹道、运输和到账的视觉关联见07。

一张引导卡只包含目的、动作、预期结果，可点“定位”将右栏滚到对应按钮，不替玩家购买。卡片不遮住瞄准、危险或资源反馈；不画全屏遮罩锁住无关区域。需要读树图、配装时沿用07暂停，普通提示不暂停游戏。

## 第一星：用完整掠袭教核心循环

以下顺序是推荐路径。实际调度按状态与优先级执行，不能为了顺序让玩家在已经枯竭的地面等待购买提示。

| ID / 理解目标 | 出现条件与引导对象 | 玩家可见短句 | 完成判定与结果 |
| --- | --- | --- | --- |
| G00 我是谁、现在做什么 | 新远征进入舰桥；观察一轮自动炮击 | “可汗，舰炮会自动轰炸。掠袭舰正把战利品运回来。” | 真实普通资源到账后完成；高亮钱包和对应返航轨迹，不要求确认弹窗 |
| G01 地面资源不等于现金 | 第一堆资源已落地、尚未到账；指向货堆与运输标记 | “这是待回收的金属。运回舰队，才能用于扩军。” | 该批资源到账即收起；不要求逐个点击资源。玩家提前理解或到账过快时不补播旧说明 |
| G02 移动才能继续掠袭 | 炮口下方地区耗尽；箭头指向邻近有资源方向，并突出A/D | “这里已被掠空。按住 A / D，航向明亮的地表。” | 航行后命中另一有资源地区并实际产出；只按一下键不算理解。鼠标航行按钮同样有效 |
| G03 买船会直接增加炮口 | 首笔收入后，钱包与指挥点足够购买推荐护卫舰 | “添一艘护卫舰，让更多炮口替你掠夺。” | 购买成功、新舰入场并实际开炮；只打开商店不完成 |
| G04 配装会改变现役舰 | G03后推荐舰有空槽；指向其“改装现役” | “这艘船还有空槽。装上动能炮，火力会立刻增加。” | 真实安装并确认，返回后新增炮台射击。仅改模板、预览或退出不算完成 |
| G05 升级只强化指定项目 | 已扩军或玩家主动打开武器树，且可负担动能攻击分支 | “选择动能炮的攻击分支。所有动能炮一起变强，其他武器不受影响。” | 实际提升该分支并在面板显示前后效果；已先升级则跳过，不再要求再买一级 |
| G06 运输与指挥是不同瓶颈 | 首次回收积压，或计划购买导致指挥不足；只提示当前真实原因 | 积压：“资源在地面等船，提升掠袭舰载量。” 满指挥：“可汗的指挥已满，扩充指挥容量才能继续增舰。” | 原因消失或相关升级生效后关闭；不要求两项都买，不以教学名义制造假积压或假上限 |
| G07 宝库需要指挥集火 | 第一星全部普通地区耗尽，最终宝库已出现 | 离屏：“宝库已暴露，沿罗盘驶向标记。” 可见：“点击宝库，下令舰队集火。” | 真实建立集火且造成伤害；宝库击破后切到回收状态，不要求连续点击 |
| G08 战利品回收与下一星 | 宝库击破，稀有物待运回 | “宝藏正在运回。结清战利品后，我们前往下一颗星球。” | 收藏登记及全部货物到账后突出“驶离”；玩家主动驶离进入第二星，完成核心引导 |

G00/G01是同一过程的先后反馈，不同时叠两张说明。G02可抢占任何普通推荐；恢复产出后再考虑尚相关的购买建议。G03—G06都不是星球结算前置，玩家可以先掠空再扩军。

### 首次购买与配装的可执行路径

初始赠送护卫舰不改，仍用06原配。首次推荐新增舰使用“单炮护卫”模板，保留空槽；买船后在现役舰补装动能炮。总支出与06原双炮护卫相同，拆为舰体＋首炮、后补炮，不赠免费模块、不加教学奖励。玩家可直接选择双炮或自己配装。

若已买满槽舰，不让G04要求不存在的空槽：优先接受玩家已做过的有效安装；否则只保留可选“查看配装”入口，等第二星母舰空槽安装防空时验证配装理解。不要为了完成任务强迫拆下再装回同一门炮。

若玩家只改了模板，提示“模板用于以后买船；要改变这艘船，请进入改装现役”，不扣费、不判完成。若购买顺序不同或钱不足，推荐切回当前可掠地区；全星普通资源已耗尽则优先处理宝库，不用“再赚钱”把玩家引回黑区。

## 第二星：有敌情才教作战配置

| ID / 理解目标 | 触发与动作 | 短句 | 判定 |
| --- | --- | --- | --- |
| G10 研发与实物不同 | 抵达后已有防空许可；定位武器树的防空主体 | “敌机会袭击舰队。先研发防空炮，再把它装到船上。” | 防空主体研发完成；接着定位现役母舰空槽，购买/安装模块才进入G11 |
| G11 防空自动拦截 | 已装备防空且出现真实导弹或敌机 | “防空炮自动拦截来袭目标，不参与地面轰炸。” | 首次真实拦截击毁目标；没有来袭时收起说明等待，不额外刷教学敌人 |
| G12 武器逐级研发、不必满级 | 防空主体刚研发，穿甲主体前置满足 | “穿甲炮已可研发。上一种武器无需升满级。” | 树连线点亮并展示可研发状态；玩家研发穿甲后完成。G10/G11尚在占焦点时仅显示树内标记，不抢弹窗 |
| G13 固定炮需要主动清除 | 固定防空炮可见且开始预警 | “这是敌人的发射源。点击集火，摧毁它。” | 目标被集火击破；不要求用防空武器打地面 |
| G14 甲伤与肉伤不同 | 导弹井可见，或首次普通集火对厚甲低效 | 未备穿甲：“厚甲会挡住普通炮，先研发并安装穿甲炮。” 已备：“选择穿甲组，先击破护甲。” | 护甲被击破后提示“护甲已碎，普通火力可接管”；目标最终击破。不得在没有穿甲武器时高亮不可用编组 |
| G15 失能不等于存档失败 | 首次舰船失能、或玩家主动点紧急撤离 | “先撤到安全轨道修复。舰体和装备都会保留。” | 完成真实撤离修复；玩家未受损不强制演示失败 |

第二星到达后的敌袭时钟沿用06，只在既有暂停窗口中暂停，不因引导重播而重置。提示必须赶在第一波前给出防空研发与安装入口。对仍未备好防空的玩家持续显示可执行解法和撤离入口，不暗加无敌，也不要求靠挨打解锁防空。

武器依赖规则归12；这里用一次从防空到穿甲的实际解锁解释规则，不要求玩家升满动能或先买防空性能等级。许可、研发、装模块、升性能分开反馈，不用同一个“已升级”通知混淆。

## 第三星：只教新能力

批量购买沿用已掌握的舰船流程，仅在批量预览中标出合计费用和指挥占用。首次解锁歼星舰时提示“普通槽装常规模块，特殊槽装中子炮”，依次引导满足激光研发前置、研发中子、解锁特殊槽、购入安装，已完成的步骤直接跳过。

中子炮首次就绪时提示“选择中子打击，再点目标”，进入目标预览而不是自动替玩家开炮；第一次手动发射后突出独立自动火控节点。没有购买歼星舰/中子时不催促、不阻止最终宝库与通关。

## 调度、跳步与纠错

引导采用事件与状态判断，不采用按时间播放的固定演出。事件至少涵盖：资源到账、地区耗尽、航行后产出、舰船购买与首射、模块安装、分支升级、研发完成、敌袭出现/拦截、集火命中、宝库回收、星球驶离及修复完成。

建议状态：未适用→可提示→展示中→已验证，另记录已跳过/稍后提醒。保存引导版本、状态与对应世界事实；存读档不重发奖励，不重复执行购买，也不把“看过”冒充“会操作”。价格、许可、可用槽位从当前状态读取，不写死在提示句里。

- **优先级：**立即威胁/失能 → 无收入的枯竭或无回收能力 → 可驶离/宝库 → 当前用户打开界面的说明 → 非必要升级建议。已有模态窗口不被自动切页，紧急信息先缩为边缘提示。
- **顺序自由：**玩家提前航行、购买、配装或研发，按历史事件补记，后续不要求重做。一次真实操作可完成多个相关教学事实，但只播当前最必要的反馈。
- **主动跳过：**卡片提供“稍后”和“关闭操作引导”，设置可重新开启。跳过不发奖、不改变许可、资源或敌袭。关闭教学后仍保留资源枯竭、敌情、价格不足等正常游戏反馈。
- **恢复引导：**根据当下缺少的能力继续，不从开局重播；已掠尽的第一星不要求返航补课。阶段结束收起失效任务。
- **无动作：**按06提示节流规则先增强当前定位，再提供可选说明；从不替玩家移动、花钱或旋转星球。升级不可买时先解释真实前置或余额。
- **失败操作：**点普通地面不发额外炮、母舰放轰炸炮不合法、中子未解锁槽位不可安装；给对应短句，不清空编辑内容或重复弹框。

帮助入口保存简短“作战手册”：自动轰炸、A/D航行、运输到账、购买与配装、研发与分支、集火与拦截、驶离。可按当前问题直达，完整规则仍以系统文档为准。

## 如何验证玩家理解

无口头讲解观察新玩家：是否知道不用连点、能从焦黑区主动移动、能区分地上资源与钱包、购买后能找出新增炮口、能把武器装到现役船、知道无需满级即可研发下一武器，以及会把固定炮交给集火、敌机交给防空。

验收同时覆盖完全按提示、提前操作、全程跳过、误买配置、关闭后恢复、战斗中开配装、读档、只用鼠标、跨星未完成教学等路径。日志分别记录提示展示/关闭与真实成功操作，避免把点过“知道了”当成功。量化目标与时间窗口统一见06；本稿未做真人验证。
