# 舰队轰炸 Demo · v0.3.2 实装说明

更新：2026-09-11。当前开发入口是 `scenes/fleet_demo.tscn`，已从固定结构循环替换为三颗有限资源星球的远征原型。设计入口：[舰队轰炸策划索引](../舰队轰炸策划案/00_索引.md)。数值采用06号文档的 **EA建议**，实现不代表这些建议已经成为用户确认的最终设计。

## 运行与操作

用 Godot 4.6.2 或兼容版本打开本目录的 `project.godot`，F6运行 `scenes/fleet_demo.tscn`。项目当前 F5 默认入口也是此场景。已在 Windows、Godot 4.6.2 Compatibility / RTX 5060 上运行验证。

- 开始菜单选择新远征或读取新版存档。不会自动续玩上次进度。
- 普通轰炸从开局自动进行。按住 **A / D** 或右侧方向按钮绕星航行；按住不需要反复点击。
- 点击红色固定防御或金色最终宝库持续集火。右键取消集火／中子瞄准。可选择全部、穿甲或常规轰炸编组；防空独立工作。
- 点击舰船或打开舰队管理改装。模块支持拖拽入槽，也可先点模块再点槽。模板用于未来购买，现役改装另行确认。
- 研究树有舰体、武器、装备、全局四类；可平移缩放。武器研发依次解锁，前项无需升级或安装。
- 藏品舱持续作业；研究、配装、交易确认、手册和菜单暂停模拟。Esc返回；失去窗口焦点自动暂停，清除按住输入。
- 中子炮需要歼星舰特殊槽。先手动瞄准并实际开火，再解锁独立自动火控。
- 每星资源与固定防御耗尽后出现唯一宝库。击破宝库、清除残余空中威胁、回收所有金属与藏品后可驶离。第三星结束显示远征成果，没有第四星占位入口。

## 本版已实现

| 系统 | 实际行为 |
| --- | --- |
| 有限星球 | 三星、8/16/24地区、360°逻辑经度、90°可见弧、45°/秒航行；半径逐星增加 |
| 地表轰炸 | 普通地面无血条、不再生；炮弹按命中时角度落地；同地区共享预算；装饰、焦黑状态与掉落随经度转动 |
| 舰队 | 护卫、巡洋、战列、歼星、母舰与掠袭舰；主舰宽高约为旧版四分之一；稳定网格阵列 |
| 装备 | 动能、穿甲、激光、中子、防空；装甲衬板、损管舱、供能器；舰体、武器、装备分支分别成长 |
| 配装交易 | 独立模块ID、普通／特殊槽校验、空槽与重复模块、多个同型模板、批量建造、单舰及全体同型舰整批改装；先用库存模块再购新件，确认时整笔交易 |
| 容量 | 6→12→24→48指挥；母舰共享机库等级、各自泊位；掠袭舰购买、转移、退役与容量／速度升级 |
| 火力职责 | 普通炮不自动索敌固定防御；甲伤／肉伤分开且不溢出；激光固定2秒、20步结算后装填；防空预留拦截伤害；中子主目标加最多两个半效邻近目标 |
| 后勤 | 地表、在途、到账分开；出发预留货物和锁定航程；离屏运输；藏品独占一趟，可点击优先回收；母舰失能时在途任务仍返回 |
| 敌袭与生存 | 固定防空、导弹井、飞机波次；可见区预警；离屏固定炮停止发射；飞机并发上限；舰船失能保留，8秒免费撤离维修，期间冻结战场与运输 |
| 藏品 | 每星独特藏品，回收后入库、默认锁定、可解锁出售，售出仍保留图鉴记录 |
| 引导 | 根据真实到账、移动后产出、新舰射击、实际新装模块射击、研究与拦截事实调度；可稍后／关闭／恢复，满槽舰不会卡在补装教程；跨星防空和中子提示 |
| 表现 | 程序化舰桥与曲面地表、导弹／激光／中子演出、带重力的资源碎片、到账合并跳字、基础炮声音效；右栏可滚动 |
| 存档 | 新远征／读取、30秒自动保存、手动保存与退出保存；版本及核心嵌套数据验证，临时文件原子替换 |

退役退款为实际支付价；研发分支不退款。为阻止重购刷新战斗状态，本轮采用较保守的实现：**初始三艘赠舰不可退役；受损舰须先免费维修；装填或激光发射中的资产暂不可退役，激光发射中不可改装**。模块仍可卸回仓库；冷却在仓库继续流逝。免费救援可恢复被卸掉／卖掉的初始动能火力。该限制是本轮原型差异，不应误写为策划已确认规则。

## 新成员与 AI 的代码入口

| 文件 | 职责 |

| `scripts/fleet/module_slot.gd` | 模块拖拽数据与槽位放置 |

| `tests/test_fleet_v3.gd` | 边界回归、经济守恒、零资金逐步远征、规模模拟 |
| `tests/render_fleet_v3.gd` | 实际窗口渲染、按键／暂停检查、研究树连接、配装报价、截图 |

旧 `scripts/fleet/main.gd`、`model.gd`、`board.gd` 和 `tests/test_fleet.gd`、`render_fleet.gd` 保留为 **v0.2历史原型**，当前场景不引用它们。不要给旧文件补功能后误以为新场景已经更新。刮地皮EA与旧经营工程仍是历史项目，未将其清理、货币或盲盒流程混入本版。

模拟账本的不变量：当前星球的未提取地表 + 地表金属堆 + 在途金属 + 已送达金属 + 尚未释放的宝库金属 = 当前星预设预算。钱包另受消费、退款和藏品出售影响，不用作守恒总额。粒子数量与经济数额完全分离。

2026-09-11实测：

- **171项逻辑检查通过**。覆盖自动首笔收入、360°旋转与有限预算、命中时落点、甲伤不溢出、激光周期、中子范围／装填、研究链、槽位、库存复用与整批失败回滚、伤损／冷却、保存覆盖与坏档拒绝、免费救援和引导事实。

- 真实窗口渲染通过研究树连接、按键清除、暂停冻结／库存持续运行等检查，无脚本报错。截图在 `reports/fleet_v3_*.png`，其中大舰队截图为48主舰＋96掠袭舰。

## 尚需试玩与打磨

- 仍为程序化二维视觉，无正式星球／舰船美术；藏品暂无独立3D揭晓场景。大规模掠袭舰仅绘制前96个，全部实例继续模拟。
- 引导已可用，但13规定的1.5秒完成反馈、各步骤独立跳过／历史状态面板与完整8／20秒条件节流尚未全量验收；当前是事实调度、定位增强、稍后及全局关闭。未完成无讲解真人试玩，不能宣称所有教学时间目标达标。
- 研究树已有主体与分支连线，跨类别前置用详情文字提示。配装可整批应用于所有同型号舰，尚不支持任意多选子编组。
- 当前按地区共享有限存量，未增加地区内独立可存档的撞击子带。抽取会使地区整体逐渐变暗，不等于每个装饰物有独立资源。
- 第三球模拟时间短于06的单星4—5分钟候选目标；真人操作和暂停决策可能延长体验。后续应先试玩再调数值，不用硬等待补时长。
