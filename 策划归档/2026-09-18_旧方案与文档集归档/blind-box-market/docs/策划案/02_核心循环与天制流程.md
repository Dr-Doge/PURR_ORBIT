# 02｜核心循环与天制流程

## 核心循环

**完成基础工作 → 获得小额现金 → 查看行情与订单 → 买入／持有盲盒 → 拆封或转卖 → 出售藏品／交付订单／配对合成 → 推进下一天 → 解锁更高系列。**

## 单局结构

- MVP 单局为 7 个游戏日，天数保留为可配置参数。
- 每天是一个回合，玩家主动点击“结束今天”后推进。
- 第 7 天结束时按现金、未拆盒回收估值与藏品市值计算总资产；订单和收藏只展示完成度。
- 无传统死亡；资金不足时仍会在次日收到基础快递工作。

## 每日六阶段

### 1. 早间播报

- 日期推进。
- 显示 1—2 条市场新闻：爆火、退潮、联名传闻或供货变化。
- 更新藏品报价、盲盒进货价和整盒回收价。
- 提醒即将到期的订单。

### 2. 基础工作

- 桌上送达 3 个普通快递纸箱。
- 玩家逐个拆开后，将纸板和填充物投入回收框。
- 每箱获得极少但稳定的现金，确保游戏不会软锁。
- 首日通过这一阶段完成无文字或少文字教学。

### 3. 市场决策

玩家在桌面终端查看：

- 今日可购买的盲盒系列和价格。
- 已持有未拆盒的今日转售价。
- 各主题趋势、新闻原因与最近三日走势。
- 当前订单、剩余期限与潜在奖励。

### 4. 购买与开箱

- 购买后的盲盒进入桌面待处理区。
- 玩家可立即拆封，也可保留到后续日期。
- 拆封后生成具体藏品，盲盒资产被消耗。
- 每个实体均按统一的“找封条 → 右滑 → 上滑取物”流程操作。

### 5. 处置与交付

藏品可执行：

- 按当日市场价立即出售。
- 留在库存，等待行情或订单。
- 交付符合条件的限时订单，换取高额回报。
- 配对组件集齐后，在仓库中合成为完整款；合成不可逆且不产生现金。

未拆盲盒可执行：

- 保留。
- 按当日整盒回收价转卖。
- 拆封并承担结果波动。

### 6. 日终确认

界面展示：

- 今日现金变化。
- 已实现收益和库存估值变化。
- 完成／过期订单。
- 下一日可能发生变化的模糊预告。

确认后保存并进入次日。

## 新手节奏

### 第 1 天

1. 桌上只有快递箱与回收框。
2. 玩家完成 3 次拆箱并获得约 9—12 元。
3. 市场终端亮起，可购买第一款入门盲盒。
4. 第一次购买后强引导完成一次盲盒拆封。

### 第 2 天

- 解锁持有与整盒转卖说明。
- 出现第一条明确利好新闻。
- 投放一个宽松期限的主题订单。

### 第 3 天以后

- 逐步解锁基准价为 100、1,000、10,000 与 100,000 的更高等级盒型，门槛为目标盒价本身——开出一件上一系列的稀有档（10 倍盒价）即达解锁线。
- 市场始终公开本系列完整权重；高等级盒内容物更多、奖励成倍放大。
- 系列四、五出现配对隐藏款，玩家需要在“卖出单件”与“保留合成”之间抉择。
- 新闻影响加大，史诗、隐藏与合成款允许更高的市场涨幅，订单条件也更具体。
- 不再强制教学，只保留上下文提示。

## 决策张力

每个回合至少要形成一个问题：

- 某系列走红时，是卖掉未拆盒获取稳定利润，还是承担 60% 常见低回报风险去追逐隐藏款？
- 开出配对单件时，是立刻按单件价兑现，还是赌之后开出另一半并合成为完整款？
- 订单即将到期时，是继续买目标盒，还是放弃订单保住现金？
- 史诗、隐藏或合成款上涨时，是立即兑现完成盒级跃迁，还是等待下一日继续膨胀？

## 结算评价

最终总资产只计算：

- 现金。
- 未拆盒按第 7 日回收价计算的市值。
- 藏品按第 7 日收盘价计算的市值；合成款按合成款收盘价计算，未合成的配对单件按单件价计算。

订单奖励和首次发现奖励到账时已经计入现金，不在最终结算中重复加分。完成订单数、收藏完成度和历史最高单笔成交额只作为独立成就展示。

分数仅用于单局评价，不引入长期局外养成，控制 Game Jam 范围。
