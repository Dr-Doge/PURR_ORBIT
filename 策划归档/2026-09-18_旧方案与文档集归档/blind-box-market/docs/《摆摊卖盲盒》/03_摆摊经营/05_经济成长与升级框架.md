# 05｜经济成长与升级框架

## 经济目标

- 金额能够被玩家一眼理解，不依赖万、亿等数量级制造刺激。
- 收入主要来自卖出实体商品，支出主要来自补货和摊位升级。
- 普通营业日可以稳定周转，隐藏款提高利润但不是继续游戏的唯一条件。
- 收藏选择有机会成本，但不会因保留一件喜欢的模型而立刻破产。

## 核心指标

- **现金**：唯一可消费货币。
- **摊位声望**：不可消费，来自成交、顾客满意和收藏展示，用于解锁位置、系列与功能。
- **收藏完成度**：长期目标和部分内容解锁条件，不作为货币。

不再使用“累计赚取资产达到天文数字”作为主要等级门槛。

## 初步价格锚点

以下仅用于首轮原型，待模拟后调整：

| 内容 | 建议区间 |
|---|---:|
| 初始现金 | 约 130 元 |
| 入门盲盒进货价 | 18—25 元／盒 |
| 各系列常规款基础市价 | 同系列盲盒进货价的约 1.5 倍 |
| 小隐藏建议售价 | 150—4,000 元 |
| 大隐藏建议售价 | 3,000—12,000 元 |
| 首次摊位升级 | 120—180 元 |

高阶系列可以整体提高进货与售价，但相邻系列建议保持约 1.5—2.5 倍，而不是10倍递增。万元价格只允许出现在明确标记为大隐藏的摆件上；常规款不得借系列升级普遍膨胀到万元。

## 收入与支出

### 收入

- 顾客购买上架藏品。
- “毒”中的悬赏订单。
- 周末或主题活动的摊位奖金。
- “扭扭”按当前市价 60% 即时回收，用于批量处理重复款。

### 支出

- 购买盲盒与批量补货。
- 升级摊位位置、陈列容量、招牌、服务和进货渠道。
- 购买装饰与功能设备。
- 电脑配件不再作为现金支出；玩家在“超级小狗”查看装机店老板的委托，用指定隐藏款交换八阶段配件。
- 后续可加入摊位租金，但首版不设置强制固定支出。

## 毛利原则

- 按建议价出售整系列的长期平均毛利应为正，保证经营可以持续。
- 单盒开出任意常规款的基础市价约为盒价1.5倍；实际成交还会受到顾客报价和讲价影响，因此不会保证每单固定50%净利润。
- 常规款依靠稳定客流和具体角色热度形成小幅价差；小隐藏和大隐藏提供高额利润。
- 高价会降低周转速度，低价会提高成交但减少利润，形成经营选择。
- 隐藏款的价值上限来自收藏需求和稀缺性，不通过每日成倍行情膨胀。

## 首版升级树

所有需要现金购买的摊位升级统一在手机“基米”百货平台完成；经营中心只保留经营数据与试玩控制，不再兼任商店。

### 货架

- 仅消耗现金，增加桌面可摆放／上架的商品栏位。
- 升级后以实体货架扩展表现，不能只增加手机里的抽象数字。

### 库存

- 仅消耗现金，增加背包库存容量。
- 超过容量时不能继续选择“保存到库存”，但仍可直接上架或先在扭扭出售旧物。

### 摊位位置

- 提高基础路过人数与高预算顾客比例。
- 改变背景街景和招牌位置，提供最强的视觉成长。
- 以声望等级为购买门槛，再消耗现金升级。
- 建议 5 级，每级成本显著增加，但保持几百到几千元尺度。

### 特殊展示盒

- 消耗现金购买，用于摆放高价值收藏物或待售摆件。
- 展示物当前市价越高，提供的摊位吸引力越高，从而增加顾客驻足数量。
- 吸引力采用递减收益并设置上限，防止单件万元大隐藏使客流无限增长。

### 新盲盒种类

- 不再使用日期门槛。第一个系列默认开放，后续系列分别要求累计开启上一系列8、12、18、25盒。
- 只有真正完成开盒并揭晓内容物才计入进度，购买后仍放在桌面的未开盒不计数。
- 左上HUD与进货页都要显示下一系列名称、上一系列开盒进度和目标次数。

### 连开能力

- 以声望等级为门槛，再消耗现金升级。
- 等级路线固定为：单开 1 盒 → 五连开 → 十连开。
- 升级只改变单次处理数量和演出，不改变概率。

### 口才

- 以声望等级为门槛，再消耗现金升级。
- 扩大顾客愿意接受玩家还价的范围，降低高反报价直接谈崩的概率。
- 口才不能突破顾客预算硬上限，也不能保证每次讲价成功。

## 暂不保留的旧升级

- 取消撕封脱手率，因此不再需要“降低脱手率”的开封技巧升级。
- 取消自动开盒机器人、容量和速度升级，统一由连开能力替代。
- 永久幸运度升级明确取消；幸运只允许作为单次道具或限时事件效果。
- 摇盒次数、包装速度等是否回归，待核心摆摊循环验证后再决定。

## 解锁节奏

- 肥嘟嘟伙伴默认开放；开启8盒后解锁高雅企鹅。
- 高雅企鹅开启12盒后解锁奶蛙生肖；奶蛙生肖开启18盒后解锁牛来。
- 牛来开启25盒后解锁胖企鹅，形成逐级加深的系列投入。
- 大蓝书、毒、扭扭、集换处依次采用现金与已解锁系列数量的复合门槛；达到条件后永久解锁，不会因花钱而重新锁定。
- 电脑配件不再是现金消耗项，改由装机店老板的隐藏款交换任务推动。

## 防软锁

- 若现金低于最便宜盲盒价格且没有可售库存，次日提供一笔一次性供货商赊账。
- 赊账只提供固定数量入门盒，从后续销售额中缓慢扣回，不产生复利。
- 玩家永远可以降低现有商品价格来提高周转，不需要等待随机行情翻盘。
