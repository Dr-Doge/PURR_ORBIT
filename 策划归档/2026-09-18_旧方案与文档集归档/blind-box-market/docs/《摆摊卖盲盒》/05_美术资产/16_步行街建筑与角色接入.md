# 16｜步行街建筑与角色接入

## 可见街段

使用 `assets/Cartoon City Massive Megapack/gLTF/Buildings/` 的建筑，沿用现有玩家镜头和步行街根节点的 4 倍缩放。

| 场景节点 | 模型 | 用途 |
| --- | --- | --- |
| ShopRed/CityBuilding | Building 14/Building_14_A.glb | 左侧住宅底商 |
| ShopBlue/CityBuilding | Building 10/Building_10_A.glb | 橱窗楼、模型店 |
| ShopGold/CityBuilding | Building 12/Building_12_A.glb | 带蓝色遮阳棚的漫画店 |
| ShopGreen/CityBuilding | Building 6/Building_6_A.glb | 右侧拱窗沿街楼 |

这些正式模型直接实例化在 `scenes/stall_demo/stall_demo.tscn` 中，打开编辑器就能调整。每栋建筑明确保存 Position、Rotation 和 Scale；入口朝向玩家一侧，底部对齐街面。铺地保留可编辑 CSG，取消机动车道黄线，灯柱与花槽移至店前一侧避开行走线路。不搭建背后街区或玩家视野之外的完整城市。

## 行人身份与外观

角色取自素材包的 `gLTF/Characters/`，映射位于 `scripts/stall_demo/city_pedestrian.gd`。每名角色出生时确定身份，此后外观和议价档案保持一致。

| 分类 | 专属模型 | 行为 |
| --- | --- | --- |
| 穷学生 | Character_11_1_1 | 年轻黑发、粉色上衣；低预算特殊议价 |
| 普通爱好者 | Character_2_1_1 | 棕色夹克；普通购买 |
| 补全党 | Character_6_1_1 | 立发、墨镜、蓝色夹克；愿为缺款加价 |
| 土豪父母 | Character_5_1_1 | 西装领带；高预算特殊议价 |
| 收藏家 | Character_7_1_1 | 礼帽、眼镜；收藏型议价 |

装机店老板也使用正式白衬衫角色，保留原有任务点击范围和提示牌。

## 行走与到摊流程

素材包 `gLTF/Animations/Animations.glb` 提供 Walk_A、Walk_B、Walk_C 和 Idle_A。动画轨道按骨骼名称接到各角色骨架，删除无对应骨骼的辅助轨道，锁定 Hips 水平位移，避免动画与路径重复推动角色。

角色统一以本地 +Z 为正面。每帧按实际移动方向平滑转身，速度与走路动画播放速度对应。背景行人沿三条平行通道双向行走。

有顾客名额时，从摊位附近正在行走的人流中选择可购买角色；原节点保留世界位置，斜向走出原通道，到桌前停下、转向玩家并切换待机，随后报价。成交、拒绝或等候超时后，原角色转身走回原通道，再沿原方向离开。禁止另外生成面向玩家横移入场的顾客，也不在报价时重新随机身份。

验证脚本 `tests/validate_city_presentation.gd` 检查真实骨骼运动、同一角色身份延续、接近过程无跳跃、停步朝向与离开后回归人流；有图形渲染时同时输出主菜单和玩家视角截图到 Godot user 目录。
