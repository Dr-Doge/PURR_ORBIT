**场景保持全屏俯视2D像素风，没有需要移动的小人。鼠标就是玩家的手：抓猫、搬猫、摆设备、接产线。**增量目标和生产循环延续角色版；下表具体手势与设备流程为EA建议。

## 1. 最基本怎么玩

**拖猫进设备 → 设备产出 → 猫休息恢复 → 再次送入。**

开局有猫和可用设备。按住猫拖到设备入口，松手就开始工作；猫不被消耗，产物短暂弹出后自动结算。之后升级抓取数量，再让设备接手搬运，最后提高整条循环的速度。

| 角色版的行动 | 鼠标版的操作 |
| --- | --- |
| 走到猫旁边，夹起一只 | 直接按住一只猫，拖动搬运 |
| 升级吸取工具，一次搬多只 | 升级一次抓取的猫数；按住猫时带起附近一批，拖到入口一起放下 |
| 走到设备旁卸下猫 | 拖到高亮入口后松手；入口接走可容纳的猫 |
| 用工具引导猫群 | 切换引导模式，移动鼠标光点让猫群跟随 |
| 到现场摆放、调整设备 | 在建造模式中拖出或移动设备，点旋转按钮调整方向 |
| 到接口附近连接运输 | 在建造模式中，从一个接口拖线到另一个接口 |
| 到现场检查设备 | 点设备查看工作、等候和缺少输入的状态 |
| 跑去另一片区域 | 后续大场地用屏幕边缘平移或小地图切换视野；基础Demo一屏可操作 |

## 2. 瓶颈怎样出现、怎样突破

| 阶段 | 玩家遇到的问题 | 突破办法 | 玩家能感受到的变化 |
| --- | --- | --- | --- |
| **单只搬运** | 猫很多，每次只能拖一只，设备经常等猫 | 升级一次抓取的数量 | 从一只只拖，变成一批批送；操作次数减少 |
| **批量搬运** | 一次能搬很多，但仍要自己反复拖放 | 摆放自动送料装置，接入照料和恢复回流 | 松开鼠标后，猫仍会自动进入设备并重复产出 |
| **自动送料** | 就绪猫很多，送料却断断续续，机器吃不饱 | 改入口位置、扩大覆盖、增加输送量 | 猫更连续地进入设备，停顿减少 |
| **设备处理** | 猫送得足够快，入口开始排长队 | 提升处理速度，或增加设备并分流 | 多只猫同时处理，产物连续弹出 |
| **猫群恢复** | 设备足够快，但猫都在休息，机器又空了 | 改善恢复能力；猫群不足时再增加猫 | 就绪猫能够接上下一轮，持续产出提高 |
| **区域规模** | 设备越来越多，逐台摆放和调整又变繁琐 | 解锁成组移动、布局复制和区域管理 | 从操作一台设备，变成安排一整片生产区域 |

**这些是常见的发展阶段，不是强制购买顺序。看见哪里慢，就优先解决哪里；不会暗中降低旧设备效率来制造问题。**

## 3. 玩家需要探索什么

| 看见的现象 | 可以试的办法 |
| --- | --- |
| 有很多猫没被自动装置接走 | 把接收口移近猫群，看看覆盖范围是否合适 |
| 一台机器排队，另一台闲着 | 把输入分一部分过去，比较实际入账速度 |
| 买了更快的设备，收入没怎么涨 | 检查送料与恢复，确认慢的是不是别的环节 |
| 全部自动化后还想继续提高收益 | 调整布局、扩充有效猫群，后续研究新品种和设施组合 |

鼠标可以直接跨场地搬猫，因此**不再用人物走路距离制造瓶颈**。手动阶段主要受抓取数量与重复操作限制；自动化阶段受覆盖、输送、处理和恢复限制。玩家依然可以手动补位，但不会因为不亲手拖猫而让基础自动循环停下。

## 4. 操作保持简单

- 普通状态拖猫；进入建造模式才拖设备、接线路，避免误操作。
- 抓取时显示本批数量，设备入口高亮；无效落点可取消，满载时未接收的猫安全回到原位，不丢失、不凭空产出。
- 搬动猫不会重置恢复进度；不能反复拖进设备刷奖励。
- 少量资源信息放顶部，底部只放工具和建造入口；研究、建造按需打开，不恢复旧竖高边栏。
- 不人为限制鼠标速度，也不增加拖动耗时条。自动化的首要价值是省去重复操作，产线升级再提高持续产量。

**Demo建议：做完“单只拖动 → 批量抓取 → 自动循环 → 调整产线后明显增产”。**先用同一批猫与设备对照角色版；鼠标版搬运更快，研究价格和解锁节奏必须重新验证，不能直接继承角色版等待时长。
