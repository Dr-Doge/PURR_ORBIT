# 猫咪资源与再生｜方案选择

> v0.14更新：猫永久存在、蓄积再生已确认。养猫提供原料，生产负责加工换金，两套升级独立；见[12双循环表](12_养猫与生产_双循环对照表.md)与[00当前规则](00_简明策划案.md#dual-loop)。本篇早期“采集即入账”简化不再用于新经济，具体采集与培育设施仍为EA建议。

2026-09-16｜本篇为EA推荐，永久猫循环方向已获用户确认，具体细则仍为EA建议，未实装。适用于[09角色版](09_史莱姆猫咪养殖场_玩法流程与拓展表.md)与[10鼠标版](10_史莱姆猫咪养殖场_鼠标操作对照版.md)，规则与参数统一见[00](00_简明策划案.md#cat-resource)。

**建议：猫咪永久存在，体内产物会重新蓄积；扩大猫群另外花资源培育。**日常生产循环和猫群数量增长分开设计。

## 1. 两种方案的区别

| 方案 | 玩家反复做什么 | 主要瓶颈 | 优势与代价 |
| --- | --- | --- | --- |
| **猫咪循环产出（推荐）** | 将长满的猫送入设备，产出后让它重新蓄积 | 抓取、送料、处理、蓄积速度与猫群数量 | 容易建立熟悉的猫群，也能做多种体态反馈；必须让回流自动化，避免重复搬回 |
| **猫咪作为消耗品** | 不断生成猫，再把它们送入设备消耗 | 生成速度、生成成本、运输与处理 | 原料流清楚，适合持续喷出和吞入的大规模流水线；猫种更接近原料类别，独特个体难保留，供给中断会停产 |

如果采用消耗方案，必须先解决“猫从哪里持续来”：免费定时生成，瓶颈主要是生成速度；付费生成，则要核算每只猫的加工净收益，并提供不会花光后断粮的保底来源。它不是省掉恢复，而是把恢复环节换成生成环节。

## 2. 推荐的日常循环

**瘪猫 → 慢慢鼓起 → 长满 → 送入设备 → 弹出产物、重新变瘪 → 返回蓄积区。**

| 状态 | 玩家看见什么 | 怎样处理 |
| --- | --- | --- |
| 正在蓄积 | 猫从软瘪逐渐变圆 | 可以搬迁，暂时不能生产；不需要额外喂一次才能恢复 |
| 已经长满 | 饱满、弹跳，带明显就绪提示 | 可以送入生产设备；暂时不收也不损失已有产物 |
| 正在生产 | 设备揉压，猫明显变形 | 设备处理，不再接受重复抓取或重复投放 |
| 完成生产 | 产物弹出，猫变瘪 | 猫仍然存在，安全返回蓄积区域，开启下一轮 |

基础版长满后停止蓄积，不无限囤积多轮产物，也不因为多等一会儿直接涨售价。就绪猫形成可见的待处理储备；机器够快时，更多猫可以接替正在蓄积的猫。

## 3. 猫群数量怎样增加

| 项目 | EA建议 |
| --- | --- |
| 初始来源 | 开局免费提供可完成首轮生产的猫群，避免先花钱才能获得第一笔收入 |
| 扩群方式 | 用基础生产收入启动培育舱，等待孵化完成后新增猫咪 |
| 是否消耗老猫 | 不消耗老猫；培育是新增长期生产能力 |
| 新猫怎样加入 | 以空蓄积状态加入，首次长满后参与正常生产 |
| 后续自动化 | 先手动选择培育，后续可解锁批量培育／有预算的自动培育；不默认自动花光资金 |
| 后续升级 | 培育速度、同时培育数量；与猫本身的产量、蓄积速度分别承担不同职责 |

Demo先不加入免费自动分裂，也不增加营养、饥饿、卫生等多条需求。免费分裂会让数量自行指数增长，容易掩盖玩家在工具和产线上的投资。培育费用与时长待测，不沿用旧摸猫版价格。

## 4. 玩家会怎样选择升级

| 场景里的问题 | 优先考虑 | 为什么 |
| --- | --- | --- |
| 设备空闲，猫都还没长满 | 更多猫，或加快蓄积 | 提高能够持续送入的就绪猫数量 |
| 长满的猫很多，设备却没接走 | 抓取数量、自动送料、接收范围 | 供给已有，慢的是送达 |
| 设备入口排长队 | 处理速度、并行设备、分流 | 继续加猫只会增加等候 |
| 循环稳定，但希望每次产出更多 | 单次产量 | 提高一次有效生产的价值；不等于缩短周期 |
| 猫数量多，搬迁和整理麻烦 | 批量操作、区域管理、自动回流 | 规模增长不能退回逐只管理 |

**增加猫数＝增加长期生产单位；加快蓄积＝缩短这些单位的等待；增加单次产量＝提高每轮价值。**三者最终都要经过送料与设备才能变成实收，不能把理论增幅直接当成收入增幅。

以后若想加入“消耗式生产”的视觉和产线，可以让永久猫咪分泌出小凝胶团，再加工凝胶团。这样保留猫群，又增加可消耗原料；这属于后续备选，不与Demo的基础循环同时展开。
